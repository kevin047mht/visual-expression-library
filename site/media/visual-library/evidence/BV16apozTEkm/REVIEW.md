# 《静止系mad/风华回战2025》正如我们共同谱写的故事那般：实际画面审阅

[B站原作](https://www.bilibili.com/video/BV16apozTEkm/)

ATRI最棒了，实页6712播放、2025-09-20；作者描述5月至9月制作、抠图与合成，并感谢看稿建议。传统静止画候选；未证明全程零AI。片头出现比赛/团队图样，归属不明，不能全算作者独立制作。

实际查看26张3秒概览0–75秒（2表）、4.4–6.333及28–29.933两组60密集帧（4表，15/s）；44–47.9另40帧（3表，实际10/s，请求12）。76.074秒1920×1080、30fps编码，3段4秒摘录。未听审、未完整连续观看。

|0–9秒|**桌面贴纸拼贴／手机唱片 UI／相机框／递归照片**。开头彩色桌面有地图、手机、明信片、笔与胶带；4.4秒唱片页，随后向右上移动，照片逐张显露、6秒再出现本画面拍成照片的嵌套卡。此段可能为团队/活动片头素材。|把平面素材分层在虚拟桌面放置，摄像机平移/旋转；照片矩形遮罩显露，再将合成快照回贴成小卡；相机控件固定在边缘。 中等，机制可代码直出；素材排布多，归属与片头复用须核实。|
|9–24秒|**黑白漫画抠图／场景合成／景深／留白细字卡**。9秒模糊漫画，12秒两人车厢；15/18秒留白中央小字、编号及纤细装饰线，21秒侧脸、24秒竖幅人物。|人物分割与背景修补，多层平移建立视差，近层虚化，灰度统一；小字与细线布局独立。 基础排版容易，抠图和补背景中等且需检查边缘。|
|28–30秒|**橙红漏光／辉光色差／前景遮挡／横条位移**。28–28.2橙红光泄漏，28.267见牵手人物；29秒前景灰弧遮挡+高亮色差，29.533转低机位双人，29.8同画面横向撕条变形后恢复。|软噪声渐变做漏光，亮度曲线与RGB轻微错位；前景alpha移动；按扫描行切条做不同横向偏移。 漏光/色差/条带容易；人物和空间源素材需处理。|
|30–42秒|**静止人物运动／漂浮叶片／背景光斑**。双人与街景、长椅与树木构图中有漂浮叶片和散焦光点，主体为漫画线稿，空间背景有照片/绘画质感。不能仅凭画风确认实拍来源。|叶片透明贴图按轨迹/深度缩放旋转，远近不同模糊；人物与场景分层缓慢推拉，光点用散焦圆。 有抠图与背景时中等；简单粒子/推拉容易。|
|44–45.9秒|**相机框/负片闪烁／重复字纹／竖排文案／条带转场**。44秒叶片带相机边框与负片，44.3回正常叶；44.9整屏重复汉字，45.1青色大字一闪，45.2转花朵和竖排字，45.8条带撕裂后45.9转儿童。|反色开关和UI层，文字在规则网格重复、整体缩放，换色闪帧；竖字按纵向布局，横向条带噪声掩护新图。 容易到中等，字网格和滤镜可直接出；节奏可读性需调整。|
|46–73.8秒|**漫画细节推近／前景铅笔／水波与光影／竖幅书本**。47秒人物画本，47.7更近书本，51秒俯视，63秒室内前景铅笔，66秒桥下人物与水，72秒竖幅笔记。某些运动可由同张图裁切完成。|从大图裁切不同取景，用分层变换/轻微形变；前景模糊道具与投影，水面置换/反射可简化。 平移缩放容易；真实水面、光影和补画需素材或逐镜合成。|
