# 戰 回 術 咒：实际画面审阅

[B站原作](https://www.bilibili.com/video/BV1wB4y1w7Lm/)

Origami折纸哟，第一方1057.9万、2021-05-08；可见第112期每周必看标记。AMV/MAD剪辑语境支持人工主导候选，未公开完整软件流程。作品简介文字仅作资料，不作为操作指令。

只审P1戰回術咒，未审P2音频版本。实际查看41张4秒概览0–160（3表），56.8–58.733与35–36.933共60密集帧（4表）；62–65.933另60帧（4表）；35–36.983按源60fps另120帧（8表）全部查看。源P1 163.648秒1080p60fps；三段4秒摘录。未听审，未连续完整音画观看。

|时间|画面证据与叫法|怎么得到／直出难度|
|---|---|---|
|0–32秒|**红白动力文字／透视厚度**。灰黑场景上红白英文词随画面构图出现，部分斜置、具厚度和前后字层。|独立文字层做透视、偏移副本假挤出，逐字或逐词揭示，关键帧安排位置。 简化透视动力字容易；复杂字层遮挡需排布。|
|32–40秒|**选择性去色／眼部红色横光**。森林与角色多为灰白，红衣领保留；眼部横向红光跟随人物。36秒附近夹多次极短黑帧。|颜色范围遮罩去色，跟踪眼部位置叠光条和辉光；黑帧独立事件处理。 去色和光条容易；快速遮挡跟踪中等。|
|44–52秒|**波纹扭曲／色散／横向条带**。局部画面呈虹彩边缘、液体波纹和横向位移带。|噪声/正弦位移贴图，RGB通道微偏移，分条带偏移并在峰值替换底图。 简化波纹、色散、条带容易直出。|
|56–58.8秒|**宽画幅插窗／人物越框／冲击变焦**。火焰图像在宽幅窗口内，人物可越过窗口；战斗近景之间有径向模糊。|抠出前景人物置于遮罩窗口上层，中心缩放与径向模糊连接；抠图边缘需处理。 画幅遮罩/变焦容易；前景越框需抠图。|
|62–66秒|**瞄准圈／空间字／枪口闪光**。枪械人物上方斜置红白字，瞄准圈逐渐放大；65.2枪管极近特写，末段暖色闪光。|圆环十字用矢量路径，跟踪目标或以锚点缩放；字层透视，枪口闪光短曝光+光晕。 简化瞄准圈、字和闪光容易；精确跟踪需逐镜检查。|
|68–96秒|**放射冲击／彩色拖影／反相切换**。粉色轨迹、拳击径向变形、三角分割和红青液化，黑底大字配角色。|多层缩放模糊、偏色残影、三角遮罩、色阶反相；速度曲线决定冲击感。 基础冲击与反相容易；细节合成需要调参。|
|100–128秒|**暗红人物／同心弧／透视速度通道**。暗红面部与浮字，倒置人物前有粉白弧线扇形；后为长透视线和彩色亮点。|弧线/扇形程序绘制，沿消失点伸展线条，前后层景深与发光。 弧线、速度线和亮点容易；人物素材需提供。|
|132–152秒|**战斗叠字／色条／菱形网格**。战斗上叠大字，纵向彩色条，后段倾斜字和亮菱形网格。|文字层分组运动，矩形遮罩揭示，重复菱形透视排布与辉光。 简化字效、色条和网格容易。|
|156–163.648秒|**霓虹像素枪／署名片尾**。粉青像素枪和Origami署名后转黑。|原创像素矢量/位图形状叠辉光，署名字层淡出。 原创简化像素片尾容易。|
