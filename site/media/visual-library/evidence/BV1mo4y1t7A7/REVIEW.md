# 《让驱魔师免于堕落》：静止画空间化审阅

[折木Lz，BV1mo4y1t7A7](https://www.bilibili.com/video/BV1mo4y1t7A7/)。第一方页面23.7万播放，注明漫画和音乐来源。源120.128秒、1080p24。实际查看31张4秒间隔全片概览，以及85–87、91–93秒密集源帧。请求15fps，在24fps源上实际每约0.083秒一帧。没有听审音轨。

|时间|所见效果、叫法|复现路线与直出判断|
|---|---|---|
|4–8秒概览|灰阶楼顶剪影、云层、局部小字，画面边缘黄蓝色偏移|“剪影环境／分层视差／通道偏移”。基础分层、调色和色散容易；静帧不能证明真实3D模型。|
|12–28秒概览|漫画人物抠像置于粉、红、白色块；链条前景、棋盘地面、黄眼和暗部轮廓|“漫画抠图拼贴／局部着色／前后景遮挡”。已有图层后基础合成容易；人物拆分、补画和统一光影需准备。|
|32秒概览|黑底细衬线中文，下面小号英文与短横线|“中英层级排版／叙事卡”。文字和显隐容易。|
|48–56秒概览|漫画角色置于建筑剪影、深色空间；粉色碎片和橙色线团前景|“2.5D漫画空间／景深／粒子前景”。规则粒子可做；原片精细分层和美术不能视为一键滤镜。|
|80–84秒概览|人物分立在透视棋盘地面前后，相互遮挡，布局有深度|“漫画立绘空间化／透视地板／相机编排”。可用Three.js平面贴图或Blender相机实现；需抠图、深度排序、相机和边缘处理。|
|85–87秒密集帧|橙白发光折线、光球、重复菱形列阵在棋盘空间中变化，末尾人物大形状进入|“能量轨迹／重复几何阵列／加法辉光／遮挡转场”。基础折线和阵列容易，复杂空间镜头与人物遮挡中等至较难。每束光的闪动不算换镜。|
|91–93秒密集帧|强方向模糊与亮闪后，由远近双人构图到脚部近景、人物消散碎点，再出现俯冲人物反打|“甩镜模糊／白闪／粒子消散／动作反打”。已有图层可做相机和遮罩；肢体动画、人物图层连接和动态修形需逐镜处理。|

85–87秒的高变化主要是能量轨迹、几何阵列、亮闪和遮挡；91–93秒有明确景别替换，但需要结合完整连续播放区分相机连续移动与硬切。本次不把自动场景候选数当作切镜率，不给全片平均值。

可以轻松直出的是字效、双色填充、简单通道错位、规则光线和基本几何遮罩。要达到该片的空间化漫画效果，需要高质量抠图、补画、前后层级、相机轨迹和动画调试；这比“把一张图加运镜”要求高。漫画原画署名与作者后期劳动分别记录，未证明作品完全不用AI。
