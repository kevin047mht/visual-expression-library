# H03《崩 溃 边 缘》抽帧实审

已检查原片0–102秒每4秒一帧的26张概览图，以及56.300–58.300、93.900–95.900秒两个15fps连续抽帧窗口。附两段4秒含音片段；本次没有连续全片播放和听音，因此不声称全片观看或已评定音画对拍。

16、20、24秒可见矩形局部叠压和错位拼贴，适合以裁切图层和关键帧复现。56.300–57.033秒主要是同一车内构图中的枪火和玻璃变化；57.100、57.633、58.233秒附近才可辨至少3次不同构图切换。场景检测的高频命中大量是闪光及原动画动作，不能算成同等数量硬切。

93.900–94.900秒是霓虹字标、水平色块撕裂、RGB色散、噪点故障；94.967–95.233秒字标碎片向镜头爆散；95.300–95.767秒亮黄EDGE RUNNER字母跳排和前景Logo收束。故障条带、文字跳排、色散和矩形拼贴可轻松代码直出；精确金属挤出与碎片空间效果需要3D或逐镜调试，原角色动作不能仅靠滤镜得到。

详见同目录 `manual-review.json`，时间码来自原片抽帧，切点仅精确到15fps抽样的约67毫秒夹区。作者简介“工作量最大的一集”支持人工投入，但不证明完全无AI辅助。
