# 呐，你喜欢跑步嘛？【小栗帽/赛马娘/静止系MAD】：实际画面审阅

[B站原作](https://www.bilibili.com/video/BV1tC41147At/)

百椰果，第一方3.8万、2024-02-08；作者称制作半年多并感谢文腾Wen、猫奴头子、折木lz的静止系源计划素材。这说明含共享素材，不能把每层场景都视为独立原创。

实际查看37张约3秒概览0–108.108（3表），102.728–104.646与62.020–63.939共48密集帧（4表，实际约11.99/s）；89.006–92.926另48帧（4表，实际约11.99/s）。源110.741秒1080p23.976fps；三段4秒摘录。未听审，未连续完整音画观看。

|89–93秒|**透视胶片带／随机文字变换／景深**。斜置胶片条中有小画面，前方大串文字快速替换，90.34前后收束成较小中央语句，泡泡继续漂浮。|带齿孔曲线网格贴图、图像窗，随机字符序列按时刻换成目标字；分层景深和缓动拉远。 平面透视胶片/字效中等；弯曲空间胶片和多图层遮挡需调试。|
