# 「影视飓风·无限进步」影视飓风五百万粉丝混剪：实际画面审阅

[B站原作](https://www.bilibili.com/video/BV1g841177ym/)

拍照的蛋不包饭，第一方2.3万、2022-11-18；作者描述自2018年关注并制作粉丝混剪，画面明确使用影视飓风团队素材。因此区分该UP的选材连接与原团队拍摄/包装，不能把原片镜头都算粉丝新增特效。

实际查看60张5秒概览0–295（4表），21.9–23.833及220–221.933共60密集帧（4表，约15/s）；28–31.9另40帧（3表，实际10/s、标题请求12/s）。295.445秒1080p30fps，三段4秒摘录。未听审、未连续完整音画观看。
