类型专题 · 界面、程序与秩序

信息成为叙事

先让观众理解规则，再让规则发生变化。面板、坐标、进度和弹窗可以承担叙事，但必须区分主信息与环境纹理。

先问这个问题

此刻观众必须读懂哪一条信息？如果所有界面都在动，谁仍然是主角？

适合什么内容

产品功能解释、推理线索、人物关系、搜索与等待、制度压力、人与机器的关系。

容易失效的地方

把装饰日志当正文、每层同时入场、图表只有形式没有含义。界面越像真实系统，数值和因果就越需要核查。

做一次小练习

用同一句“正在寻找一个人”做三种状态：有秩序的搜索、遇阻、失控。每版只允许一个主信息区和两层辅助信息。
