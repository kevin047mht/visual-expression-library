第一次来，从这里开始

先读关系，再学包装

先看一张画面，指出焦点和依据；再看相邻状态，判断信息怎样改变；最后换一种题材做同一表达。不要把学习停在“复制效果”。

  1. 沿一条阅读路径，看5—6个案例
  2. 打开一例，图与分析并排阅读
  3. 用两例对照，找共性与取舍
  4. 完成一次有限约束的表达练习
