手法专题 / 规则、用途与取舍

画中画、分屏与局部拼贴

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

什么时候使用

记忆、对话、关系对照、主观视点、多人角色介绍、跨素材呼应。

什么时候应该减掉

窗口太多无主次，眼位错位、边框挤脸，层的出现没有叙事理由。

制作步骤

①定义主窗；②选择共同锚点如眼睛/手；③统一裁幅；④按信息先后加窗；⑤用留白或色差区分层级。

直出条件

矩形裁切易；选材与空间对位需判断。
