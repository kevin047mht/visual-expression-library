手法专题 / 规则、用途与取舍

界面、菜单与信息面板

用规则、选择与反馈组织关系，让抽象状态可被看见。

什么时候使用

人物关系、搜索、等待、推理、产品功能解释、系统压力；数值需要真实含义或明确虚构设定。

什么时候应该减掉

假数据制造伪解释；辅助文字太暗；每个窗口同时运动；手机界面只是装饰外壳。

制作步骤

①列状态与触发条件；②固定主信息区；③辅助区延迟进入；④只改变与事件有关的模块；⑤用色彩/尺寸标记状态，保留阅读停留。

直出条件

规则布局、计数与显隐易；语义和可读性需设计。
