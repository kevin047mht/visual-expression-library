AI02 · 原作约0—66秒

分析单元 01 / 0—66秒

终端打字机、界面骨架揭示、环形路径排字、数学图形动画

实际观察

深色聊天界面从线框和占位条转到聊天框，英文标题、歌词和代码逐段显示；36–48秒有点集、环形字、函数图表。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

Canvas/SVG绘制UI，文字substring或矩形遮罩揭示，按t更新点线坐标；沿圆弧逐字布局

直出判断：易，规则几何和文字可代码直出

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →界面、菜单与信息面板 →

AI02 · 原作约54—126秒

分析单元 02 / 54—126秒

像素化降采样、半色调网点/点阵化

实际观察

54秒出现低分辨率马赛克；126秒人物呈离散点阵/网点印刷轮廓。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

先缩小再nearest放大；按亮度阈值或有序抖动绘制圆点/像素

直出判断：易到中，轮廓质量取决于输入素材

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →

AI02 · 原作约138—162秒

分析单元 03 / 138—162秒

故障弹窗轰炸、界面拼贴、代码逐行执行、计数器

实际观察

错误提示和聊天窗口层层叠放，粉红色ILLEGAL ARGUMENTS与EXECUTION反复出现；随后代码行高亮与run计数变化。

表达作用（教学解读）

用规则、选择与反馈组织关系，让抽象状态可被看见。

具体应用场景

人物关系、搜索、等待、推理、产品功能解释、系统压力；数值需要真实含义或明确虚构设定。

复现建议（非原作者工程还原）

独立卡片图层按时间出现/位移；确定性排布，代码高亮区横向遮罩，计数floor(time*rate)

直出判断：易，先整理版式与时间表

常见误用：假数据制造伪解释；辅助文字太暗；每个窗口同时运动；手机界面只是装饰外壳。

界面、菜单与信息面板 →RGB错位、条带与故障 →

AI02 · 原作约170—171.933秒

分析单元 04 / 170—171.933秒

硬切、亮度脉冲、色差边缘、水平切片故障、放射光

实际观察

170.133秒由人物特写切到标志+闪电箭头，170.600秒同一构图突然高亮与字形横切错位，171.533秒切回人物构图且短暂块状撕裂。

表达作用（教学解读）

把短暂破坏作为失控、断裂、冲突或数字材质的提示。

具体应用场景

赛博题材、记忆中断、身份不稳、高潮强调；也可短时掩护连接。

复现建议（非原作者工程还原）

在确定时间切场景，Bloom/多层模糊叠加发光；按横条随机偏移采样，RGB通道轻微错位

直出判断：易到中，代码直出可控；需要按音乐人工校验节奏

常见误用：全程持续导致麻木；色散让脸和字长期看不清；把所有亮度变化算成切镜。

RGB错位、条带与故障 →动作、视线与形状匹配 →

AI02 · 原作约180—180秒

分析单元 05 / 180—180秒

递归窗口、Droste式画中画、无限缩放通道

实际观察

人物和浏览器窗在窗内反复缩小，形成向中心递归的画中画。

表达作用（教学解读）

把可控规则变成可见变化；通过不变量、比例和相位建立秩序或空间。

具体应用场景

概念解释、音乐可视化、抽象世界、图表、程序艺术。

复现建议（非原作者工程还原）

同一预合成复制多层，等比例缩小并错开位置/时间，可加色边和模糊

直出判断：易到中，2D递归合成即可

常见误用：符号无含义；空间复杂度替代概念清晰；将程序生成误等同于文生视频生成。

几何、图表与程序空间 →RGB错位、条带与故障 →
