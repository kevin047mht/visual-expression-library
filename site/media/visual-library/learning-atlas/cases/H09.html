H09 / 主要视觉研究样本

人物与图形对话用素材建立新联系动作／武侠／英雄

软软冰 · 43万播放快照 · ≥10万 · B站原作 ↗

人物与街景不是抠出来放上去就够了。透视、光向、遮挡与环境色共同决定虚实是否可信。

从画面里找依据

这一例先看什么

街景、站台、扶梯中定位漫画角色，分屏和镜像连接实际空间与虚构人物，透视/遮挡/灯光匹配是关键。

审美判断

实景霓虹与角色重着色呼应，主脸/立绘从街景突出，蓝标题和黑字底块使文字有对比。

迁移到自己的题材

角色介绍、青春与活力、音乐视觉、活动包装、虚实人物合成、鲜明的个人品牌。

教学提问：去掉人物后，几何元素还剩什么功能？加回人物后，哪一层负责引导视线？

带画面的分析单元

图像标出取样时间，对应观察中的关键状态。单帧不能独立证明运动，连续性请结合摘录。表达作用与应用场景是教学解读，复现路线是建议，不是原作者工程还原。

H09 · 原作约0—12秒

分析单元 01 / 0—12秒

实景与漫画角色合成／冷暖分区／染色高亮

实际观察

东京街景、公交与小巷中叠动漫人物，蓝/紫/橙灯光与人物着色互相呼应，9秒蓝线形构件覆盖楼体。

表达作用（教学解读）

建立段落、材质和情绪的一致性；颜色变化可以承担信息，而不只是美化。

具体应用场景

多片源混剪、人物立场、回忆/现实区分、冷暖转折、品牌统一。

复现建议（非原作者工程还原）

人物抠图/描边，跟踪实景机位、匹配透视和大小，遮挡物遮罩；人物边缘按环境光染色，加接地阴影。

直出判断：中等到难；稳定跟踪、遮挡和光线匹配不能仅靠全局滤镜

常见误用：所有镜头同一滤镜；肤色被破坏；饱和度代替焦点；色彩含义前后矛盾。

色彩组织与选择保色 →

H09 · 原作约12—16秒

分析单元 02 / 12—16秒

故障条带／RGB错位／拆笔画字／黑色字底块

实际观察

12.012蓝色大标题，12.1–12.7多条水平错位块；12.763起黑矩形上白细笔画拼入，间或巨大笔画闪现，15秒左右版面较完整。整个底图是同一街景构图。

表达作用（教学解读）

把短暂破坏作为失控、断裂、冲突或数字材质的提示。

具体应用场景

赛博题材、记忆中断、身份不稳、高潮强调；也可短时掩护连接。

复现建议（非原作者工程还原）

标题透明层切为字/笔画或矩形切片，按时间显隐；当前图复制横条横移，RGB通道小幅分离，字底黑块独立。

直出判断：字层和条带机制容易；原片标志字形与设计节奏需专门制作

常见误用：全程持续导致麻木；色散让脸和字长期看不清；把所有亮度变化算成切镜。

RGB错位、条带与故障 →文字排版与逐字动效 →

H09 · 原作约18—33秒

分析单元 03 / 18—33秒

旋转甩镜／倾斜画卡／镜像万花筒

实际观察

18秒实景旋转模糊，30秒黑底多张倾斜画卡带方向模糊，33秒街景被多向镜像成几何拼接。

表达作用（教学解读）

把可控规则变成可见变化；通过不变量、比例和相位建立秩序或空间。

具体应用场景

概念解释、音乐可视化、抽象世界、图表、程序艺术。

复现建议（非原作者工程还原）

组层快速旋转平移并加运动模糊；复制视频做三角/扇形蒙版、镜像与旋转，构成万花筒。

直出判断：机制中等，中心/方向连续性和卡片时间需调试

常见误用：符号无含义；空间复杂度替代概念清晰；将程序生成误等同于文生视频生成。

几何、图表与程序空间 →几何拼贴与形状语言 →

H09 · 原作约21—57秒

分析单元 04 / 21—57秒

角色海报式定位／实景空间中的立绘／线框多屏

实际观察

人物出现在楼梯、扶梯、站台；42秒多张黑白角色卡带线框，48秒动漫人物和真实店内立牌并置。角色并非总有完整动画动作。

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

分层漫画人物在二维/三维平面定位，按镜头跟踪移动；线框是多层矩形变换，卡片由原画裁切。

直出判断：已有分割素材时中等；自动生成可用抠图与准确空间关系仍需检查

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →色彩组织与选择保色 →

H09 · 原作约75—83秒

分析单元 05 / 75—83秒

蓝红能量线／径向拉伸／高阈值黑白闪变

实际观察

80.914手势发蓝光，81.081转角色脸+街景，81.665起径向模糊连接人群广角；81.915、82.249、82.332等黑白阈值/反色变化，蓝能量轮廓保留。

表达作用（教学解读）

短暂中断视觉连续性，强调接触、转折或心理断裂；其价值来自前后的对比。

具体应用场景

打击点、快速连接、记忆跳跃、段落转折；需要根据内容选择强度。

复现建议（非原作者工程还原）

沿曲线画能量线加辉光；缩放多副本加权做径向拖影；灰度阈值、反色及RGB偏移按帧开关。

直出判断：简化光线/径向模糊/黑白效果容易，追踪角色轮廓需遮罩

常见误用：把闪烁当节奏本身；没有稳定画面作参照；为掩盖动作不清持续加闪。

闪白、黑帧与冲击帧 →色彩组织与选择保色 →

H09 · 原作约90—102.7秒

分析单元 06 / 90—102.7秒

漫画光影重绘／人物卡与实景切换／红黑负片

实际观察

90秒蓝色角色加光点，99秒黑白漫画叠金色纹理，100.892暖黄街景侧脸，101.56更远双人街景，102.227起红黑人物和白黑反转。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

原画分层和调色遮罩，金色纹理与发光边缘；按剪点在合成场景/漫画卡之间接镜，短反色强化连接。

直出判断：滤镜层容易；复杂重绘、材质与环境光需素材或人工处理

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →闪白、黑帧与冲击帧 →

H09 · 原作约105—115秒

分析单元 07 / 105—115秒

大字版面／粒子擦除人物／蓝色发光片尾

实际观察

105秒红色倾斜大字与人物对置，111秒粉白粒子露出角色，114秒蓝色纹理与标题。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

字形独立层旋转排版，人物alpha乘噪声阈值形成粒子式显隐，标题描边加辉光、背景噪声滚动。

直出判断：简化版中等，字形和人物细节依赖素材

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →粒子、花瓣、雪与碎片 →

短时变化怎样理解
