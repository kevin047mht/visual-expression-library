H40 · 原作约0—42秒

分析单元 01 / 0—42秒

暖冷调色／前后景虚化／竖排标题

实际观察

咖啡馆、人物近景、树林双人，配竖排说明和居中关键词。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

曲线调色、柔光、前景模糊、字层渐显。

直出判断：调色/虚化/字效容易；人物动作来自源素材

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →景深、柔焦与负空间 →

H40 · 原作约42—54秒

分析单元 02 / 42—54秒

胶带拍立得／单张到双张／景深模糊

实际观察

白底关键词后出现胶带照片框，由单张转双张冷暖人物组合，模糊接近景。

表达作用（教学解读）

把画面变成可触摸的记忆或记录；纸边、阴影与展示顺序可以表现珍惜、拼凑或碎裂。

具体应用场景

回忆、青春、艺术创作、旅行手记、人物档案、纪念短片。

复现建议（非原作者工程还原）

纸框和胶带透明图、阴影，照片裁切，图层位置/旋转和模糊动画。

直出判断：简化拍立得/胶带/阴影/模糊容易

常见误用：所有纸张纹理一样重；阴影方向不一致；折页遮挡错误；照片墙只有数量而没有观看顺序。

纸张、照片与漫画分格 →漫画分层与2.5D视差 →

H40 · 原作约54—78秒

分析单元 03 / 54—78秒

双语混排／关键词方块／逐层揭示

实际观察

蓝天白字配小外文与揭示方块，饮料植物夕色旁有红黑文字块，再转暗云。

表达作用（教学解读）

把注意力从旧信息带往新信息；遮满时换底图，保持方向或形状上的联系。

具体应用场景

章节转换、空间跨越、角色亮相、画内物体自然遮挡后的换景。

复现建议（非原作者工程还原）

大小字层、矩形遮罩、混合字体、背景调色与遮罩揭示。

直出判断：文字排版/块状揭示容易；需校对可读性

常见误用：每镜不同花哨转场；遮罩与运动方向相反；过渡比内容本身更长；遮挡未满就穿帮。

形状遮挡、擦除与揭示 →文字排版与逐字动效 →

斜向漫画条／水泡蝴蝶／留白排字

实际观察

窄斜漫画条带文字，手在水中并有蝴蝶和气泡，随后留白小字。

H40 · 原作约102—143秒

分析单元 05 / 102—143秒

眼泪特写／伸手／屋顶前景叠像

实际观察

人物惊讶与眼部特写、夜间伸手及屋顶对话，大而模糊的人物层压住小人物。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

原动画选镜，人物抠图、前后层景深、缩放位移。

直出判断：有抠图后视差容易；精细人物分离需处理

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →巨构、雾层与尺度参照 →

H40 · 原作约143—158秒

分析单元 06 / 143—158秒

霓虹边缘／漫画格扫移／黑白块转场

实际观察

彩色人物短暂变边缘光，再接漫画格；相机扫过同页多个格。哭脸后灰黑矩形过渡至漫画页逐格出现。

表达作用（教学解读）

把画面变成可触摸的记忆或记录；纸边、阴影与展示顺序可以表现珍惜、拼凑或碎裂。

具体应用场景

回忆、青春、艺术创作、旅行手记、人物档案、纪念短片。

复现建议（非原作者工程还原）

边缘检测着色、漫画页平移缩放，矩形遮罩和面板透明度动画。

直出判断：简化霓虹/面板/块转场容易；同页扫移不应虚增切镜

常见误用：所有纸张纹理一样重；阴影方向不一致；折页遮挡错误；照片墙只有数量而没有观看顺序。

纸张、照片与漫画分格 →色彩组织与选择保色 →

H40 · 原作约198—231.594秒

分析单元 08 / 198—231.594秒

线稿拥抱／夜桥与雨／黑底片尾

实际观察

简化线条拥抱图形配字，随后桥上人物、雨伞片段与黑底歌曲片尾。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

线稿素材和字层，源片段调色、淡入淡出。

直出判断：文字/淡出容易；原线稿和人物表演需素材

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。
