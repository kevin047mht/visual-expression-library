AI19 · 原作约0—12秒

分析单元 01 / 0—12秒

黑白诊断档案版式／衬线标题与粗体AI／细线边框

实际观察

0秒多重细矩形内框，4–8秒中文衬线与粗体英文字结合的标题，12秒进入左字右人物卡；底部双行小字幕与细线组成统一模板。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

按安全边距定义布局栅格、字体层级、段落锚点和边框；矩形轻旋转/缩放、文字alpha与遮罩揭示。

直出判断：容易，准确字体和排版仍需调试

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →色彩组织与选择保色 →

AI19 · 原作约12—32秒

分析单元 02 / 12—32秒

左右交替图文卡／编号／台词重复纹理

实际观察

12、16、20、24秒人物卡与文字交换左右或上下；图内有重复小字背景、强调词、编号，底部字幕延续。它们是版式内容，不是当前系统界面。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

人物图与字卡为独立组，使用预设左右/上图下字布局；背景重复文字降低透明度；编号与文案随时间更新。

直出判断：已有立绘时容易，角色图像生成不属于排版直出

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →文字排版与逐字动效 →

分析单元 03 / 26—30秒

全画面波形位移／抖动字形／横向扫线

实际观察

26–27.7秒左文字右人物稳定，27.8开始外框、人物和字行同受波形扭曲，27.9有多条横线；28秒变横幅人物和左下文字，28.1后恢复稳定。扭曲期间多个局部跃变不是多次换镜。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

先将画面预合成，按y坐标叠正弦/噪声x位移，幅度在转场短暂升高再归零；扫线独立遮罩，随后换布局。

直出判断：容易到中等，shader或逐条带位移都可导出

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

AI19 · 原作约168—231.8秒

分析单元 07 / 168—231.8秒

品牌卡复现／圆环标识群／结尾人物静帧

实际观察

168–208秒复用角色卡与标识环/双行，212–228秒人物大图不同裁切和表情静帧，前段黑白细线基调保持。仅概览不能断言全部表情连续变化。

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

卡片组件复用；环形标识用坐标函数旋转；结尾按裁切框和静帧切换，字幕逐段显示。

直出判断：已有图像时容易，人物表情素材需生成或绘制

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →色彩组织与选择保色 →
