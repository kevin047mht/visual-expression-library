H29 · 原作约1.2—3.2秒

分析单元 01 / 1.2—3.2秒

游戏人物近景／相机裁切推进

实际观察

游戏低机位切人物正面，随后相机向机器人靠近，主体逐渐出框。白条与113更像游戏界面/标签，未列为作者字效。

表达作用（教学解读）

用规则、选择与反馈组织关系，让抽象状态可被看见。

具体应用场景

人物关系、搜索、等待、推理、产品功能解释、系统压力；数值需要真实含义或明确虚构设定。

复现建议（非原作者工程还原）

已有片段裁切与缩放容易；游戏人物模型及动作需源素材。

直出判断：剪辑容易，不能仅靠滤镜生成游戏场景

常见误用：假数据制造伪解释；辅助文字太暗；每个窗口同时运动；手机界面只是装饰外壳。

H29 · 原作约8.933—9.533秒

分析单元 02 / 8.933—9.533秒

游戏到动画的动作匹配／红闪遮挡

实际观察

游戏人物动作后8.967秒为红色覆盖的动画人物，红色逐渐减弱；9.533秒切飞行动画。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

选择服装/动作相近素材，切点叠红色层后渐隐，必要时对齐人物位置。

直出判断：已有匹配素材后容易

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

H29 · 原作约9.3—11.3秒

分析单元 03 / 9.3—11.3秒

短镜头硬切／重复主题快切

实际观察

人物飞行、站立、抱持与脸部近景接连替换，画幅一致，转场依靠硬切。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

按时间轴裁切拼接；主体位置和色调尽量匹配。

直出判断：容易

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →语义选材与意象蒙太奇 →

H29 · 原作约19.5—21秒

分析单元 04 / 19.5—21秒

横向条带画中画

实际观察

飞行画面保留上下区，中间叠独立动画条带，内容连续替换。

表达作用（教学解读）

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

具体应用场景

记忆、对话、关系对照、主观视点、多人角色介绍、跨素材呼应。

复现建议（非原作者工程还原）

矩形裁切后覆盖中央，按片段切换。

直出判断：容易

常见误用：窗口太多无主次，眼位错位、边框挤脸，层的出现没有叙事理由。
