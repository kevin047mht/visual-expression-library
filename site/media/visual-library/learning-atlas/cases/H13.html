这一例先看什么

扫描线暗场、撕纸与石纹拼贴、留白飞散字形成多种段落；人物踩字面和递归框将文字纳入空间关系。

审美判断

大汉字、人物轮廓和前后景叠字有主次；暗色CRT段为压抑风格，浅色后段轮廓更清楚，小字幕在石纹/扫描线背景需注意对比。

迁移到自己的题材

漫画改编、人物回忆、纪念、故事提案、海报动态化、低动作但高情绪密度的段落。

教学提问：前景、中景、背景分别是什么？如果镜头移动，原图未画出的部分由谁补齐？

带画面的分析单元

图像标出取样时间，对应观察中的关键状态。单帧不能独立证明运动，连续性请结合摘录。表达作用与应用场景是教学解读，复现路线是建议，不是原作者工程还原。

H13 · 原作约16—32秒

分析单元 01 / 16—32秒

CRT扫描线／色散错位／汉字笔画残影

实际观察

人物和大号汉字带红绿蓝边，画面覆盖横扫描线，32秒字与人物被纵向条纹拉开。

表达作用（教学解读）

把短暂破坏作为失控、断裂、冲突或数字材质的提示。

具体应用场景

赛博题材、记忆中断、身份不稳、高潮强调；也可短时掩护连接。

复现建议（非原作者工程还原）

RGB通道偏移、扫描线透明纹理、噪声驱动切片位移。

直出判断：容易

常见误用：全程持续导致麻木；色散让脸和字长期看不清；把所有亮度变化算成切镜。

RGB错位、条带与故障 →文字排版与逐字动效 →

H13 · 原作约36—48秒

分析单元 02 / 36—48秒

文字包围人物／递归画框／撕纸边／小窗拼贴

实际观察

人物前后有大字与细线，40秒多个倾斜框套住中央人物，48秒粗糙纸边分割角色与字幕。

表达作用（教学解读）

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

具体应用场景

记忆、对话、关系对照、主观视点、多人角色介绍、跨素材呼应。

复现建议（非原作者工程还原）

透明人物图层配背景大字，矩形副本等比缩小旋转；纸纹遮罩和子画面。

直出判断：规则框与字效容易，人物遮罩和纸纹需素材

常见误用：窗口太多无主次，眼位错位、边框挤脸，层的出现没有叙事理由。

画中画、分屏与局部拼贴 →文字排版与逐字动效 →

H13 · 原作约52—80秒

分析单元 03 / 52—80秒

石纹开裂／几何分割／线框叠层／相机界面

实际观察

灰石纹被人物轮廓打断；60秒横竖矩形切片分割人物，68秒取景框围住角色。

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

纹理位移与遮罩、矩形切片、线框矢量和相机UI叠加。

直出判断：基础机制容易

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →几何、图表与程序空间 →

H13 · 原作约88—104秒

分析单元 04 / 88—104秒

手部线稿／粒子流／紫色高曝光／倾斜卡片

实际观察

黑底线描手前漂浮细小粒子；96秒手部转紫白高曝光，100秒人物卡片倾斜并被液体样边缘包围。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

描边或现成线稿、粒子、多段调色、透视卡片与噪声边缘。

直出判断：基本版容易，干净线稿与高级液体边缘需调整

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →

H13 · 原作约112—140秒

分析单元 05 / 112—140秒

墨滴遮挡／红色聚光／石刻字／人物踩字面

实际观察

黑色墨团遮挡人物，红色光照人物脸，石纸质大字和角色形成前后关系，脚部落在满字纹理上。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

噪声阈值蒙版、局部红光、石纸纹理与透视投影、人物分层。

直出判断：遮罩字效容易，空间配准和人物抠图需逐镜处理

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →纸张、照片与漫画分格 →

H13 · 原作约159.9—161.9秒

分析单元 06 / 159.9—161.9秒

同镜头闪色／素描化／英文拆字／描边实字叠排

实际观察

同一喊叫脸部在黄白、紫白、灰素描和原色之间转换；英文词拆散后聚合，实字与大号空心字叠在人物前。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

调色与曝光关键帧、边缘线稿滤镜、逐字位置缩放、描边文字和遮罩。

直出判断：基础机制容易；原动画表情变化不算后期生成

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →

H13 · 原作约166.8—168.8秒

分析单元 07 / 166.8—168.8秒

蓝白排字／横条擦除／放大字形／配色反转

实际观察

蓝白大字被重复成横排并由条块擦过；167.584秒进入另一大字版式，168.085秒变为倾斜字形构图，168.418秒转黑黄配色。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

文本与矩形遮罩分层，条块位移、字形缩放，调色或主题色关键帧。

直出判断：容易，属于程序排字和几何运动的适合项

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。
