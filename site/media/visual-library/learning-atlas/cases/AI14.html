AI14 · 原作约12—20秒

分析单元 01 / 12—20秒

道具发光／腰带能量核心／局部火花

实际观察

12秒概览角色手持圆形道具，16秒道具中心黄光，20秒腰带接触部位蓝光并有黄白火花；底部白字黑边台词。仅概览，不能确认道具变形/插入操作每一帧的完整性。

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

对现成画面中道具位置做跟踪，叠加发光圆、透镜耀斑和放射短线，按接触时刻给alpha/亮度脉冲。没有证据这些层在本片由后期单独叠加，也可能在AI片段中已生成。

直出判断：简单发光和火花容易；道具三维形变、手部交互和精确遮挡需素材/跟踪

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

发光字、光迹与轮廓光 →复杂动作与镜头素材 →

AI14 · 原作约62—65.933秒

分析单元 02 / 62—65.933秒

球形电场／分叉闪电／环绕能量带

实际观察

62.000–62.400秒狗脸近景后，62.467秒变成悬浮全身狗与透明粉色球壳；分叉电弧持续变化。64秒后金橙色环形能量带绕身体旋转，视角和背景逐步改变。闪电分支亮灭和旋转带位置变化不计切镜。

表达作用（教学解读）

以观看距离和运动方向改变心理距离，让观众发现、逼近、远离或重新理解对象。

具体应用场景

环境揭示、人物情绪、冲刺、回忆、同一张图中的细节发现。

复现建议（非原作者工程还原）

基础版可用球面/圆轮廓噪声shader、分段递归折线闪电、多层Glow、环形带粒子；前后环带分层并用主体蒙版遮挡。真实毛发遮挡、球面视差和一致环绕需跟踪/3D素材。

直出判断：简化电场容易，逼真的角色环绕和体积光中等到难

常见误用：每镜都推近；速度变化没有事件依据；把同镜转动误算为剪辑；光流扭曲当成流畅。

镜头推拉、跟随与变速 →密度、停留与段落节奏 →

AI14 · 原作约72—88秒

分析单元 03 / 72—88秒

场景置换／金色变身轮廓／装甲显现

实际观察

72秒概览从灰色屋顶转到熔岩暗场中的狗，76秒出现强金光的拟人轮廓，80–88秒转成兽形/装甲角色。稀疏概览只能证明这些状态出现，不能证明完整无缝变身或是单段生成。

表达作用（教学解读）

复杂表演与形体变化通常来自镜头素材本身。先明确事件与连续性要求，再选择拍摄、原动画、生成或三维等获取路线。

具体应用场景

近身动作、幻想形变、角色交互、复杂环境事件。已有源片时先辨认并保留动作因果，不把全部动作记作后期增量。

复现建议（非原作者工程还原）

可在已有起止造型之间用强光、烟雾、阈值蒙版遮挡换形；精确骨骼变形、装甲组装需建模/绑定或挑选生成片段，并以连续画面检查。

直出判断：遮光换形的基础合成可做，连贯复杂变身不能轻松一次代码直出

常见误用：连续性靠闪光掩盖；人手/道具无因果变化；把模型内部运镜当全部剪辑能力；承诺单次稳定长表演。

复杂动作与镜头素材 →

AI14 · 原作约111.1—113.033秒

分析单元 04 / 111.1—113.033秒

拳击接触火花／碰撞亮闪／近景运动模糊

实际观察

111.100秒双人远景，111.167秒重置为金色装甲脸部近景；之后双方互击、手臂从镜头前掠过，111.500、111.700、111.833、112.967秒附近有黄白碰撞亮点与短线火花。亮点频次远高于确认的构图重置次数。

表达作用（教学解读）

用熟悉尺寸与层次，让宏大空间被感知；留停帮助观众建立尺度。

具体应用场景

世界观、建筑概念、场景设定、神圣、敬畏、孤独和压迫。

复现建议（非原作者工程还原）

在打击接触点发射短寿命放射线粒子并加Bloom，亮闪限定少数帧；运动模糊由已有动作素材或运动矢量处理。准确拳脚接触、装甲遮挡、力学反应需逐镜处理。

直出判断：叠火花容易，可信打斗动作与遮挡不属于简单直出

常见误用：没有比例参照；每镜同一宏大构图；雾遮住所有结构；反射与相机运动不一致。

巨构、雾层与尺度参照 →

AI14 · 原作约118.5—122.433秒

分析单元 05 / 118.5—122.433秒

飞行尾焰／紫色能量弹／青色符文盾／爆裂冲击

实际观察

118.5秒两角色在阴云中飞行，一方带橙色尾焰；紫色发光球向前景快速放大，119.567秒前后青色圆形盾显现，约120.300秒盾处出现亮冲击，121.300秒盾区蓝光爆开并有火花。粒子和前景能量球的遮挡不另计切镜。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

用噪声圆形sprite/shader做能量球、拖尾粒子做尾焰，圆环/径向刻线贴图做符文盾并按视角投影；冲击用扩张圆环、亮闪、短线粒子。贴合角色手掌、透视、遮挡与环境反光需跟踪和调试。

直出判断：孤立能量球/符文盾/尾焰基础版容易，准确合入复杂飞行打斗中等到难

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →粒子、花瓣、雪与碎片 →

AI14 · 原作约123.2—125.133秒

分析单元 06 / 123.2—125.133秒

环绕跟拍外观／角色前景遮挡／快速换位

实际观察

同一组金黑与白黑装甲角色持续交手，镜头相对方位快速变动：白色角色从右侧掠过中间到左侧，再挡住前景，背景云层也改变。大面积像素差来自运动、近景遮挡和火花，不足以证明同等数量的剪点。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

类似观感需安排相机绕角色的轨迹并保持动作连续；已有透明分层可做有限2.5D模拟，完整角色多视角、互遮挡与动作对应需要3D角色或质量可控的生成镜头。

直出判断：仅裁切/抖动/缩放容易，完整环绕打斗不能用单张图简单直出

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →漫画分层与2.5D视差 →

AI14 · 原作约16—96秒

分析单元 07 / 16—96秒

白字黑边对白字幕／镜头段落硬切

实际观察

多个概览出现底部单行中文台词，角色/狗/装甲之间按叙事段落转换；62.400→62.467秒专项确认从正脸近景换到侧身全景。所查画面未见复杂动态标题字效。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

字幕按起止时间绘制描边白字，镜头按素材入出点直接拼接；需要校对文本与画面，不把画内发光或AI内容变化自动当剪接操作。

直出判断：容易，字幕和素材拼接可直接代码导出

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

动作、视线与形状匹配 →文字排版与逐字动效 →
