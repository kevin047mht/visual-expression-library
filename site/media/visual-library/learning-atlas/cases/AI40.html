AI40 · 原作约0—30秒

分析单元 01 / 0—30秒

潮湿未来城市／景深／冷暖色

实际观察

工作台小生物、街道人物、湿地反射、远近城市建筑形成空间层次。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

先有场景/人物视频，统一冷灰城市与局部暖光；景深遮罩和调色可叠加。

直出判断：调色/浅景深简单；一致城市、人物和反射需要源素材或生成

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →景深、柔焦与负空间 →

AI40 · 原作约34—54秒

分析单元 02 / 34—54秒

悬浮小生物／镜面／纸张飞行

实际观察

床边小生物悬浮，随后洗脸人物与反射、楼间跳跃和黄色纸张。

表达作用（教学解读）

把画面变成可触摸的记忆或记录；纸边、阴影与展示顺序可以表现珍惜、拼凑或碎裂。

具体应用场景

回忆、青春、艺术创作、旅行手记、人物档案、纪念短片。

复现建议（非原作者工程还原）

分层生物加轨迹与投影，纸张可粒子或3D薄片；人物反射需匹配视角。

直出判断：简化悬浮/纸片中等，角色接触与正确反射较难

常见误用：所有纸张纹理一样重；阴影方向不一致；折页遮挡错误；照片墙只有数量而没有观看顺序。

AI40 · 原作约102—120秒

分析单元 03 / 102—120秒

白色笔刷标题／斜向构图

实际观察

巷道背景叠有异人第二集白色笔刷题字，字幕为独立下方小字。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

使用授权毛笔字体与透明遮罩揭示，背景旋转裁切和字层分别控制。

直出判断：标题、字幕和斜构图容易直出

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

纸马／游戏屏幕／KO字卡

实际观察

人物骑纸马；异形所在室内有游戏显示和手柄特写，屏幕战斗与KO字。

表达作用（教学解读）

AI40 · 原作约186—218秒

分析单元 05 / 186—218秒

碎片／摩托细节链／动作反应

实际观察

碎片散开，控制室和广场对照，摩托车前后轮、腿部配件、手套握把依次出现。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

碎片用粒子、景深与运动模糊，剪辑按细节到人物组织；摩托几何和人体依赖源画面。

直出判断：粒子和切镜容易；可信车辆运动/人物接触较难

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →

AI40 · 原作约221—225秒

分析单元 06 / 221—225秒

燃烧符纸／烟雾遮挡／悬石成墙

实际观察

黄色符纸燃烧、烟遮纸，221.8低位悬石，222.2高位广场石墙升起，223.9转墙后两人。

表达作用（教学解读）

把画面变成可触摸的记忆或记录；纸边、阴影与展示顺序可以表现珍惜、拼凑或碎裂。

具体应用场景

回忆、青春、艺术创作、旅行手记、人物档案、纪念短片。

复现建议（非原作者工程还原）

火焰/烟粒子叠层，石块分层带阴影与透视运动；可信成墙需3D/生成视频与遮挡处理。

直出判断：简化烟火容易，完整悬石成墙和人物遮挡需要调试

常见误用：所有纸张纹理一样重；阴影方向不一致；折页遮挡错误；照片墙只有数量而没有观看顺序。

AI40 · 原作约258—318秒

分析单元 07 / 258—318秒

港口建立镜头／对话反打／HUD

实际观察

港口远景接父子与人物反应，楼梯告示；后部摩托叠蓝色HUD。

表达作用（教学解读）

用规则、选择与反馈组织关系，让抽象状态可被看见。

具体应用场景

人物关系、搜索、等待、推理、产品功能解释、系统压力；数值需要真实含义或明确虚构设定。

复现建议（非原作者工程还原）

环境建立镜头后用景别/视线组织对话，HUD线框与透明面板叠加。

直出判断：反打剪辑和简化HUD容易；人物表情连续性依赖素材

常见误用：假数据制造伪解释；辅助文字太暗；每个窗口同时运动；手机界面只是装饰外壳。

界面、菜单与信息面板 →动作、视线与形状匹配 →

AI40 · 原作约324—346.24秒

分析单元 08 / 324—346.24秒

像素风片尾／滚动名单

实际观察

像素飞船、港口与字幕名单，尾段未完待续。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

原创像素图层加平移/淡入与名单滚动；避免照搬原标志与美术。

直出判断：有原创图层后片尾容易直出

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →
