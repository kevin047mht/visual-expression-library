H31 · 原作约4—20秒

分析单元 01 / 4—20秒

圆形信息线框／多边形破碎／伪色热成像／半色调拼贴

实际观察

纸片旁有轨道线；人物被彩色三角碎面覆盖；贝壳和人物场景呈粉青伪色，并有点阵小窗。

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

矢量圆轨道、三角网格分片、颜色查找表与网点滤镜、多层小窗。

直出判断：基础滤镜和几何容易；素材分解与统一风格需制作

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →画中画、分屏与局部拼贴 →

H31 · 原作约24—52秒

分析单元 02 / 24—52秒

漂浮卡片／地球光晕／树形能量／空间线框

实际观察

风景上有倾斜小窗，发光地球置于网格空间，巨树和人物被透明竖条切片，人物置于带坐标线的彩色能量空间。

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

图像贴片、球体贴图和发光、竖向遮罩与粒子；空间可用透视图层或3D相机。

直出判断：基础机制可做；复杂美术和多层空间有较大制作量

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →几何、图表与程序空间 →

H31 · 原作约56—76秒

分析单元 03 / 56—76秒

眼睛与花卉拼贴／散景光斑／线描飞鸟

实际观察

多个眼部切片与花枝交叠，近景散景光斑覆盖小窗，白色鸟形线稿漂浮前景。

表达作用（教学解读）

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

具体应用场景

记忆、对话、关系对照、主观视点、多人角色介绍、跨素材呼应。

复现建议（非原作者工程还原）

局部遮罩、人像与花枝拆层，模糊光点分层，鸟形路径描边动画。

直出判断：规则光斑和线稿容易；精致素材处理需人工

常见误用：窗口太多无主次，眼位错位、边框挤脸，层的出现没有叙事理由。

画中画、分屏与局部拼贴 →景深、柔焦与负空间 →

H31 · 原作约80—104秒

分析单元 04 / 80—104秒

轮廓能量／空间环轨／全景色相反转／粒子立方体

实际观察

人物和鲸形轮廓转成黄青发光线，多层环形空间包围人物；104秒人物站在金色粒子立方体前。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

边缘检测加辉光、曲线轨道与相机、调色映射、点云或粒子立方体。

直出判断：简单环轨与粒子可程序输出；完整密度与美术需要调试

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →发光字、光迹与轮廓光 →

H31 · 原作约104.3—106.3秒

分析单元 05 / 104.3—106.3秒

冲击推近／白闪／方向拖影转场

实际观察

104.6秒起推近并径向模糊，104.733秒变纵向拖影，104.8秒近白，105秒进入餐桌人物；106.133秒再换暖黄场景。

表达作用（教学解读）

短暂中断视觉连续性，强调接触、转折或心理断裂；其价值来自前后的对比。

具体应用场景

打击点、快速连接、记忆跳跃、段落转折；需要根据内容选择强度。

复现建议（非原作者工程还原）

缩放和径向模糊联动，白闪遮住素材替换，再缓出到新构图。

直出判断：容易，需根据音乐和情绪调节持续时间

常见误用：把闪烁当节奏本身；没有稳定画面作参照；为掩盖动作不清持续加闪。

闪白、黑帧与冲击帧 →镜头推拉、跟随与变速 →

H31 · 原作约128—148.5秒

分析单元 06 / 128—148.5秒

反色噪点／建筑线框／曲线示意／横向雪花干扰

实际观察

画面在彩色辉光、黑白线稿与噪点中变化；146.867秒出现曲线坐标小图，随后进入紫色纸面与鸟，147.733秒横纹干扰后转漫画人物，148.333秒转黑底建筑线稿。

表达作用（教学解读）

把可控规则变成可见变化；通过不变量、比例和相位建立秩序或空间。

具体应用场景

概念解释、音乐可视化、抽象世界、图表、程序艺术。

复现建议（非原作者工程还原）

调色、网点、边缘描线、曲线绘制、条纹位移，按镜头表组合；公式语义须另核验。

直出判断：单个机制容易，连续多层合成与叙事安排需制作

常见误用：符号无含义；空间复杂度替代概念清晰；将程序生成误等同于文生视频生成。

几何、图表与程序空间 →巨构、雾层与尺度参照 →

H31 · 原作约160—188秒

分析单元 07 / 160—188秒

画面缩为方形／极简双语字卡／文献式片尾

实际观察

彩色画面缩成黑底小方形，之后转白纸小字与签名，末尾黑底密集引用和致谢栏。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

裁切与缩放、留白排版、文字网格；自造语言需用户提供字形与编码。

直出判断：排版容易；自造文字和引用内容不应凭空生成

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →密度、停留与段落节奏 →
