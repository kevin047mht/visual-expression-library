AI41 · 原作约0—30秒

分析单元 01 / 0—30秒

漂浮碎石／紫色光球／城市爆炸／漫画拟声字

实际观察

白发人物悬于霓虹城市，碎石浮动，指端紫光球引发远景爆炸，黑色拟声大字覆盖烟团。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

生成城市和人物运动，粒子碎石/发光球/烟雾合成，拟声字独立变换。

直出判断：简化光球/碎石/拟声字容易；完整破坏场景难

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →巨构、雾层与尺度参照 →

AI41 · 原作约30—72秒

分析单元 02 / 30—72秒

极近景对话／手势插镜／蓝色边光

实际观察

嘴部、侧脸、手势和衣服局部轮换，再接蓝边光人物特写。字幕位于黑边内。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

多景别语义剪接、统一字幕安全区和色彩；面部/手部动作需源镜头。

直出判断：字幕/剪接/边光近似容易；一致角色表演需素材

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

动作、视线与形状匹配 →语义选材与意象蒙太奇 →

AI41 · 原作约72—108秒

分析单元 03 / 72—108秒

紫色贯穿光束／高速拳脚／橙色撞击火星

实际观察

光束穿楼，人物近身格斗，橙色火花与蓝白光束随碰撞迸发，随后楼内穿行。

表达作用（教学解读）

以短寿命粒子强调接触、爆发与运动方向，帮助观众辨认材质和事件时点。

具体应用场景

兵器或器械碰撞、机械摩擦、能量爆发、运动接触。先确定接触点、方向、遮挡和寿命；纪实火花应保留摄影来源。

复现建议（非原作者工程还原）

生成或动画格斗和空间镜头，轨迹光条、加色粒子、径向模糊作强化。

直出判断：简化火星/光束/冲击模糊容易；接触动作及大空间连续性难

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →发光字、光迹与轮廓光 →

AI41 · 原作约108—210秒

分析单元 04 / 108—210秒

短黑场／监看室群像／长对话近景

实际观察

108附近黑场后，人物环绕巨型多屏装置，主要以群像和人物近景轮替，背景多为稳定构图。

表达作用（教学解读）

以观看距离和运动方向改变心理距离，让观众发现、逼近、远离或重新理解对象。

具体应用场景

环境揭示、人物情绪、冲刺、回忆、同一张图中的细节发现。

复现建议（非原作者工程还原）

镜头选择和黑场分节，生成背景与人物表演，底部统一字幕。

直出判断：基本剪接/黑场/字幕容易；一致多人空间需素材

常见误用：每镜都推近；速度变化没有事件依据；把同镜转动误算为剪辑；光流扭曲当成流畅。

AI41 · 原作约210—246秒

分析单元 05 / 210—246秒

喷水动作／橙绿纯色比喻插镜

实际观察

人物饮料喷出，随后橙底站立拿瓶、绿底坐椅拿画笔的极简示意画面，再回对话室。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

角色与纯色背景独立构图，液体可素材或模拟；用对比插镜辅助解释。

直出判断：纯色示意/切换容易；液体与表演需素材

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →

AI41 · 原作约246—356秒

分析单元 06 / 246—356秒

人物轮换／红蓝分区／烟气／闪电边缘

实际观察

多角色对话和室内外插镜，后两人物分别在红蓝发光屏旁，边缘有电状线条。

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

统一人物近景、红蓝灯光分区和屏幕发光，烟雾及折线加色叠层。

直出判断：简化红蓝光/电线/烟容易；人物互动需源片

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

AI41 · 原作约356—377.719秒

分析单元 07 / 356—377.719秒

漫画拟声／黑白方框隧道／推近／黑球光爆

实际观察

格斗上叠漫画字，短黑场后白色粗糙方框层层旋转推进，回人物手势，再出现城市黑球白色放射爆光。

表达作用（教学解读）

建立段落、材质和情绪的一致性；颜色变化可以承担信息，而不只是美化。

具体应用场景

多片源混剪、人物立场、回忆/现实区分、冷暖转折、品牌统一。

复现建议（非原作者工程还原）

噪声描边矩形递归缩放旋转、相机推近、径向线与圆形遮罩辉光；城市主体需生成。

直出判断：方框隧道/径向线/球形光爆简版容易；完整城市毁坏难

常见误用：所有镜头同一滤镜；肤色被破坏；饱和度代替焦点；色彩含义前后矛盾。

色彩组织与选择保色 →镜头推拉、跟随与变速 →
