这一例先看什么

立绘放入透视棋盘与建筑剪影，前景锁链/碎片制造遮挡深度；暖光与灰白空间的组合统一。

审美判断

灰阶人物与局部红/粉/黄眼区分，黑底叙事小字留足空白；强黄白亮闪是短暂动作强调，不凭一个闪帧判曝光失控。

迁移到自己的题材

漫画改编、人物回忆、纪念、故事提案、海报动态化、低动作但高情绪密度的段落。

教学提问：前景、中景、背景分别是什么？如果镜头移动，原图未画出的部分由谁补齐？

带画面的分析单元

图像标出取样时间，对应观察中的关键状态。单帧不能独立证明运动，连续性请结合摘录。表达作用与应用场景是教学解读，复现路线是建议，不是原作者工程还原。

H06 · 原作约12—28秒

分析单元 01 / 12—28秒

漫画抠图拼贴／局部着色

实际观察

漫画人物抠像置于粉、红、白色块；链条前景、棋盘地面、黄眼和暗部轮廓

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

“漫画抠图拼贴／局部着色／前后景遮挡”。已有图层后基础合成容易；人物拆分、补画和统一光影需准备。

直出判断：已有图层后容易；抠图补画需准备

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →画中画、分屏与局部拼贴 →

分析单元 02 / 80—84秒

漫画立绘空间化／透视地板

实际观察

人物分立在透视棋盘地面前后，相互遮挡，布局有深度

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

直出判断：中等至较难，需深度排序与相机调试

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

H06 · 原作约85—87秒

分析单元 03 / 85—87秒

能量折线／菱形阵列／加法辉光

实际观察

橙白发光折线、光球、重复菱形列阵在棋盘空间中变化，末尾人物大形状进入

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

“能量轨迹／重复几何阵列／加法辉光／遮挡转场”。基础折线和阵列容易，复杂空间镜头与人物遮挡中等至较难。每束光的闪动不算换镜。

直出判断：基础机制容易，空间合成需调试

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

发光字、光迹与轮廓光 →几何拼贴与形状语言 →

H06 · 原作约91—93秒

分析单元 04 / 91—93秒

甩镜模糊／粒子消散／反打

实际观察

强方向模糊与亮闪后，由远近双人构图到脚部近景、人物消散碎点，再出现俯冲人物反打

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

“甩镜模糊／白闪／粒子消散／动作反打”。已有图层可做相机和遮罩；肢体动画、人物图层连接和动态修形需逐镜处理。

直出判断：基础滤镜容易；人物动作和图层连接需逐镜处理

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →动作、视线与形状匹配 →
