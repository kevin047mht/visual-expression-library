亮黄底黑色巨字和人物轮廓对比强，暗段用手电锥形光保持局部焦点；上下多语字幕同时存在，有信息负担，不能只看大字便认为全部字幕轻松可读。

AI09 · 原作约4—12秒

分析单元 01 / 4—12秒

巨型英文重复字／手电锥形遮罩／人物亮暗切换

实际观察

暗底人物前后是大号浅字；手电对应黄色三角光区，人物脸与身体受遮罩局部照亮。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

人物暗版与亮版叠层，以手电发出的三角形遮罩揭示亮版；大字作背景层。

直出判断：基础版容易，手电与人物位置需配准

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →形状遮挡、擦除与揭示 →

AI09 · 原作约43.6—45.6秒

分析单元 03 / 43.6—45.6秒

大字冲屏／拳头前景／白色放射形转场

实际观察

44.125秒左右大黑字进入人物前景，44.292秒换亮黄背景并由拳头和白色放射形占画面，44.625秒转黄底人物与背景大字。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

文字平移缩放、拳头PNG前景、白色爆炸形状遮罩，遮满时替换画面。

直出判断：基础机制容易；拳头和人物原画需素材

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →漫画分层与2.5D视差 →

实际观察

人物在前景做不同表情，52.333秒缩小后大字与浅色圆形区域展开，52.583秒换人物动作，53.833秒新一组文字占背景。

表达作用（教学解读）

直出判断：基本合成容易；逐句排字与差分需要编排

AI09 · 原作约120—136秒

分析单元 05 / 120—136秒

暗场人物／局部圆形亮区／横躺画面裁切

实际观察

躺姿人物处于暗底，脸被圆形亮区照出，128秒附近推近脸，136秒突然进入亮黄底。

表达作用（教学解读）

以观看距离和运动方向改变心理距离，让观众发现、逼近、远离或重新理解对象。

具体应用场景

环境揭示、人物情绪、冲刺、回忆、同一张图中的细节发现。

复现建议（非原作者工程还原）

暗版人物叠亮版圆蒙版，位置缩放和背景主题色切换。

直出判断：容易，人物差分需素材

常见误用：每镜都推近；速度变化没有事件依据；把同镜转动误算为剪辑；光流扭曲当成流畅。
