AI29 · 原作约0—48秒

分析单元 01 / 0—48秒

景别交替／门框前景遮挡／底部对白字

实际观察

早餐近景到室内全景再到楼道两人；24秒拳套插入，30秒人物前景模糊。文字白色有暗边并较宽字距。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

按剧情剪镜头；前景虚化优先在源图/视频生成或拍摄中得到，已有景深可保留；字体描边及位置定时。

直出判断：剪接字幕容易；保持人物、场景一致性的生成需专门素材

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →动作、视线与形状匹配 →

AI29 · 原作约48—60秒

分析单元 02 / 48—60秒

黑白回忆插入／彩色恢复

实际观察

48秒楼道人物，54秒黑白人物与建筑，60秒转学校彩色画面。概览只证实状态，不确定所有入出转场。

表达作用（教学解读）

利用相邻镜头改变理解，使原来无关的画面形成主题、对比或关系。

具体应用场景

纪念、广告、人物关系重组、旅行随笔、社会观点、品牌回顾。

复现建议（非原作者工程还原）

选回忆片段灰度/降饱和，连接当前叙事；如需柔和连接可做短叠化，但不是已证实作者参数。

直出判断：已有素材时容易

常见误用：素材只因好看而排列；上下文失真；借剪接制造未经支持的事实判断。

语义选材与意象蒙太奇 →色彩组织与选择保色 →

AI29 · 原作约90—130.3秒

分析单元 03 / 90—130.3秒

车内正反打／反应特写／车灯增亮与碰撞连接

实际观察

96秒车内正面全景、102秒后排近景、108秒司机背后、114秒另车人物；128.667转惊恐面部后逐渐逼近变亮，129.833转侧窗来车，130.167起碰撞晃动。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

先分镜生成/选取各机位，时间线上硬切；曝光曲线、局部光晕、短抖动可后加，碰撞动作和玻璃火花须素材。

直出判断：剪法、曝光/抖动容易；真实车祸运动不能纯滤镜直出

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

AI29 · 原作约130—138秒

分析单元 04 / 130—138秒

黑场作段落分隔

实际观察

132秒概览为黑场，138秒回到暖色楼道。仅从概览不推断精确黑场持续时间。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

插入黑色视频或透明度淡出/入；按叙事设置停顿。

直出判断：容易，需进一步定位精确入出点

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →

AI29 · 原作约148—158秒

分析单元 05 / 148—158秒

物件插入／门缝局部构图／电光高亮

实际观察

150秒拳套，152.292–153.958门缝只见脚，154.042转热水器仰视，154.125高亮电弧；156秒低机位人物。

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

细节插入交代因果；电弧用曲线抖动+辉光+短曝光闪烁，按遮挡关系合成。

直出判断：简化电弧与插镜容易，物体受光和人物动作需素材

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

发光字、光迹与轮廓光 →

AI29 · 原作约162—174秒

分析单元 06 / 162—174秒

建立镜头→事故全景→手机细节的因果蒙太奇

实际观察

164秒无人机，164.083转路口翻车全景，166.417转地上红光手机，随后上方物体进入。手机大色块可见，不能据此读完整界面。

表达作用（教学解读）

用规则、选择与反馈组织关系，让抽象状态可被看见。

具体应用场景

人物关系、搜索、等待、推理、产品功能解释、系统压力；数值需要真实含义或明确虚构设定。

复现建议（非原作者工程还原）

按空间/因果安排三镜；手机屏幕可四角跟踪贴片，加红色发光外溢。

直出判断：有素材时容易；灾难场景和无人机运动需素材或生成

常见误用：假数据制造伪解释；辅助文字太暗；每个窗口同时运动；手机界面只是装饰外壳。

界面、菜单与信息面板 →几何拼贴与形状语言 →

具体应用场景
