从画面里找依据

这一例先看什么

蓝色天空/人物、黄色和粉色几何点缀形成统一清爽画面；原动画对话段与插入包装区分，末段回蓝天人物。

审美判断

角色面部与色块保持清楚分区，几何转场让主角落在统一视觉中心；短片字效较少，不能因为没有大量字幕而扣分。

迁移到自己的题材

角色介绍、青春与活力、音乐视觉、活动包装、虚实人物合成、鲜明的个人品牌。

教学提问：去掉人物后，几何元素还剩什么功能？加回人物后，哪一层负责引导视线？

带画面的分析单元

图像标出取样时间，对应观察中的关键状态。单帧不能独立证明运动，连续性请结合摘录。表达作用与应用场景是教学解读，复现路线是建议，不是原作者工程还原。

H02 · 原作约2.5—2.77秒

分析单元 01 / 2.5—2.77秒

孟菲斯几何拼贴／人物遮罩／弧形框

实际观察

用户参考图匹配：蓝色人物半身、蓝黄粉孟菲斯几何拼贴；圆环、斜线三角、细线和弧形外轮廓

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

Canvas/矢量图层做图形、遮罩和旋转缩放容易。角色抠像与轮廓检查需要素材准备；不承诺任意动画自动无瑕抠像。

直出判断：图形容易；人物需干净图层

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →几何、图表与程序空间 →

H02 · 原作约3.2—3.6秒

分析单元 02 / 3.2—3.6秒

几何遮挡揭示转场

实际观察

高密度三角、条纹、圆点铺满屏幕，再逐渐让出人物；可称“几何图形遮挡转场／拼贴揭示”

表达作用（教学解读）

把注意力从旧信息带往新信息；遮满时换底图，保持方向或形状上的联系。

具体应用场景

章节转换、空间跨越、角色亮相、画内物体自然遮挡后的换景。

复现建议（非原作者工程还原）

用带独立位移旋转的几何图层覆盖切点，然后退出；机制容易，元素密度、色彩、人物前后遮挡需要设计。

直出判断：机制容易，美术需设计

常见误用：每镜不同花哨转场；遮罩与运动方向相反；过渡比内容本身更长；遮挡未满就穿帮。

形状遮挡、擦除与揭示 →几何拼贴与形状语言 →

H02 · 原作约4.4—5.4秒

分析单元 03 / 4.4—5.4秒

双色描边标题／手写名与涂鸦

实际观察

大号蓝白、粉白日文标题；手写风人物名、白线涂鸦环绕人物。连续更换背景构图

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

字体描边、双色填充、文字和涂鸦分层可以直出。标题看起来属于所用片头设计，不能断言UP自行制作；不能把字体样式等同于已核验逐字动画。

直出判断：容易；所用片头素材归属未核

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →几何拼贴与形状语言 →

H02 · 原作约14—14.7秒

分析单元 04 / 14—14.7秒

竖条遮罩揭示

实际观察

14秒附近黄白竖条遮罩揭开人物，14.7秒附近接回举物人物；这是遮罩揭示与后继画面的连接，遮罩逐步移动不各算一次新镜。

表达作用（教学解读）

把注意力从旧信息带往新信息；遮满时换底图，保持方向或形状上的联系。

具体应用场景

章节转换、空间跨越、角色亮相、画内物体自然遮挡后的换景。

复现建议（非原作者工程还原）

硬切、裁切推进、竖条遮罩可直出。人物扑向镜头的连续动作属于动画素材内容，不能当成代码转场自动生成能力。

直出判断：容易

常见误用：每镜不同花哨转场；遮罩与运动方向相反；过渡比内容本身更长；遮挡未满就穿帮。

形状遮挡、擦除与揭示 →几何拼贴与形状语言 →

H02 · 原作约18—18秒

分析单元 05 / 18—18秒

中央画中画

实际观察

中央叠加紫色矩形小画面，背景仍保留蓝发人物

表达作用（教学解读）

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

具体应用场景

记忆、对话、关系对照、主观视点、多人角色介绍、跨素材呼应。

复现建议（非原作者工程还原）

原始媒体中也有此画中画，证实不是网页播放器悬浮层。位置、缩放、透明度和蒙版可直接导出；只看概览未确认它的完整出现过程。

直出判断：容易；仅概览时间点

常见误用：窗口太多无主次，眼位错位、边框挤脸，层的出现没有叙事理由。

短时变化怎样理解

既有2–4秒30fps与13.3–14.05秒60fps专项可核几何遮挡/人物揭示；18秒中央紫色画中画遮住部分脸，是刻意的插入模块，可研究但非清晰展示主体的通用做法。

把镜头连接、版式更新、局部图层变化和镜内运动分开记录。所查窗口是下限，不是全片平均或AI／人工排名。

这次练习的约束

同一人物只配两种主色、三种形状做三张版式。分别让形状承担“包围、引导、遮挡”一种功能。
