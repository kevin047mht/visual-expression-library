H44 · 原作约0—21.9秒

分析单元 01 / 0—21.9秒

暗底CRT／RGB错位／扫描线／故障片名

实际观察

黑底噪点与人物，红色花朵/字形，横向错位条，20秒素材名大字；整段有暗角/扫描线。

表达作用（教学解读）

把短暂破坏作为失控、断裂、冲突或数字材质的提示。

具体应用场景

赛博题材、记忆中断、身份不稳、高潮强调；也可短时掩护连接。

复现建议（非原作者工程还原）

隔行暗线、噪声、RGB通道平移和随机条带位移，文字独立叠层；人物源片保留。

直出判断：容易，控制可读性和持续时间需要调试

常见误用：全程持续导致麻木；色散让脸和字长期看不清；把所有亮度变化算成切镜。

RGB错位、条带与故障 →文字排版与逐字动效 →

H44 · 原作约22—26秒

分析单元 02 / 22—26秒

人物特写与大字／方块／描边重复图／拉远

实际观察

22.36近脸淡入，头部文字和小方块漂动，24.04白化模糊转坐姿人物，24.28后大字/描边身体/矩形随相机拉远。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

透明人物/源片、文字与方块分层，线稿用边缘提取或描边；白闪/模糊遮连接，整体缩放和各层视差。

直出判断：方块/字效/缩放容易；干净人物抠图和轮廓处理需素材整理

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →密度、停留与段落节奏 →

H44 · 原作约28—52秒

分析单元 03 / 28—52秒

故障缩窗／几何拼贴／撕纸边／墨烟／线框

实际观察

28秒蓝色窄窗故障，32秒人物横卡+十字，36秒不规则撕边，40秒人物配灰色墨烟，44秒字形环绕，52秒线框矩形。

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

遮罩限定画面、噪声位移撕边、透明烟素材或噪声遮罩、环形排字与矩形路径。

直出判断：图形/字环容易；复杂墨烟和细边遮罩中等，人物美术为原动画

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →纸张、照片与漫画分格 →

H44 · 原作约104—144秒

分析单元 06 / 104—144秒

红黑剪影／放射模糊／波形遮罩／横条位移

实际观察

104红黑人物与字，108放射模糊，112红色起伏遮罩，116细竖线，120白色波面，124–132人物与波纹/条带，144黄十字与橙线。

表达作用（教学解读）

把注意力从旧信息带往新信息；遮满时换底图，保持方向或形状上的联系。

具体应用场景

章节转换、空间跨越、角色亮相、画内物体自然遮挡后的换景。

复现建议（非原作者工程还原）

剪影阈值/双色映射、径向采样模糊、正弦/噪声边界遮罩、横条坐标位移，前景几何线条。

直出判断：这些简化机制容易，原美术与细粒度参数需匹配

常见误用：每镜不同花哨转场；遮罩与运动方向相反；过渡比内容本身更长；遮挡未满就穿帮。

形状遮挡、擦除与揭示 →RGB错位、条带与故障 →

H44 · 原作约149—151秒

分析单元 07 / 149—151秒

同一脸部持续／轮廓化／反色／色阶／散字

实际观察

人物近脸闭眼张口动作持续，轮廓线、紫白双色、灰阶和高亮状态交替；NIGHT转DIVER、实心/描边/散字来回更新。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

复用同一源片做边缘提取/灰阶/双色和曝光切换；字母位置、缩放、填充/描边按状态表控制。

直出判断：容易复现简化滤镜/字效；不把每次滤镜变化当新角色镜头

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →闪白、黑帧与冲击帧 →
