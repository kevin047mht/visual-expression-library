【静止系MAD】从今往后无人再说芦毛跑不快！「小栗帽/赛马娘」

让静止画产生空间动作与冲突的组织运动／竞技

漫画格、窗格阴影、锁链和粒子空间连接赛场人物，静止画层次与运动方向互相呼应。

从画面里找依据

这一例先看什么

漫画格、窗格阴影、锁链和粒子空间连接赛场人物，静止画层次与运动方向互相呼应。

审美判断

双色墨流中的中心字与锁链前景竖字有明确层级，跑步段以人物轮廓作焦点；亮闪帧不保证每帧字幕可读。

迁移到自己的题材

漫画改编、人物回忆、纪念、故事提案、海报动态化、低动作但高情绪密度的段落。

教学提问：前景、中景、背景分别是什么？如果镜头移动，原图未画出的部分由谁补齐？

带画面的分析单元

图像标出取样时间，对应观察中的关键状态。单帧不能独立证明运动，连续性请结合摘录。表达作用与应用场景是教学解读，复现路线是建议，不是原作者工程还原。

H14 · 原作约28—32秒

分析单元 01 / 28—32秒

双色墨流字幕卡

实际观察

蓝、红纯色底上有黑色墨流／烟流，中心小白字

表达作用（教学解读）

建立段落、材质和情绪的一致性；颜色变化可以承担信息，而不只是美化。

具体应用场景

多片源混剪、人物立场、回忆/现实区分、冷暖转折、品牌统一。

复现建议（非原作者工程还原）

“双色墨流字幕卡”。有烟墨素材可调色合成；程序流体可做近似，不能保证即刻生成同等细节。

直出判断：有素材后容易；程序烟墨近似需调试

常见误用：所有镜头同一滤镜；肤色被破坏；饱和度代替焦点；色彩含义前后矛盾。

色彩组织与选择保色 →

H14 · 原作约48—48秒

分析单元 02 / 48—48秒

锁链前景／竖排字

实际观察

人物在红色链条网络中，链条分前后层，旁边细竖排字

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

“锁链前景／剪影层级／竖排排版”。链条图形可重复排布；精确遮罩和空间层级需要设计。

直出判断：基础机制容易，遮挡需设计

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →漫画分层与2.5D视差 →

H14 · 原作约132—132秒

分析单元 03 / 132—132秒

玻璃多边形／粒子空间

实际观察

透明多边形层叠，内有粒子点和亮线

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

“玻璃碎片感／多边形粒子空间”。基础多边形和粒子可编程；真实折射、复杂相机和角色层级要调试。

直出判断：基础版可做，真实折射与相机较难

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →

H14 · 原作约136.7—138.7秒

分析单元 04 / 136.7—138.7秒

能量轨迹／白闪／闪电前景

实际观察

电光轨迹接强白闪，出现跑道上人物；景别移向侧面手臂再到面孔；前景电光持续横扫

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

“能量轨迹转场／白闪／近景推进／闪电前景”。光线和白闪容易，角色拆分、姿态与镜位统一较难；不能把每次电光闪过算新镜头。

直出判断：基础光效容易，角色运动较难

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →闪白、黑帧与冲击帧 →

H14 · 原作约207—209秒

分析单元 05 / 207—209秒

冲击帧／跟拍／前景柱子遮挡／残影

实际观察

人物并肩近景后，207.56–207.64出现高对比白黑冲击帧，再变为侧向奔跑；柱子一根根从前景掠过、轻微重影、电弧环绕

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

“冲击帧／横向跟拍／前景遮挡／运动残影”。遮挡柱和光效可合成；高质量跑步姿态与头发层次需要角色素材和逐镜动画。

直出判断：遮挡与滤镜容易，跑步姿态和分层需逐镜处理

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。
