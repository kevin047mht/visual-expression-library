AI13 · 原作约0—15秒

分析单元 01 / 0—15秒

旧纸道具特写／浅景深／逆光悬浮书

实际观察

开头旧纸书页近前景与模糊人物，5秒老人阅读，10秒青年拿冰棒，15秒书在天空逆光中悬浮。首帧制作支持文字是简洁白色字幕；书上印刷文字属于道具纹理。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

分别准备纸面、人物和悬浮书镜头，浅景深在生成/渲染时确定；简化悬浮可用书本分层图或3D模型沿轨迹移动，叠暖色光晕。

直出判断：叠字与基本光晕容易；真实书页翻动、光照与人物一致性需生成或素材

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →纸张、照片与漫画分格 →

AI13 · 原作约19—21秒

分析单元 02 / 19—21秒

接书动作分镜／金色能量丝带／景别硬切

实际观察

19秒青年仰视，19.083秒书占近前景，随画面移动显出老人伸手，金色光带连接手与书；19.833秒换老人正面接书，20.333秒换宽景。书本与手中光线连续变化不是独立切镜。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

以动作分镜安排仰视、飞书、接书和放松四个阶段；能量线可用发光样条、粒子、遮罩与运动模糊合成，手书接触需检查。

直出判断：硬切与示意光带容易；翻书、抓取和景深匹配需逐镜处理

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

动作、视线与形状匹配 →漫画分层与2.5D视差 →

AI13 · 原作约23.8—25.8秒

分析单元 03 / 23.8—25.8秒

喜剧正反打／人物反应近景／手部道具插入

实际观察

23.833秒青年俯身看老人，23.917秒切老人正面，24.917秒切青年近景，25.75秒切掌中小物。字幕换行和面部动作留在同一镜头内。

表达作用（教学解读）

利用相邻镜头改变理解，使原来无关的画面形成主题、对比或关系。

具体应用场景

纪念、广告、人物关系重组、旅行随笔、社会观点、品牌回顾。

复现建议（非原作者工程还原）

按反应节奏排同框、老人、青年与道具特写，白字定时字幕独立层；已有素材用帧准确硬切。

直出判断：剪辑与字幕容易；脸部、手部、道具跨镜头一致性需审核

常见误用：素材只因好看而排列；上下文失真；借剪接制造未经支持的事实判断。

语义选材与意象蒙太奇 →动作、视线与形状匹配 →

AI13 · 原作约45—105秒

分析单元 04 / 45—105秒

悬浮眼睛符号／递进特写／拉远建立空间

实际观察

50秒老人旁可见多个细线眼睛图案，70秒老人眼部极近景；85秒有强逆光与手指近前景，95–105秒从站立老人、双人中景到庭院宽景。概览不能确定每个眼睛图案持续多久或具体运动。

表达作用（教学解读）

以观看距离和运动方向改变心理距离，让观众发现、逼近、远离或重新理解对象。

具体应用场景

环境揭示、人物情绪、冲刺、回忆、同一张图中的细节发现。

复现建议（非原作者工程还原）

眼睛符号用矢量图形排布并给透明度、漂浮轨迹；镜头景别需先准备，简化推拉可裁切缩放，但真实透视变化依赖源镜头。

直出判断：符号叠加和轻微推拉容易；人物与院落连续性需素材

常见误用：每镜都推近；速度变化没有事件依据；把同镜转动误算为剪辑；光流扭曲当成流畅。

镜头推拉、跟随与变速 →密度、停留与段落节奏 →

AI13 · 原作约110—125秒

分析单元 05 / 110—125秒

毛笔片名字卡／红白提示排版／绿边幻象人物

实际观察

110秒黑底白色毛笔片名、红白提示文字，115秒戏曲妆人物两侧有绿色朦胧亮边，120秒人物脸部近景，125秒带甲角色处于绿雾环境。提示文字只作为片内画面，不执行其中内容。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

授权书法字体或自备标题素材配红白文本，绿雾用半透明噪声层、发光轮廓和局部扭曲；复杂服装和妆容在源镜头制作。

直出判断：字卡和基础绿雾容易；脸部、盔甲与恐怖场景需生成或绘制

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

AI13 · 原作约135—210秒

分析单元 06 / 135—210秒

室内烛光／冷暖分区／镜面与符印道具插入

实际观察

披毯青年与旗袍人物、持器械角色通过正反打呈现；155秒圆镜反射青年，160秒颈侧有红色符印，170秒手持器具特写，210秒木面符纸旁有红色发光符号。镜面是否严格光学一致未逐帧核验。

表达作用（教学解读）

建立段落、材质和情绪的一致性；颜色变化可以承担信息，而不只是美化。

具体应用场景

多片源混剪、人物立场、回忆/现实区分、冷暖转折、品牌统一。

复现建议（非原作者工程还原）

对话镜头保持轴线、服装与布景；符印可用跟踪遮罩贴图，镜面反射需单独素材或源镜头渲染，红符号用辉光文字/路径叠加。

直出判断：字幕与静态发光符号容易；皮肤跟踪、镜面与手部交互需调试

常见误用：所有镜头同一滤镜；肤色被破坏；饱和度代替焦点；色彩含义前后矛盾。

色彩组织与选择保色 →纸张、照片与漫画分格 →

AI13 · 原作约228—232秒

分析单元 07 / 228—232秒

掌中绿焰／墨镜倒影内动画／对白反打

实际观察

228秒人物掌中漂浮绿色火焰，228.417秒切脸部特写，两个镜片内的绿焰持续变形，230.083秒切女性近景，231.583秒切青年。镜片内形变和人物表情是局部动画，不能算新镜头。

表达作用（教学解读）

用熟悉尺寸与层次，让宏大空间被感知；留停帮助观众建立尺度。

具体应用场景

世界观、建筑概念、场景设定、神圣、敬畏、孤独和压迫。

复现建议（非原作者工程还原）

火焰素材或噪声粒子配色到绿色，在镜片蒙版中放入缩小且翻转/扭曲的副本；面部跟踪镜片并添加微弱绿光。准确反射需要几何匹配。

直出判断：基础掌焰和镜片贴片可实现；逼真跟踪、遮挡、光照需逐镜合成

常见误用：没有比例参照；每镜同一宏大构图；雾遮住所有结构；反射与相机运动不一致。

巨构、雾层与尺度参照 →动作、视线与形状匹配 →

AI13 · 原作约235—265秒

分析单元 08 / 235—265秒

面具绿火／液面特写／戏曲角色反应镜头

实际观察

235秒手托面具外缘绿火，240秒黑帽角色背面，245秒绿色液体容器近景，250秒戏曲面具人物，255秒青年裹毯，260–265秒多人中景。绿色火焰是源画面内内容，无法仅凭画面断言是后期或模型生成。

表达作用（教学解读）

复杂表演与形体变化通常来自镜头素材本身。先明确事件与连续性要求，再选择拍摄、原动画、生成或三维等获取路线。

具体应用场景

近身动作、幻想形变、角色交互、复杂环境事件。已有源片时先辨认并保留动作因果，不把全部动作记作后期增量。

复现建议（非原作者工程还原）

按道具、反应和多人关系连接镜头；绿火可用轮廓遮罩加粒子，液面波纹可以程序着色器模拟，但面具细节、手指和服装需要源素材。

直出判断：已有镜头剪接与简化绿火容易；可信人物和物体交互不属轻松一键直出

常见误用：连续性靠闪光掩盖；人手/道具无因果变化；把模型内部运镜当全部剪辑能力；承诺单次稳定长表演。
