AI20 · 原作约5—30秒

分析单元 01 / 5—30秒

向量射线／矩阵网格变形／面积平行四边形／字幕辉光

实际观察

箭头从原点发散，网格与蝴蝶曲线随矩阵变形，平行四边形示意面积后压成直线。

表达作用（教学解读）

把可控规则变成可见变化；通过不变量、比例和相位建立秩序或空间。

具体应用场景

概念解释、音乐可视化、抽象世界、图表、程序艺术。

复现建议（非原作者工程还原）

对二维点与网格应用矩阵插值，箭头路径加亮点和辉光，字幕独立排版。

直出判断：容易，数学和画面参数须分别校验

常见误用：符号无含义；空间复杂度替代概念清晰；将程序生成误等同于文生视频生成。

几何、图表与程序空间 →发光字、光迹与轮廓光 →

AI20 · 原作约40—65秒

分析单元 02 / 40—65秒

向量场流线／彩色旋涡／线框圆环体

实际观察

向量基与流线交织，彩色曲线旋成圆盘，之后线框环形曲面与矩阵并排。

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

积分或解析生成曲线路径、轨迹累积；参数化圆环体网格与透视相机。

直出判断：基础版可程序做，密度与渲染需调试

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →几何、图表与程序空间 →

线框视图与着色视图闪切／霓虹网格地形

实际观察

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

直出判断：基础版容易；这种状态切换应与叙事换镜分开

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

AI20 · 原作约125—140秒

分析单元 05 / 125—140秒

波形叠加／旋转圆链／光点描字

实际观察

多条正弦曲线分解叠加；133–137秒多个转动圆链端点连续留下金色线，形成美字轮廓。

表达作用（教学解读）

把可控规则变成可见变化；通过不变量、比例和相位建立秩序或空间。

具体应用场景

概念解释、音乐可视化、抽象世界、图表、程序艺术。

复现建议（非原作者工程还原）

傅里叶系数或预设复数圆链驱动端点，累积轨迹并加辉光。简单路径揭示也能近似外观。

直出判断：基础描线容易，精确圆链需计算与路径预处理

常见误用：符号无含义；空间复杂度替代概念清晰；将程序生成误等同于文生视频生成。

AI20 · 原作约145—185秒

分析单元 06 / 145—185秒

网络节点／连线激活／神经网络示意／词语空间

实际观察

彩色节点网络点亮并配排名条；纵向神经网络层之间连线，词语点集用向量箭头连接。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

图布局、边透明度和节点亮度关键帧、矩阵乘法图示、词语坐标插值。

直出判断：基本机制容易；示意不等于真实模型内部数据

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →

AI20 · 原作约191—210秒

分析单元 07 / 191—210秒

白闪色散蒙太奇／结尾标题与透视网格

实际观察

191.533秒换网格太阳，192秒换蕨叶，192.533秒换描字；短暂白闪与RGB边缘，末尾大标题落在网格地面上。

表达作用（教学解读）

把短暂破坏作为失控、断裂、冲突或数字材质的提示。

具体应用场景

赛博题材、记忆中断、身份不稳、高潮强调；也可短时掩护连接。

复现建议（非原作者工程还原）

镜头表切换、短曝光包络和通道偏移，文字描边发光、地面透视。

直出判断：容易

常见误用：全程持续导致麻木；色散让脸和字长期看不清；把所有亮度变化算成切镜。

RGB错位、条带与故障 →文字排版与逐字动效 →
