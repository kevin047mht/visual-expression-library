拟人茶馆/屋顶月夜到米白水墨，再落现实猫狗拖鞋，幻想回现实具有清楚视觉对应，题材和风格转换丰富。

AI48 · 原作约0—3秒

分析单元 01 / 0—3秒

纸纹／墨迹标题

实际观察

米白纸纹上墨色笔刷题字和灰墨扩散，片尾亦重复。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

纸纹底图+透明墨迹序列或噪声扩散遮罩，授权书法字体揭示。

直出判断：简化墨迹题字容易直出

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →纸张、照片与漫画分格 →

AI48 · 原作约3—33秒

分析单元 02 / 3—33秒

拟人毛发／茶馆反打／景深

实际观察

白猫与黑犬以武侠装束对坐饮茶，近景/过肩/双人，后有女子。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

角色、服装和场景需稳定生成或3D；分镜用景别/视线组织，远景虚化。

直出判断：反打剪辑/调色容易；毛发手爪与道具接触难

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →景深、柔焦与负空间 →

AI48 · 原作约36—81.4秒

分析单元 03 / 36—81.4秒

月夜剪影／跳跃／刀光与冲击尘

实际观察

大月亮与屋顶构图，角色跳跃、双刃相接、白色弧线和尘碎片。

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

刀光用跟踪曲线/残影，冲击粉尘用粒子；完整空中缠斗和屋顶空间依赖源视频。

直出判断：简化刀光尘粒容易；连贯打斗动作难

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

发光字、光迹与轮廓光 →粒子、花瓣、雪与碎片 →

AI48 · 原作约81.4—90秒

分析单元 04 / 81.4—90秒

水墨风格化／黑白冲击／墨弧

实际观察

屋顶写实式打斗经黑白冲击转米白底水墨打斗；85秒猫挥刀大墨弧，人物前后景变化。

表达作用（教学解读）

建立段落、材质和情绪的一致性；颜色变化可以承担信息，而不只是美化。

具体应用场景

多片源混剪、人物立场、回忆/现实区分、冷暖转折、品牌统一。

复现建议（非原作者工程还原）

可先做黑白阈值/纸纹叠加，再加入手绘墨弧；完整画风切换要匹配轮廓、动作与构图。

直出判断：简化冲击帧和墨弧中等；保留角色动作的完整风格迁移较难

常见误用：所有镜头同一滤镜；肤色被破坏；饱和度代替焦点；色彩含义前后矛盾。

色彩组织与选择保色 →

AI48 · 原作约90—112秒

分析单元 05 / 90—112秒

气浪／云尘涡旋／碎片

实际观察

兵刃冲击形成圆形气浪，月夜屋顶白色涡旋、飞瓦与周边烟尘。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

径向位移和环形透明噪声加碎片粒子，前后遮罩及景深需要素材分层。

直出判断：简化气浪烟尘中等；建筑碎裂/角色遮挡难

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →

AI48 · 原作约114—139秒

分析单元 06 / 114—139秒

细节到表情／幻想接现实／冲击线

实际观察

女子脚步、脸与远景交替；122.6左右从武侠院子切到猫狗挨着拖鞋，后黑白放射冲击。

表达作用（教学解读）

用熟悉尺寸与层次，让宏大空间被感知；留停帮助观众建立尺度。

具体应用场景

世界观、建筑概念、场景设定、神圣、敬畏、孤独和压迫。

复现建议（非原作者工程还原）

脚/脸/全景按信息组织；A/B硬切建立幻想与现实，放射线用消失点生成。

直出判断：硬切和放射冲击容易；角色变装及动作需源素材

常见误用：没有比例参照；每镜同一宏大构图；雾遮住所有结构；反射与相机运动不一致。

巨构、雾层与尺度参照 →色彩组织与选择保色 →

AI48 · 原作约141—181.046秒

分析单元 07 / 141—181.046秒

水墨片尾／宠物彩蛋／拉远

实际观察

水墨题字后为现实猫狗嬉闹，继而回武侠坐姿、茶馆拉远，末尾书法感谢字。

表达作用（教学解读）

以观看距离和运动方向改变心理距离，让观众发现、逼近、远离或重新理解对象。

具体应用场景

环境揭示、人物情绪、冲刺、回忆、同一张图中的细节发现。

复现建议（非原作者工程还原）

墨迹遮罩、片尾字淡入；慢拉远可源视频或2.5D分层实现。

直出判断：题字淡入和简化拉远容易；猫狗互动与毛发难

常见误用：每镜都推近；速度变化没有事件依据；把同镜转动误算为剪辑；光流扭曲当成流畅。

镜头推拉、跟随与变速 →文字排版与逐字动效 →
