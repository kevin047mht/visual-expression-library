漫画人物、照片质感背景和落叶之间的遮挡形成空间。共享活动片头与正文的个人合成劳动要分别观察。

从画面里找依据

这一例先看什么

人物抠图、前景叶片、照片质感背景、景深和留白卡有空间组织，活动手机桌面片头单列。

审美判断

黑白漫画和大量白底细字统一，人物轮廓与章节编号有层级；缩略图上极细字不作全程可读保证。

迁移到自己的题材

漫画改编、人物回忆、纪念、故事提案、海报动态化、低动作但高情绪密度的段落。

教学提问：前景、中景、背景分别是什么？如果镜头移动，原图未画出的部分由谁补齐？

带画面的分析单元

图像标出取样时间，对应观察中的关键状态。单帧不能独立证明运动，连续性请结合摘录。表达作用与应用场景是教学解读，复现路线是建议，不是原作者工程还原。

H41 · 原作约0—9秒

分析单元 01 / 0—9秒

桌面贴纸拼贴／手机唱片 UI／相机框／递归照片

实际观察

开头彩色桌面有地图、手机、明信片、笔与胶带；4.4秒唱片页，随后向右上移动，照片逐张显露、6秒再出现本画面拍成照片的嵌套卡。此段可能为团队/活动片头素材。

表达作用（教学解读）

把画面变成可触摸的记忆或记录；纸边、阴影与展示顺序可以表现珍惜、拼凑或碎裂。

具体应用场景

回忆、青春、艺术创作、旅行手记、人物档案、纪念短片。

复现建议（非原作者工程还原）

把平面素材分层在虚拟桌面放置，摄像机平移/旋转；照片矩形遮罩显露，再将合成快照回贴成小卡；相机控件固定在边缘。

直出判断：中等，机制可代码直出；素材排布多，归属与片头复用须核实

常见误用：所有纸张纹理一样重；阴影方向不一致；折页遮挡错误；照片墙只有数量而没有观看顺序。

纸张、照片与漫画分格 →画中画、分屏与局部拼贴 →

H41 · 原作约9—24秒

分析单元 02 / 9—24秒

黑白漫画抠图／场景合成／景深／留白细字卡

实际观察

9秒模糊漫画，12秒两人车厢；15/18秒留白中央小字、编号及纤细装饰线，21秒侧脸、24秒竖幅人物。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

人物分割与背景修补，多层平移建立视差，近层虚化，灰度统一；小字与细线布局独立。

直出判断：基础排版容易，抠图和补背景中等且需检查边缘

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →景深、柔焦与负空间 →

H41 · 原作约28—30秒

分析单元 03 / 28—30秒

橙红漏光／辉光色差／前景遮挡／横条位移

实际观察

28–28.2橙红光泄漏，28.267见牵手人物；29秒前景灰弧遮挡+高亮色差，29.533转低机位双人，29.8同画面横向撕条变形后恢复。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

软噪声渐变做漏光，亮度曲线与RGB轻微错位；前景alpha移动；按扫描行切条做不同横向偏移。

直出判断：漏光/色差/条带容易；人物和空间源素材需处理

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →发光字、光迹与轮廓光 →

H41 · 原作约30—42秒

分析单元 04 / 30—42秒

静止人物运动／漂浮叶片／背景光斑

实际观察

双人与街景、长椅与树木构图中有漂浮叶片和散焦光点，主体为漫画线稿，空间背景有照片/绘画质感。不能仅凭画风确认实拍来源。

表达作用（教学解读）

把画面变成可触摸的记忆或记录；纸边、阴影与展示顺序可以表现珍惜、拼凑或碎裂。

具体应用场景

回忆、青春、艺术创作、旅行手记、人物档案、纪念短片。

复现建议（非原作者工程还原）

叶片透明贴图按轨迹/深度缩放旋转，远近不同模糊；人物与场景分层缓慢推拉，光点用散焦圆。

直出判断：有抠图与背景时中等；简单粒子/推拉容易

常见误用：所有纸张纹理一样重；阴影方向不一致；折页遮挡错误；照片墙只有数量而没有观看顺序。

纸张、照片与漫画分格 →

H41 · 原作约44—45.9秒

分析单元 05 / 44—45.9秒

相机框/负片闪烁／重复字纹／竖排文案／条带转场

实际观察

44秒叶片带相机边框与负片，44.3回正常叶；44.9整屏重复汉字，45.1青色大字一闪，45.2转花朵和竖排字，45.8条带撕裂后45.9转儿童。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

反色开关和UI层，文字在规则网格重复、整体缩放，换色闪帧；竖字按纵向布局，横向条带噪声掩护新图。

直出判断：容易到中等，字网格和滤镜可直接出；节奏可读性需调整

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →密度、停留与段落节奏 →

H41 · 原作约46—73.8秒

分析单元 06 / 46—73.8秒

漫画细节推近／前景铅笔／水波与光影／竖幅书本

实际观察

47秒人物画本，47.7更近书本，51秒俯视，63秒室内前景铅笔，66秒桥下人物与水，72秒竖幅笔记。某些运动可由同张图裁切完成。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

从大图裁切不同取景，用分层变换/轻微形变；前景模糊道具与投影，水面置换/反射可简化。

直出判断：平移缩放容易；真实水面、光影和补画需素材或逐镜合成

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →镜头推拉、跟随与变速 →

H41 · 原作约73.8—76.1秒

分析单元 07 / 73.8—76.1秒

白底比赛标志／来源与音乐署名

实际观察

75秒比赛logo和原作、音乐说明，主体为静态片尾版面。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

合法标志图片居中排版，署名字体统一，短淡入/停留。

直出判断：容易，但标志素材本身不算原创绘制

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →

短时变化怎样理解
