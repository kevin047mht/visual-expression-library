AI12 · 原作约0—2秒

分析单元 01 / 0—2秒

打字机／输入光标

实际观察

输入框的“花生，你会做什么”逐字增加，竖线光标跟随；框体视图缓慢改变

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

“打字机／输入光标／界面缩放”。文字截取、光标位置和相机裁切都容易代码直出。

直出判断：容易

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →镜头推拉、跟随与变速 →

AI12 · 原作约12—16秒

分析单元 02 / 12—16秒

径向线束／线框图形空间变换

实际观察

大量细线向中心汇聚，紫色短条分布其间，中心小物体逐渐变大，外围线条退去

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

“星际隧道／径向线束／速度线”。2D极坐标线段与透明度可做基础版；有真实空间变化时用Three.js相机与线段。

直出判断：基础版容易，连续空间需调试

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →

AI12 · 原作约16—20秒

分析单元 03 / 16—20秒

棱镜分光／光束辉光

实际观察

单束光经过三角形后分成紫、粉、黄、白等多条光束，旁边标功能名称

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

“棱镜分光／加法辉光／标签引线”。曲线或线段多层模糊加法叠加，配合几何图形可做基础版；未核验其真实物理光学。

直出判断：基础视觉版容易；物理光学未核验

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

发光字、光迹与轮廓光 →几何拼贴与形状语言 →

AI12 · 原作约24—40秒

分析单元 04 / 24—40秒

关键词发光／线框装置／文字轨道

实际观察

大白字中的关键词带紫色光，旁边线框机械与滚动文字轨道，深色透视网格

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

“关键词辉光／线框装置／文字传送带”。文字和网格容易；齿轮、机械图和空间构图需要预先绘制或建模。

直出判断：字效容易，装置需设计

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →文字排版与逐字动效 →

AI12 · 原作约82—86秒

分析单元 05 / 82—86秒

环形多屏／空间运镜／HUD字幕

实际观察

图表屏幕沿弧面排列，镜头旋转／倾斜，光柱和柱状图保持空间对应，字幕锁在左上区域

表达作用（教学解读）

用规则、选择与反馈组织关系，让抽象状态可被看见。

具体应用场景

人物关系、搜索、等待、推理、产品功能解释、系统压力；数值需要真实含义或明确虚构设定。

复现建议（非原作者工程还原）

“环形多屏／空间运镜／HUD字幕”。此窗主要是运镜和图表更新，未确认多次硬切。Three.js网格、贴图与相机可实现，精细版中等难度。

直出判断：中等，需相机和空间布局调试

常见误用：假数据制造伪解释；辅助文字太暗；每个窗口同时运动；手机界面只是装饰外壳。

界面、菜单与信息面板 →镜头推拉、跟随与变速 →
