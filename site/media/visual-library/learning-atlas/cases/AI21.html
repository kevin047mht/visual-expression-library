AI21 · 原作约0—29秒

分析单元 01 / 0—29秒

烛光羊皮纸／羽毛笔书写／双语小字幕

实际观察

暖光矩形纸面，左下蜡烛、羽毛笔沿书写区域移动，花体字逐步出现，底部中英双语。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

噪声/纸纹底图叠暖色径向光，蜡烛火焰alpha动画；字路径描边或字序遮罩，笔尖位置跟随当前字符。

直出判断：简化版容易到中等；精准连笔轨迹需要字路径与笔素材

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →纸张、照片与漫画分格 →

AI21 · 原作约29—33秒

分析单元 02 / 29—33秒

金色粒子聚字／扩散光环／横向镜头光晕

实际观察

29秒金点覆盖旧字，30秒粒子逐渐组成中文标题，30.2起圆环扩大，31.1左右字面转连续明亮金色，32秒英文副题渐显。

表达作用（教学解读）

把可控规则变成可见变化；通过不变量、比例和相位建立秩序或空间。

具体应用场景

概念解释、音乐可视化、抽象世界、图表、程序艺术。

复现建议（非原作者工程还原）

从文字alpha采点，粒子初始随机位置插值到字点，寿命/亮度错峰；薄圆环半径增长降alpha，横线和模糊亮点加色叠加。

直出判断：中等，可程序直出机制；粒子密度、字体细节和过曝需调试

常见误用：符号无含义；空间复杂度替代概念清晰；将程序生成误等同于文生视频生成。

几何、图表与程序空间 →粒子、花瓣、雪与碎片 →

AI21 · 原作约114—180秒

分析单元 04 / 114—180秒

暖冷段落切换／同心圆层级／点线格与公式版式

实际观察

引用段偏暖棕，图示偏青蓝；132秒同心圆，138/144秒菱形点线关系，150/162秒公式上下搭图，174/180秒居中多行公式。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

两套颜色/背景alpha衔接；公式以矢量渲染保证上下标，节点线图按拓扑和坐标布局，淡入/淡出。

直出判断：视觉机制容易；公式正确与易懂性不能由好看证明

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →语义选材与意象蒙太奇 →

AI21 · 原作约186—210秒

分析单元 05 / 186—210秒

根式层级变换／数字替换／扩散圆环

实际观察

195秒根式内四行，195.067白圈扩散，195.133后只剩两行且右上4改2，其余中心位置和背景连贯。

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

独立公式对象错位/alpha变换，行数删除或重新排版；数字层替换，圆环扩大淡出。

直出判断：容易到中等；这是公式局部状态变化，不是多个镜头

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

分析单元 07 / 270—334秒

结论字卡／螺旋线／书信回环／金字片尾

实际观察

270/276秒放射背景上的结论排版，288秒纵向螺旋，294秒近黑后300秒回羊皮纸书写，324秒金字标题、330秒渐暗。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

文字层分组淡入；参数螺旋3D投影，回用开头纸面模板构成首尾呼应，片尾alpha渐减。

直出判断：机制容易到中等；长片编排与文字内容需要人工复核

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。
