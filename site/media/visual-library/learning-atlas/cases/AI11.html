AI11 · 原作约0—66秒

分析单元 01 / 0—66秒

写实异星角色／浅景深正反打／固定对白字幕

实际观察

面馆中人类、蟹状外星角色、盔甲执法者的中近景和特写交替，背景普遍较虚；白色小字号对白字幕在下方居中。60秒概览另有纸质评级表插入镜头。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

先准备各角色与场景一致的镜头，按对白组织正反打；字幕用定时文字层与轻描边/阴影；景深可在源镜头制作，或用人物遮罩加背景模糊模拟。

直出判断：字幕、现成镜头硬切容易；角色、手部和空间一致性需生成或美术审核

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →景深、柔焦与负空间 →

AI11 · 原作约72—90秒

分析单元 02 / 72—90秒

科幻城市建立镜头／新旧建筑尺度对比

实际观察

72秒是老建筑与高耸发光塔、飞行器同画面；78秒外星角色近景，84秒队列与车，90秒老人近景。高塔和飞行器是场景内容，不能仅凭外观确定3D软件。

表达作用（教学解读）

用熟悉尺寸与层次，让宏大空间被感知；留停帮助观众建立尺度。

具体应用场景

世界观、建筑概念、场景设定、神圣、敬畏、孤独和压迫。

复现建议（非原作者工程还原）

先构建或生成城市总览，再用不同角色与景别说明世界；霓虹辉光可分层叠加，真实遮挡和透视需要镜头级制作。

直出判断：基础辉光容易；大型城市与飞行器空间关系不属轻松确定性直出

常见误用：没有比例参照；每镜同一宏大构图；雾遮住所有结构；反射与相机运动不一致。

AI11 · 原作约109.6—111.6秒

分析单元 03 / 109.6—111.6秒

景别递进硬切／低机位踢击／倾斜动作镜头

实际观察

109.6秒是店员与蟹角色同框，110.0秒变店员近景，110.267秒变蟹角色低角度近景，110.867秒换鞋和腿近前景的低机位；111.2秒起店员倒地、商品散落。后半段快速视角移动和物件飞散应与硬切分开统计。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

分镜预先列同框、反应、威胁特写、出脚和受击；已有素材用帧准确硬切。动作生成需检查肢体接触、空间方向与物件连续性；轻微倾斜和运动模糊可在剪辑层补。

直出判断：剪辑连接容易；可信的多角色踢击和倒地镜头需逐镜处理

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

动作、视线与形状匹配 →密度、停留与段落节奏 →

AI11 · 原作约132—204秒

分析单元 04 / 132—204秒

夜景湿地反射／悬浮器红蓝灯／光束照明

实际观察

132、150、174、198、204秒概览可见悬浮圆盘、红蓝点灯及湿地反光，150秒有向下的可见光束。不同时间图像不能证明所有光效都是后期叠层。

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

反射和照明可随源镜头一同生成/渲染；简化复现用半透明锥形光束、模糊发光点、地面透视遮罩及低透明度镜像，但要按人物遮挡分层。

直出判断：示意灯光和光束容易；照片级反射、接触阴影和遮挡需素材与合成

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

AI11 · 原作约270—294秒

分析单元 05 / 270—294秒

乘龙式城市飞行／追随与逆光近景

实际观察

270秒屋顶远景后，276和282秒人物骑在白色鳞片长形生物上，288秒沿建筑间向前飞行，294秒转暖色逆光双人近景。这里的主体飞行是镜头内动作，不应把每次位移算为切镜。

表达作用（教学解读）

用熟悉尺寸与层次，让宏大空间被感知；留停帮助观众建立尺度。

具体应用场景

复现建议（非原作者工程还原）

设计远景、骑乘细节、追随和人物反应镜头，分别制作再连接。简单平移缩放只能模拟镜头运动，不能可靠生成复杂骑乘、衣物和建筑视差。

直出判断：现成素材裁切与调色容易；新生成飞行长镜头和稳定人物需逐镜审核

AI11 · 原作约345.2—347.2秒

分析单元 06 / 345.2—347.2秒

火苗落地引燃／湿地火焰扩散与倒影

实际观察

345.2秒火苗近前景、角色虚化；345.267秒切到脚边地面，随后火焰由小点扩展、铺满下缘并映在湿地，地面构图持续。场景检测器在346–347.2秒多次触发，但目视是同一镜头内火焰变化和闪动。

表达作用（教学解读）

用熟悉尺寸与层次，让宏大空间被感知；留停帮助观众建立尺度。

具体应用场景

世界观、建筑概念、场景设定、神圣、敬畏、孤独和压迫。

复现建议（非原作者工程还原）

简化版以火焰素材或噪声驱动粒子合成，设置扩散遮罩、暖色泛光与倒影；照片级火焰需匹配地面透视、遮挡、反射和照明，或在源镜头中生成。

直出判断：平面火焰叠加可直出；匹配实景的火焰扩散与反射需调试

AI11 · 原作约366—432秒

分析单元 07 / 366—432秒

符纸特写插入／追逐视角切换／方向性运动模糊

实际观察

366秒黄色符纸特写，378和384秒人物看符纸与俯视街道；390秒人物与白色飞鸟越过城市，396秒建筑侧面高速前移，426秒飞鸟，432秒巷内奔跑。符纸上的字属于道具纹理，不等同于屏幕动态字效。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

把关键道具作为插入镜头，再安排俯视、追随、低机位逃跑建立行动连续性；运动模糊可用方向滤镜近似，但高质量视差仍依赖镜头素材。

直出判断：插入硬切、基础模糊和字幕容易；可靠追逐空间与飞鸟动作需制作

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →纸张、照片与漫画分格 →

用连续画面核对

保留原研究的多段局部摘录。片段含音轨不代表已听审；本资料不评价音乐卡点或对白节奏。

短时变化怎样理解

109.6–111.6秒至少3处明确景别变化；345.2–347.2秒切脚边后火焰扩散主要是同镜动画，不能按每次火光计刀。

把镜头连接、版式更新、局部图层变化和镜内运动分开记录。所查窗口是下限，不是全片平均或AI／人工排名。
