分析单元 01 / 0—32秒

黑底说明／赤色书法片名／燃烧寺院

实际观察

黑底说明后是暖橙火寺院与白发怪物，24秒附近红色恶仙片名叠武器和人物。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

文字排版、笔刷字体、透明度和轻推；火寺院主要为生成场景。

直出判断：文字卡容易；精确场景和角色需素材

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

分析单元 02 / 32—112秒

发丝触手／缠绕／多眼血肉武器

实际观察

白发如粗触手掠过并缠人，人物跃屋顶，武器有眼和牙。32.7窗口为连续追踪白发至眼球。

表达作用（教学解读）

复杂表演与形体变化通常来自镜头素材本身。先明确事件与连续性要求，再选择拍摄、原动画、生成或三维等获取路线。

具体应用场景

近身动作、幻想形变、角色交互、复杂环境事件。已有源片时先辨认并保留动作因果，不把全部动作记作后期增量。

复现建议（非原作者工程还原）

生成镜头或角色/毛发模拟，再作选镜、稳定与合成；不能用普通转场替代复杂遮挡。

直出判断：完整形体和缠绕较难；毛发素材叠加只能近似

常见误用：连续性靠闪光掩盖；人手/道具无因果变化；把模型内部运镜当全部剪辑能力；承诺单次稳定长表演。

分析单元 03 / 112—136秒

红色地面电环／刀光／残烬

实际观察

武器触地伴红色电环，红刀光横扫发丝，人物落地持剑。

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

直出判断：简化电环/刀光/残烬容易

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

AI38 · 原作约136—208秒

分析单元 04 / 136—208秒

漂浮人头／多手怪物／眼球点亮

实际观察

巨大白发怪物带漂浮头颅和多手；197.9附近武器眼睛变橙亮，切单眼和人物挥剑。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

生成或3D负责怪物几何；眼部局部mask加色、模糊光晕和红色轨迹可另合成。

直出判断：眼睛发光容易；完整怪物/肢体变化难

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

分析单元 06 / 304—400秒

火光散景对话／黑烟聚散／泪滴特写

实际观察

人物近景对话，390.9切手部黑烟，391.3切人物全景，392.2眼部，393.3泪滴。

表达作用（教学解读）

决定什么值得看、什么退到感受层；清晰与模糊、占满与留空之间的关系塑造语气。

具体应用场景

复现建议（非原作者工程还原）

直出判断：简化黑烟/散景容易；准确烟化和泪滴反射需素材

常见误用：模糊所有层；细字落在高亮区域；浅色误认为高级；没有清楚的主焦点。
