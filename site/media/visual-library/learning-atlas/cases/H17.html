这一例先看什么

人物特写、黑场留白、多窗口、线网和白刷遮罩构成统一图形语言。

审美判断

斜字、大黑底字块与脸部形成前后层，黑红色划痕强化情绪；局部小字需原尺寸阅读。

迁移到自己的题材

漫画改编、人物回忆、纪念、故事提案、海报动态化、低动作但高情绪密度的段落。

教学提问：前景、中景、背景分别是什么？如果镜头移动，原图未画出的部分由谁补齐？

带画面的分析单元

图像标出取样时间，对应观察中的关键状态。单帧不能独立证明运动，连续性请结合摘录。表达作用与应用场景是教学解读，复现路线是建议，不是原作者工程还原。

H17 · 原作约0—24秒

分析单元 01 / 0—24秒

环境建立／原动画镜头串联／分屏与小字幕

实际观察

0–20秒森林、步行、教室、人物背影；24秒左上和右下两人物画面，余下区域黑底小字。背景自然运动可能继承原片。

表达作用（教学解读）

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

具体应用场景

记忆、对话、关系对照、主观视点、多人角色介绍、跨素材呼应。

复现建议（非原作者工程还原）

选现成动画镜头硬切，按矩形裁切到对角位置，黑底文字按时间显示；统一级别的底字幕。

直出判断：已有素材时容易，剧情选择与剪点需编排

常见误用：窗口太多无主次，眼位错位、边框挤脸，层的出现没有叙事理由。

H17 · 原作约28—76秒

分析单元 02 / 28—76秒

倾斜字行／大小字错落／描边字／黑色逐字底块

实际观察

概览多处白字斜穿人物；58.25起斜字行扫入，58.667起局部大字带黑色方底，字的大小、位置与底块不同步变化。它们是图层内排版变化。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

逐字符独立锚点、字号、旋转与起止时间；字轮廓可描边，底块按字体包围盒绘制，组层沿斜线位移。

直出判断：容易到中等，动态排版机制可代码直出；准确字体/可读性需校对

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

H17 · 原作约58—62秒

分析单元 03 / 58—62秒

同镜头三态闪烁／重复画面切片／画中画累积

实际观察

59.25–60.083同人物在正常色、红黑划痕和负片状态交替；60.25转宽景，61秒后局部动作画面条块叠入，61.417加人物近景，61.667近景卡放大。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

对当前镜头复制正常、灰度反色和红黑三版本按帧交替；矩形区域裁切复制素材，逐层叠入并放大。

直出判断：基础调色、复制裁切和缩放容易；素材时间对应需处理

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →RGB错位、条带与故障 →

H17 · 原作约136.6—138.6秒

分析单元 04 / 136.6—138.6秒

红黑竖向刮痕／透明残影／人物动作延续

实际观察

连续帧大部分保留同一母亲与窗户构图，红黑竖划痕不断变宽移位，人物动作有透明残影；138.533换近黑画面和斜细线。48个scene候选不是48刀。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

用噪声控制细竖条长度/位置，红色外层与黑色内层重叠；短延迟帧低alpha混合做残影，尾部独立黑场线条。

直出判断：简化刮痕与残影容易，素材动作不属于这两个后期层

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

H17 · 原作约148—156.8秒

分析单元 05 / 148—156.8秒

颗粒/旧胶片划线／白色涂抹转场／轮廓圈与文字线网

实际观察

154.8–155.533人物图配红黑划痕、白颗粒和斜排文字；155.6起白色粗涂层遮画面，155.8后显露黑底白头部轮廓、交叉细线与周边白红文字，随后继续转动/增密。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

复现建议（非原作者工程还原）

直出判断：简化轮廓、线网和遮罩容易；真实笔刷与原画需素材

H17 · 原作约172—243.1秒

分析单元 07 / 172—243.1秒

柔光与低对比回忆／底字幕收束／尾段原动画运动

实际观察

172–180秒浅色、柔光与钟面画面，224秒背光剪影，228秒暗场居中小字，232秒高亮人物，236–240秒回正常彩色人物与乡间。柔光可能来自原片。

表达作用（教学解读）

利用相邻镜头改变理解，使原来无关的画面形成主题、对比或关系。

具体应用场景

纪念、广告、人物关系重组、旅行随笔、社会观点、品牌回顾。

复现建议（非原作者工程还原）

选镜头并统一曝光、对比度/饱和度；字幕单独定时显示，使用慢淡入淡出和适当停留。

直出判断：调色字幕容易；原片光线/角色动作需原素材，不能归为一键后期生成

常见误用：素材只因好看而排列；上下文失真；借剪接制造未经支持的事实判断。

语义选材与意象蒙太奇 →景深、柔焦与负空间 →
