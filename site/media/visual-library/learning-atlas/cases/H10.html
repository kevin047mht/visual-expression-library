H10 · 原作约0—6秒

分析单元 01 / 0—6秒

年份与平行世界字幕／固定叙事标签

实际观察

0秒画面中央白色年份/平行世界标记，4秒年份移至左上；背景人物和教室来自动画素材。

表达作用（教学解读）

利用相邻镜头改变理解，使原来无关的画面形成主题、对比或关系。

具体应用场景

纪念、广告、人物关系重组、旅行随笔、社会观点、品牌回顾。

复现建议（非原作者工程还原）

定时文字层设中心或左上锚点，年份与世界标签跟随剧情切换，字号和描边保证可读。

直出判断：容易，纯文字层即可

常见误用：素材只因好看而排列；上下文失真；借剪接制造未经支持的事实判断。

H10 · 原作约6—10秒

分析单元 02 / 6—10秒

紫色火焰传送门／轮廓消失／跨场景连接

实际观察

7.007起人物附近窄紫火扩大，7.257–7.424前景头发拉长离开，火焰环持续变化；8.342换咖啡馆并保留前景紫门，9.426后门放大、人物半透明出现。门变化不是每步切镜。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

椭圆/不规则环的噪声位移加紫粉辉光，前景透明人物做水平拉伸与位移；在切场后复用门层，人物alpha渐显。

直出判断：基础环和拉伸可程序直出；可信火焰纹理、人物抠图与层次需素材和调试

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →漫画分层与2.5D视差 →

H10 · 原作约20—92秒

分析单元 03 / 20—92秒

彩色对白气泡／文字层级／人物反应重编

实际观察

概览24、36、48、56及64–92秒在人物旁有不同色圆角对白框；20秒大白字对白、60秒下方强调标题。对白是二创内容，不当作原作台词或真实用户指令。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

圆角矩形加尾角/文字，按角色设配色，手工控制锚点避免遮脸；定时替换文本并留阅读停顿。

直出判断：容易，文案、时序及角色对应仍需设计

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →粒子、花瓣、雪与碎片 →

H10 · 原作约76—108秒

分析单元 04 / 76—108秒

大英文排字／路线头像条／星级与绿色勾

实际观察

76–80秒人物旁竖向大英文字，96秒任务标题；100、108秒有圆头像、箭头、星级、绿色勾的任务条。仅概览不推断各图标进入动画。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

文字按行定位；头像圆形裁剪、箭头路径、星形与勾用矢量绘制，按任务状态显示。

直出判断：已有头像时容易，矢量图形和状态表直出即可

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

H10 · 原作约40.1—42.1秒

分析单元 05 / 40.1—42.1秒

稳定构图内原动画横移／手部动作

实际观察

40.107–41.575三人在吧台，中间人物动作；41.642后镜头向右移并露出第四人。自动scene在这里密集触发，实际仍是同一吧台构图展开。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

使用现成镜头保持动作；静态模拟可以平移裁切，但不能重造角色手部和新增被遮挡区域。

直出判断：现成镜头裁切/运镜容易；新动作与空间补全需素材

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

H10 · 原作约124—164秒

分析单元 06 / 124—164秒

手机画中画／多分屏年代对照／局部故障条

实际观察

124秒手机占右侧，左侧上下两人物画面；132秒人脸窄竖框，140秒头像路线条；152秒可见人物面部水平条状错位，160–164秒四分屏按年份对照。条状错位目前只有概览证据。

表达作用（教学解读）

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

具体应用场景

记忆、对话、关系对照、主观视点、多人角色介绍、跨素材呼应。

复现建议（非原作者工程还原）

用固定矩形裁切多个视频，手机屏四角透视贴图；故障将画面按水平带作小幅x位移，年份单独叠字。

直出判断：分屏和条带错位容易；手机跟踪、各素材衔接需调试

常见误用：窗口太多无主次，眼位错位、边框挤脸，层的出现没有叙事理由。

画中画、分屏与局部拼贴 →RGB错位、条带与故障 →

H10 · 原作约157.2—159.2秒

分析单元 07 / 157.2—159.2秒

人物组硬切／镜头内向下推移

实际观察

157.207–158.275为三人近景，158.342换另两人物构图，158.542后向下移至服装细节。后面的移动不算多刀。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

准备两组素材，在目标帧硬切；随后对当前素材裁切框作纵向关键帧。

直出判断：容易，有素材即可

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

H10 · 原作约168—204.5秒

分析单元 08 / 168—204.5秒

合成人物群像／黑带揭示／后记逐行增加

实际观察

168秒群像，176秒上下黑区只露中央横带，180秒完整生日人物合成；188秒回忆时间标签，196–200秒暗背景上白色后记行数增加，204秒渐暗。

表达作用（教学解读）

把注意力从旧信息带往新信息；遮满时换底图，保持方向或形状上的联系。

具体应用场景

章节转换、空间跨越、角色亮相、画内物体自然遮挡后的换景。

复现建议（非原作者工程还原）

人物透明立绘按前后层级排布，矩形蒙版扩大揭示；后记文字按行起始时间和alpha显示，背景压暗。

直出判断：已有立绘时中等，人物抠图/风格统一需处理；遮罩和逐行文字容易

常见误用：每镜不同花哨转场；遮罩与运动方向相反；过渡比内容本身更长；遮挡未满就穿帮。

形状遮挡、擦除与揭示 →语义选材与意象蒙太奇 →
