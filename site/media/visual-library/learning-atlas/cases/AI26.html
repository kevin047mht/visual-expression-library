AI26 · 原作约0—18秒

分析单元 01 / 0—18秒

倾斜建立镜头／坠落动作分镜／红底白色柔光标题

实际观察

概览0秒破旧城市阳台，6秒人物翻过栏杆，12秒落地；18秒暗红底白色片名并有轻微红白错位/柔光。坠落画面内动作不是转场插件。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

先制作阳台、坠落、落地镜头，按时间连接；标题独立文字层加模糊辉光和小幅色层偏移。

直出判断：标题和已有镜头连接容易；可信坠落接触及人物一致性需生成/动画审核

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →景深、柔焦与负空间 →

AI26 · 原作约24—36秒

分析单元 02 / 24—36秒

圆筒纵深／多人悬浮／蓝色雾化与快速跟随

实际观察

29.2–31.133人物在同一蓝色圆筒空间内快速移动、遮挡相机；主要人物大小、前后人物及面貌随时间有明显变化。无法仅凭该窗把每次姿态跃变解释为独立硬切。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

在3D圆筒内布人物按轨迹运动，或分别生成镜头再审核连续性；统一蓝色调、远景雾和运动模糊。

直出判断：简化空间与雾容易；可信多人悬浮、身份和遮挡需逐镜制作

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →镜头推拉、跟随与变速 →

AI26 · 原作约42—78秒

分析单元 03 / 42—78秒

红白环形中庭／升降管道／俯视几何转场

实际观察

58.7–59.833是上升视角，管道口逐渐离开前景、人物向空中移动；59.9换为垂直俯视同一中庭，圆形开口阵列形成几何图案。相机位移和人物飞起不能逐帧累计切镜。

表达作用（教学解读）

把可控规则变成可见变化；通过不变量、比例和相位建立秩序或空间。

具体应用场景

概念解释、音乐可视化、抽象世界、图表、程序艺术。

复现建议（非原作者工程还原）

建筑圆层用3D阵列或生成场景，设置侧仰与俯视相机后硬切；保持环形结构/灯光一致，前景近物可加景深。

直出判断：已有两镜头硬切容易；空间一致的复杂中庭、人物升降需3D或生成素材

常见误用：符号无含义；空间复杂度替代概念清晰；将程序生成误等同于文生视频生成。

几何、图表与程序空间 →几何拼贴与形状语言 →

AI26 · 原作约84—144秒

分析单元 04 / 84—144秒

照片插入／正反打／科幻飞行舱与尾焰

实际观察

84秒手持家庭照片，90–120秒办公室对话景别变化，126秒站台飞行舱，132秒底部蓝色喷焰，138秒飞行舱与城市、144秒舱内对话。概览不支持飞行路径完整连续性判断。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

照片用透视贴片与手部遮罩；对话按轴线组织镜头；喷焰可透明渐变/粒子叠加，飞行舱空间和视差由源镜头制作。

直出判断：字幕、基础尾焰和连接容易；手物交互、飞行器与城市一致性需逐镜处理

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

动作、视线与形状匹配 →纸张、照片与漫画分格 →

AI26 · 原作约150—258秒

分析单元 05 / 150—258秒

工业绿光／毒雾液体／疤痕道具与剧情蒙太奇

实际观察

150–234秒工业空间黄绿雾、近景人物、液体容器和伤痕；240秒剧场屏幕，246观众，252眼部近景，258舞台全景。绿色氛围与舞台白光区分场景。

表达作用（教学解读）

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

具体应用场景

记忆、对话、关系对照、主观视点、多人角色介绍、跨素材呼应。

复现建议（非原作者工程还原）

场景先统一色温/曝光与雾；伤痕贴图和液体可在源镜头中生成或跟踪合成；按照人物、反应、道具、场所的关系选择镜头。

直出判断：调色和简化雾容易；伤痕、液体和角色连续性需素材与审核

常见误用：窗口太多无主次，眼位错位、边框挤脸，层的出现没有叙事理由。

AI26 · 原作约360—414.6秒

分析单元 07 / 360—414.6秒

螺旋楼梯俯视／冷蓝巷道／道具极近景／尾卡

实际观察

360秒红白螺旋楼梯，366秒冷蓝狭巷，378秒多人同框，390秒拳部近景，402秒串状牙齿道具特写，414秒黑底片尾白红错位字。只描述抽样状态，不推断所有动作和切点。

表达作用（教学解读）

把短暂破坏作为失控、断裂、冲突或数字材质的提示。

具体应用场景

赛博题材、记忆中断、身份不稳、高潮强调；也可短时掩护连接。

复现建议（非原作者工程还原）

用空间建立镜头引入，再安排反应和道具特写；尾卡用文字和色层偏移。巷道透视、道具细节由图像/视频素材提供。

直出判断：尾卡、调色与镜头顺序容易；精细道具和跨景人物一致性需制作

常见误用：全程持续导致麻木；色散让脸和字长期看不清；把所有亮度变化算成切镜。
