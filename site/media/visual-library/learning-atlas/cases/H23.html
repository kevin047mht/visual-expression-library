这一例先看什么

审美判断

H23 · 原作约0—2秒

分析单元 01 / 0—2秒

黑场留白／白字淡入

实际观察

0秒为纯黑，0.083秒起居中白色粗体标题渐亮；0–1.919秒没有切换成动作场景，主体是标题透明度变化。

表达作用（教学解读）

决定什么值得看、什么退到感受层；清晰与模糊、占满与留空之间的关系塑造语气。

具体应用场景

回忆、亲密、孤独、人物介绍、信息减负、画面间的呼吸。

复现建议（非原作者工程还原）

纯黑背景+居中粗体文字，alpha按约定区间渐变；按画布宽高计算锚点，确保字距、对比度和阅读停留。

直出判断：容易，字效机制可直接代码渲染

常见误用：模糊所有层；细字落在高亮区域；浅色误认为高级；没有清楚的主焦点。

景深、柔焦与负空间 →文字排版与逐字动效 →

H23 · 原作约3—63秒

分析单元 02 / 3—63秒

极简字卡／主副标题层级／黄色提示行

实际观察

概览显示大量黑底居中白字，部分下方配黄色小一号解释行；21秒双短句分置左右，54秒短句放大。文字描述镜头而非真的出现英雄/火炮等画面。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

为字卡定义起止时间、文本、字号、对齐、行距、颜色；整卡替换或追加副行。黑场和留白也是版式，应保留可读停留而非不停增加动效。

直出判断：容易，素材需求低；文案与停顿设计仍需人工判断

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

H23 · 原作约65.524—69.444秒

分析单元 04 / 65.524—69.444秒

文字群像／逐层增殖排版／纵向大字淡入

实际观察

左右两侧以不同字号的白字代替英雄与反派，重复小字逐步堆积形成两阵；中央黄色短句保持。约67.109秒起一列纵向衬线大字由暗变亮，68秒以后维持构图。很多字层增加不能累计成很多个换镜。

表达作用（教学解读）

H23 · 原作约83.5—87.421秒

分析单元 05 / 83.5—87.421秒

局部关键词替换／双色强调／逐条副字幕

实际观察

83.584→83.667秒，同一句中的黄色关键词换成蓝色关键词；84.167→84.251秒整行换成较小白色主标题。85.168秒增加黄色副行，86.086秒、87.087秒副行依次替换；黑底与中心锚点稳定。

表达作用（教学解读）

建立段落、材质和情绪的一致性；颜色变化可以承担信息，而不只是美化。

具体应用场景

多片源混剪、人物立场、回忆/现实区分、冷暖转折、品牌统一。

复现建议（非原作者工程还原）

把句子拆为普通字和强调词段，按字体度量拼接并整体居中；强调词独立颜色/起止时间。主标题和副行分别换文本，避免替词后整句左右跳。

直出判断：容易，适合Canvas/SVG/文本渲染后编码直出

常见误用：所有镜头同一滤镜；肤色被破坏；饱和度代替焦点；色彩含义前后矛盾。

色彩组织与选择保色 →文字排版与逐字动效 →

中央快进圆形图标及粗白字保持，周围小字沿横向移动、逐步显露和更换，部分在画面边缘被裁断。这里的快进图标存在于实际源视频，不是浏览器播放器控件；其周围文字滑动不是相机切镜。
