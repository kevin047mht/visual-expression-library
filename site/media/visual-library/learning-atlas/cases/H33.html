H33 / 主要视觉研究样本

【静止画MAD】致作家【蓝色时期】【MADMAX2024】

让静止画产生空间人物与图形对话青春／情绪／成长

LiENRean · 4万播放快照 · <10万 · B站原作 ↗

条带、折页和逐格更新让同一主版式持续有信息；这类视觉密度不能只用硬切率解释。原作者为ALINCO。

从画面里找依据

这一例先看什么

蓝青主色、少量紫粉与黄绿点缀串联圆环、街景、留白画作、折页和画室；64–128秒人物/画作留白平衡前段繁复空间，末段回收已出现内容。

审美判断

中心定义字、三重竖字、漫画对白和单画作的主次较明确；20秒骨架星芒陈列和144秒满屏条带很密，局部可读停留需连续复看，不能据一张繁忙过渡帧否定整片。

迁移到自己的题材

漫画改编、人物回忆、纪念、故事提案、海报动态化、低动作但高情绪密度的段落。

教学提问：前景、中景、背景分别是什么？如果镜头移动，原图未画出的部分由谁补齐？

带画面的分析单元

图像标出取样时间，对应观察中的关键状态。单帧不能独立证明运动，连续性请结合摘录。表达作用与应用场景是教学解读，复现路线是建议，不是原作者工程还原。

H33 · 原作约0—18秒

分析单元 01 / 0—18秒

同心弧形色块／漫画环片／中心定义字

实际观察

黑白漫画底上紫蓝黑白同心断环，各弧旋转/缩放，中心白字定义与关键词替换，纸屑散落。

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

圆环扇段几何+漫画纹理mask，独立旋转/半径变化、中心字层和粒子。

直出判断：简化环片/字层/纸屑容易；漫画精细排布需素材

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →纸张、照片与漫画分格 →

H33 · 原作约18—34秒

分析单元 02 / 18—34秒

三维陈列／骨架物件／星芒／绿漫画框

实际观察

多种物件围绕人物悬浮，亮色星芒与彩色纸屑，接绿色漫画方框、圆周小字和城市网格拼贴。

表达作用（教学解读）

把画面变成可触摸的记忆或记录；纸边、阴影与展示顺序可以表现珍惜、拼凑或碎裂。

具体应用场景

回忆、青春、艺术创作、旅行手记、人物档案、纪念短片。

复现建议（非原作者工程还原）

3D或分层透视卡片+深度模糊、星芒粒子；圆周排字、矩形mask、网格裁切。

直出判断：星芒/圆周字/网格容易；真实骨架与陈列空间需模型素材

常见误用：所有纸张纹理一样重；阴影方向不一致；折页遮挡错误；照片墙只有数量而没有观看顺序。

纸张、照片与漫画分格 →几何拼贴与形状语言 →

H33 · 原作约34—50秒

分析单元 03 / 34—50秒

蓝色漫画街景／透视卷页／人物变条块

实际观察

彩色漫画街景做横向空间移动，蓝色片名层保持；人物剪影逐渐变为密集竖块与网点，再恢复人形。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

漫画场景分层相机，人物alpha作为条块容器，网点与块图层显隐，片名字层独立。

直出判断：简化条块人形/片名容易；完整街景分层补绘和透视较难

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →密度、停留与段落节奏 →

H33 · 原作约50—64秒

分析单元 04 / 50—64秒

三重竖排大字／头像网格／斜条遮挡

实际观察

绿底三重竖字，黑白灰轮替，细竖图和紫色横块叠加；头像网格进入，斜白条遮挡接灰条纹漫画面，再添加人物。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

复制文字层、换色、竖条mask和网格布局，斜条wipe与人物alpha错峰出现。

直出判断：字效/头像网格/斜条转场容易；素材裁切和配色需调试

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →几何拼贴与形状语言 →

H33 · 原作约64—88秒

分析单元 05 / 64—88秒

青色剪影／金色装饰框／漫画撕片

实际观察

青色人物与背景纹理，金色装饰环框住人物；黑白漫画斜切片，蓝底人物持笔，后为极简白底坐姿人物。

表达作用（教学解读）

把短暂破坏作为失控、断裂、冲突或数字材质的提示。

具体应用场景

赛博题材、记忆中断、身份不稳、高潮强调；也可短时掩护连接。

复现建议（非原作者工程还原）

区域着色、纹理与装饰框，多个斜mask按景深排布，前景人物和背景独立。

直出判断：简化着色/装饰框/斜切片容易；细致人体分层需素材

常见误用：全程持续导致麻木；色散让脸和字长期看不清；把所有亮度变化算成切镜。

RGB错位、条带与故障 →色彩组织与选择保色 →

H33 · 原作约88—108秒

分析单元 06 / 88—108秒

蓝色微缩城市／剪纸碎片／漫画说明／极简打字

实际观察

蓝色城市与斑马线有明显空间纵深和人物，后接人物漫画、气泡说明，黑底双语小字逐步出现。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

城市模型或透视图分层，碎片粒子；漫画裁切，字层打字/光标。

直出判断：打字/气泡/碎片容易；城市几何和光影需素材或3D

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →文字排版与逐字动效 →

H33 · 原作约108—130秒

分析单元 07 / 108—130秒

绘画柔光／纵深卡片队列／留白画作

实际观察

人物绘画与高亮散景，黑底图卡沿深度排列飞过，转白底人物群像与单幅画作。

表达作用（教学解读）

决定什么值得看、什么退到感受层；清晰与模糊、占满与留空之间的关系塑造语气。

具体应用场景

回忆、亲密、孤独、人物介绍、信息减负、画面间的呼吸。

复现建议（非原作者工程还原）

图卡四角投影/3D平面、相机纵深移动、景深；画作留白和软投影。

直出判断：有限卡片队列/留白/柔光容易；画作本身需原素材

常见误用：模糊所有层；细字落在高亮区域；浅色误认为高级；没有清楚的主焦点。

景深、柔焦与负空间 →

H33 · 原作约130—146秒

分析单元 08 / 130—146秒

手风琴折页／撕边竖条／连续拼贴

实际观察

白底画作中间展开黑色撕边，多个图页像手风琴沿横向展开，再变满屏竖向撕纸条；条内图案连续替换。

表达作用（教学解读）

把画面变成可触摸的记忆或记录；纸边、阴影与展示顺序可以表现珍惜、拼凑或碎裂。

具体应用场景

回忆、青春、艺术创作、旅行手记、人物档案、纪念短片。

复现建议（非原作者工程还原）

多平面折叠透视、宽度/旋转错峰；噪声扰动竖条边缘、纹理映射与遮罩。

直出判断：简化折页/撕边条带可代码导出；严密内容衔接与立体折页需逐镜调试

常见误用：所有纸张纹理一样重；阴影方向不一致；折页遮挡错误；照片墙只有数量而没有观看顺序。

纸张、照片与漫画分格 →形状遮挡、擦除与揭示 →

H33 · 原作约146—163.285秒

分析单元 09 / 146—163.285秒

窗光画室／画架／条块片尾

实际观察

明亮极简房间地上有条形窗影，画架放蓝色人物画；后白底小署名和竖向网点条块片尾。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

房间用3D或透视源图，软阴影/光束；画架贴图，片尾条块几何与字层。

直出判断：简化窗影/条块/字层容易；真实房间空间与画架需美术或3D

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →

短时变化怎样理解

132秒折页、136–144秒撕边条带显示版式连续演变，片尾画室给主体明确落点；既有专项密集记录证明条内更新与全屏硬切有区别。本轮复看为概览，不声称全片连续流畅。

把镜头连接、版式更新、局部图层变化和镜内运动分开记录。所查窗口是下限，不是全片平均或AI／人工排名。
