AI06 · 原作约0—108秒

分析单元 01 / 0—108秒

琥珀终端界面／细线面板／低亮度 HUD

实际观察

整体黑底黄字，左侧经纬线球、右侧图形、最右状态条与底部小字；大多信息较小、低对比，风格统一但可读性需更大屏检查。

表达作用（教学解读）

用规则、选择与反馈组织关系，让抽象状态可被看见。

具体应用场景

人物关系、搜索、等待、推理、产品功能解释、系统压力；数值需要真实含义或明确虚构设定。

复现建议（非原作者工程还原）

统一调色板与网格，细线画框，等宽字，小数值定时更新，独立分区用裁切蒙版。

直出判断：容易代码直出；实际阅读字号/对比需校对

常见误用：假数据制造伪解释；辅助文字太暗；每个窗口同时运动；手机界面只是装饰外壳。

AI06 · 原作约6—90秒

分析单元 02 / 6—90秒

阶梯波形／椭圆轨道／线框球旋转

实际观察

6秒阶梯线、12秒轨道、42秒单轨道，90秒球与轨道并置。运动模块反复使用而非每段全新场景。

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

正交线段插值、椭圆参数运动；经纬线球3D投影后画线，按时间改角度与数值。

直出判断：容易到中等，不需逐帧人工画

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

AI06 · 原作约30—78.6秒

分析单元 03 / 30—78.6秒

随机亮块／棋盘置换／中心红圆与辐射线

实际观察

76.625–78.458右窗黄黑方块逐格亮灭，中心红点位置变化；78.542只剩较小中央光块与线框物体，左球和外框保留。

表达作用（教学解读）

固定左球与外框，把变化限制在右侧模块，以局部变化维持系统的连续性。

具体应用场景

进度反馈、同一系统中的状态更换、实验／操作结果对照；辅助区应有足够对比，不把低亮度当复杂度。

复现建议（非原作者工程还原）

规则网格按伪随机种子/音量控制alpha，中心圆与径向线单独层；按缩放与淡出转下一图形。

直出判断：容易，动态纹理不是一格一刀的快剪

常见误用：假数据制造伪解释；辅助文字太暗；每个窗口同时运动；手机界面只是装饰外壳。

AI06 · 原作约48—108秒

分析单元 04 / 48—108秒

曲线图／进度条／雷达与频谱样式

实际观察

48秒增长填充曲线，60/72秒横条，96秒圆形雷达，108秒点阵频谱。没有证据证明显示的是实时测量数据。

表达作用（教学解读）

把可控规则变成可见变化；通过不变量、比例和相位建立秩序或空间。

具体应用场景

概念解释、音乐可视化、抽象世界、图表、程序艺术。

复现建议（非原作者工程还原）

数组驱动折线与填充，多条矩形按数值伸长；雷达扇区alpha、频谱矩形阵列；可用手工动画或真实音频数据。

直出判断：机制容易；真实数值和音频响应需数据与校验

常见误用：符号无含义；空间复杂度替代概念清晰；将程序生成误等同于文生视频生成。

AI06 · 原作约112.7—168秒

分析单元 05 / 112.7—168秒

大日期数字／像素小图标／逐项时间线／终端打字

实际观察

112.708–114.625日期大字构图稳定；120秒人物像素头像，126火箭、132建筑、138设备，144/156有命令行，150多个小人。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

像素图由低分辨率遮罩最近邻放大，日期按字符排版；左侧事件列表逐行加入，终端文本按字符揭示并画游标。

直出判断：容易，需素材或简单像素图及文字校对

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

AI06 · 原作约252—318秒

分析单元 07 / 252—318秒

地图轮廓／单色报纸版式／状态面板收束

实际观察

地图多次出现，294秒报纸式红色报头与黄字像素图，300秒红圆放射线，312–318地图加右侧文字。

表达作用（教学解读）

把画面变成可触摸的记忆或记录；纸边、阴影与展示顺序可以表现珍惜、拼凑或碎裂。

具体应用场景

回忆、青春、艺术创作、旅行手记、人物档案、纪念短片。

复现建议（非原作者工程还原）

SVG地图/遮罩填充，文字线框排版，点线路径叠加；报纸版式用矩形区域和字层组合。

直出判断：有合法地图素材时容易；此处不判断地图细节/历史准确性

常见误用：所有纸张纹理一样重；阴影方向不一致；折页遮挡错误；照片墙只有数量而没有观看顺序。
