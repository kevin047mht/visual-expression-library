分析单元 01 / 4—12秒

手绘纸框／人物差分／竖排条签

实际观察

红底米色不规则画框内人物表情和手部道具变化，随后两个人物全身像与竖排字条同框。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

透明人物差分、纸边蒙版、文本逐段显隐，主体按预设镜头表摆放。

直出判断：合成容易；一致的人物差分和动作需素材制作

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

AI07 · 原作约43.5—45.5秒

分析单元 03 / 43.5—45.5秒

道具替换／白烟遮挡／兔子放大过镜

实际观察

44.167秒附近持牌手变空手，44.417秒白烟包围手，44.75秒胡萝卜出现，45秒兔子进入，45.333秒兔子被大幅放大遮住画面。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

手势差分与道具图层分开，在烟团遮挡时替换道具，兔子图层缩放越过镜头。

直出判断：烟团和缩放容易；干净手势与兔子差分需要素材

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

动作、视线与形状匹配 →语义选材与意象蒙太奇 →

AI07 · 原作约60—72秒

分析单元 04 / 60—72秒

双人物道具交互／细线牵引／斜置小窗

实际观察

角色举杯，之后两个人物、狗与细绳同框，再转米色倾斜人物小窗。

表达作用（教学解读）

复杂表演与形体变化通常来自镜头素材本身。先明确事件与连续性要求，再选择拍摄、原动画、生成或三维等获取路线。

具体应用场景

近身动作、幻想形变、角色交互、复杂环境事件。已有源片时先辨认并保留动作因果，不把全部动作记作后期增量。

复现建议（非原作者工程还原）

人物和杯子分层绑定，线段两端跟随道具位置，小窗透视旋转。

直出判断：规则图层容易，交互遮挡和肢体一致性需返工

常见误用：连续性靠闪光掩盖；人手/道具无因果变化；把模型内部运镜当全部剪辑能力；承诺单次稳定长表演。

复杂动作与镜头素材 →画中画、分屏与局部拼贴 →

AI07 · 原作约104—116秒

分析单元 06 / 104—116秒

杂耍球轨迹／手绘纸框／舞台帘幕遮挡

实际观察

角色周围黄色球在多个位置，随后红色帘幕覆盖画面。概览确认球的多位置，未据此验证完整抛接动作。

表达作用（教学解读）

把画面变成可触摸的记忆或记录；纸边、阴影与展示顺序可以表现珍惜、拼凑或碎裂。

具体应用场景

回忆、青春、艺术创作、旅行手记、人物档案、纪念短片。

复现建议（非原作者工程还原）

球体按相位错开的抛物线或循环轨道运动，角色姿态差分同步；帘幕遮罩合拢。

直出判断：球轨迹与帘幕容易，准确抛接和手部配合需调试

常见误用：所有纸张纹理一样重；阴影方向不一致；折页遮挡错误；照片墙只有数量而没有观看顺序。
