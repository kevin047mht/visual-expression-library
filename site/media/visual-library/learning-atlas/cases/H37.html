H37 · 原作约0—9秒

分析单元 01 / 0—9秒

星空原片／RGB边缘／头像拼贴

实际观察

星空双人接眼部特写，多张人物矩形卡覆盖在女主大脸上；后为暖窗前男主。

表达作用（教学解读）

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

具体应用场景

记忆、对话、关系对照、主观视点、多人角色介绍、跨素材呼应。

复现建议（非原作者工程还原）

已有镜头裁切，通道偏移和轻虚化；矩形小窗排列、逐层显隐。

直出判断：RGB/小窗拼贴容易；星空和人物原动画需源片

常见误用：窗口太多无主次，眼位错位、边框挤脸，层的出现没有叙事理由。

画中画、分屏与局部拼贴 →RGB错位、条带与故障 →

H37 · 原作约9—22秒

分析单元 02 / 9—22秒

暗角聚光／光屑／大面积插入人物卡

实际观察

暗处跪姿、怒脸和战斗后，浮动光点与人物轮廓；16.7–18.7插入数张大人物画面。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

暗角和曝光、光点贴图；插入片段用矩形mask及scale/opacity。

直出判断：简化光屑/暗角/插入容易；原动作和投影来源待逐源对照

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →景深、柔焦与负空间 →

H37 · 原作约22—34秒

分析单元 03 / 22—34秒

窄横幅／拉弓动作匹配／青蓝魔法圈

实际观察

窄画幅与紫色人物动作，多个拉弓近景快速替换，接落脚电弧、蓝绿圆形法阵和竖条小窗。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

画幅遮罩、按动作姿态选镜、矩形/竖条遮罩、圆环几何发光。

直出判断：画幅/遮罩/简化圆环容易；原作能量几何不能全归UP

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

动作、视线与形状匹配 →密度、停留与段落节奏 →

金色角色上叠矩形脸局部，构图拉宽；菱形小窗悬于剑原背景，再缩小人物窗淡出。

表达作用（教学解读）

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

具体应用场景

H37 · 原作约43—61秒

分析单元 05 / 43—61秒

灰白人物／数字噪声／红紫爆发／插帧

实际观察

人物背后细条状数字噪声，接大规模红橙对冲，脸部小矩形插入和竖向分栏，最后蓝白特写。

表达作用（教学解读）

把短暂破坏作为失控、断裂、冲突或数字材质的提示。

具体应用场景

赛博题材、记忆中断、身份不稳、高潮强调；也可短时掩护连接。

复现建议（非原作者工程还原）

噪声流图层、去色/色阶、矩形局部替换与分栏；原爆破画面沿用。

直出判断：数字噪声/去色/矩形分栏容易；爆破与战斗需源视频

常见误用：全程持续导致麻木；色散让脸和字长期看不清；把所有亮度变化算成切镜。

RGB错位、条带与故障 →画中画、分屏与局部拼贴 →
