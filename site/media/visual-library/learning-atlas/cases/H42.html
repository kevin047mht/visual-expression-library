冷灰漫画与紫发绿眼建立人物焦点；窗列和面部反打改变心理距离，雪和纸纹承担的是空气与记忆材质。

从画面里找依据

这一例先看什么

漫画着色、景深分层、胶片字层、纸纹投影和红框窗列有统一材质，角色与背景之间有空间组织。

审美判断

紫发绿眼和冷灰底突出主体，底部双行小字幕、暖段白字有相对稳定层级；部分暗脸细节有限。

迁移到自己的题材

漫画改编、人物回忆、纪念、故事提案、海报动态化、低动作但高情绪密度的段落。

教学提问：前景、中景、背景分别是什么？如果镜头移动，原图未画出的部分由谁补齐？

带画面的分析单元

图像标出取样时间，对应观察中的关键状态。单帧不能独立证明运动，连续性请结合摘录。表达作用与应用场景是教学解读，复现路线是建议，不是原作者工程还原。

H42 · 原作约0—13.6秒

分析单元 01 / 0—13.6秒

漫画着色／人物背景分层／暗角与小字幕

实际观察

人物绿眼、紫发与冷背景，前景脸和城市/屋内背景有景深差；双行外文/中文小字幕。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

漫画抠图并补背景、区域着色，前景相机微移、背景虚化、暗角；字幕独立层。

直出判断：字幕/虚化/暗角容易；精细着色补绘和头发分层需逐图处理

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →景深、柔焦与负空间 →

H42 · 原作约13.6—17秒

分析单元 02 / 13.6—17秒

胶片字层／白闪X形遮罩／横向故障

实际观察

躺姿人物上叠胶片框和大字，白闪和X形接双人漫画；横条位移、噪点及橙色脸特写。

表达作用（教学解读）

把注意力从旧信息带往新信息；遮满时换底图，保持方向或形状上的联系。

具体应用场景

章节转换、空间跨越、角色亮相、画内物体自然遮挡后的换景。

复现建议（非原作者工程还原）

胶片齿孔贴图、字层粗糙遮罩、X形mask替换底图，条带分块位移与噪声、色映射。

直出判断：简化胶片/白闪/X遮罩/条带容易；精细多层排布需调试

常见误用：每镜不同花哨转场；遮罩与运动方向相反；过渡比内容本身更长；遮挡未满就穿帮。

形状遮挡、擦除与揭示 →RGB错位、条带与故障 →

H42 · 原作约18—28.3秒

分析单元 03 / 18—28.3秒

浅景深／眼部特写／俯视人物与白底碎片

实际观察

人物与室内背景分层，脸部推近、俯视人物脚下投影，白底人物旁有飞散碎片。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

人物、投影、背景分别运动，碎片粒子+运动模糊，白底用alpha合成。

直出判断：简化投影/碎片容易；人物视角变化和补绘需素材

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →粒子、花瓣、雪与碎片 →

H42 · 原作约29.5—37.92秒

分析单元 04 / 29.5—37.92秒

粉花／景深建筑／雪粒子

实际观察

花在前景、远处塔楼虚化；双人站于雪街，后转人物背影离开门口。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

花/人物/建筑分层，雪点分大小/速度/模糊表现深度，前景遮罩保留。

直出判断：有素材后雪/景深容易；细致漫画着色和建筑原图需处理

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →漫画分层与2.5D视差 →

H42 · 原作约37.92—46.6秒

分析单元 05 / 37.92—46.6秒

暂停符号画框／烟花背光／阴影扫脸

实际观察

画框内双人有暂停图标，接烟花双人近景、人物侧面和正脸，面部阴影/虚焦变化。

表达作用（教学解读）

决定什么值得看、什么退到感受层；清晰与模糊、占满与留空之间的关系塑造语气。

具体应用场景

回忆、亲密、孤独、人物介绍、信息减负、画面间的呼吸。

复现建议（非原作者工程还原）

画框角点透视贴图，暂停符号矢量叠加，烟花与光斑粒子，移动软遮罩控制阴影。

直出判断：简化图标/烟花/软阴影容易；人物发丝/源动画归属待对照

常见误用：模糊所有层；细字落在高亮区域；浅色误认为高级；没有清楚的主焦点。

景深、柔焦与负空间 →

H42 · 原作约46.6—52.08秒

分析单元 06 / 46.6—52.08秒

全身纸纹／花瓣投影／竖排字

实际观察

暖纸纹底全身人物，花瓣状影子掠过；后海边人物配竖排小字。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

纸纹底层、人物抠图、前景叶片/花瓣及模糊投影，竖排字分列揭示。

直出判断：纸纹/投影/竖字容易；抠图边缘需处理

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →粒子、花瓣、雪与碎片 →

H42 · 原作约52.08—57.2秒

分析单元 07 / 52.08—57.2秒

红框窗列／横向遮挡／脸部反打

实际观察

红色窗框状前景连续横移，人物从窗间可见；54.2转女脸，55.52转男脸，中间短黑。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

前景窗列平铺横移加运动模糊，人物后层遮挡；竖字独立保持，黑帧接反打。

直出判断：简化窗列遮挡、字效、反打容易；原窗列场景/来源需对照

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

动作、视线与形状匹配 →漫画分层与2.5D视差 →

H42 · 原作约58.4—66.12秒

分析单元 08 / 58.4—66.12秒

面部到暖色双人／横向光晕／赛事片尾

实际观察

人物面部接夕照双人，蓝色横光和暖背光，转黑后赛事标。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

横光条screen叠加、人物轮廓暖光遮罩、淡黑；赛事标为公共包装单列。

直出判断：简化横光和淡出容易；双人美术/动作需要素材

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →
