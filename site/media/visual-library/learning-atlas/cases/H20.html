H20 · 原作约0—4秒

分析单元 01 / 0—4秒

圆形头像／火环片头

实际观察

黑底头像周围橙黄色环状火光，下方紫色描边署名。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

圆形裁切头像，环形噪声遮罩加发光与沿圆周流动；署名描边淡入。

直出判断：简化火环和署名容易；头像须提供或原创

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

H20 · 原作约4—94秒

分析单元 02 / 4—94秒

宽画幅／粉色字幕／语义选段

实际观察

主要用动画全景、人物反应、表情特写串联；下方黑边有粉色描边字幕，有的字幕亮度渐变。

表达作用（教学解读）

利用相邻镜头改变理解，使原来无关的画面形成主题、对比或关系。

具体应用场景

纪念、广告、人物关系重组、旅行随笔、社会观点、品牌回顾。

复现建议（非原作者工程还原）

固定上下留边，授权字体填充/描边，透明度关键帧；根据动作和语义选段。

直出判断：画幅、字幕和硬切容易；选段准确性需看源片并听审

常见误用：素材只因好看而排列；上下文失真；借剪接制造未经支持的事实判断。

H20 · 原作约26—28秒

分析单元 03 / 26—28秒

反应插窗／表情夸张

实际观察

茶杯接双人，再出现横条表情窗口扩张到大脸，随后回双人。

表达作用（教学解读）

把短暂破坏作为失控、断裂、冲突或数字材质的提示。

具体应用场景

赛博题材、记忆中断、身份不稳、高潮强调；也可短时掩护连接。

复现建议（非原作者工程还原）

可用裁切矩形、缩放和边缘亮线模拟插窗；原素材也可能已包含该动画处理。

直出判断：模拟横条插窗容易；不能确认由UP新增

常见误用：全程持续导致麻木；色散让脸和字长期看不清；把所有亮度变化算成切镜。

分析单元 04 / 54—60秒

星芒／可爱气氛背景

实际观察

人物旁的亮黄色背景有许多白色星芒，后为双人近景。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

星芒由十字线/菱形随机位置、尺寸与透明度闪动，背景渐变。

直出判断：简化星芒容易；此处不能把原动画星芒算UP新增

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

H20 · 原作约94—98秒

分析单元 05 / 94—98秒

竖向分屏／局部眼睛特写

实际观察

94秒双人近景，约94.84起右侧加眼睛特写分区；96.16前后换到户外人物场景。

表达作用（教学解读）

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

具体应用场景

记忆、对话、关系对照、主观视点、多人角色介绍、跨素材呼应。

复现建议（非原作者工程还原）

两个裁切窗口并排，右侧从窄到宽揭示，文字独立覆盖。

直出判断：分屏与局部放大容易；是否来自源动画需对照工程

常见误用：窗口太多无主次，眼位错位、边框挤脸，层的出现没有叙事理由。
