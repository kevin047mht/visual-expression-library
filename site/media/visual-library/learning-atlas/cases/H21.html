H21 · 原作约0—32秒

分析单元 01 / 0—32秒

红白动力文字／透视厚度

实际观察

灰黑场景上红白英文词随画面构图出现，部分斜置、具厚度和前后字层。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

独立文字层做透视、偏移副本假挤出，逐字或逐词揭示，关键帧安排位置。

直出判断：简化透视动力字容易；复杂字层遮挡需排布

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →漫画分层与2.5D视差 →

H21 · 原作约32—40秒

分析单元 02 / 32—40秒

选择性去色／眼部红色横光

实际观察

森林与角色多为灰白，红衣领保留；眼部横向红光跟随人物。36秒附近夹多次极短黑帧。

表达作用（教学解读）

建立段落、材质和情绪的一致性；颜色变化可以承担信息，而不只是美化。

具体应用场景

多片源混剪、人物立场、回忆/现实区分、冷暖转折、品牌统一。

复现建议（非原作者工程还原）

颜色范围遮罩去色，跟踪眼部位置叠光条和辉光；黑帧独立事件处理。

直出判断：去色和光条容易；快速遮挡跟踪中等

常见误用：所有镜头同一滤镜；肤色被破坏；饱和度代替焦点；色彩含义前后矛盾。

色彩组织与选择保色 →画中画、分屏与局部拼贴 →

H21 · 原作约44—52秒

分析单元 03 / 44—52秒

波纹扭曲／色散／横向条带

实际观察

局部画面呈虹彩边缘、液体波纹和横向位移带。

表达作用（教学解读）

把短暂破坏作为失控、断裂、冲突或数字材质的提示。

具体应用场景

赛博题材、记忆中断、身份不稳、高潮强调；也可短时掩护连接。

复现建议（非原作者工程还原）

噪声/正弦位移贴图，RGB通道微偏移，分条带偏移并在峰值替换底图。

直出判断：简化波纹、色散、条带容易直出

常见误用：全程持续导致麻木；色散让脸和字长期看不清；把所有亮度变化算成切镜。

RGB错位、条带与故障 →

H21 · 原作约56—58.8秒

分析单元 04 / 56—58.8秒

宽画幅插窗／人物越框／冲击变焦

实际观察

火焰图像在宽幅窗口内，人物可越过窗口；战斗近景之间有径向模糊。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

抠出前景人物置于遮罩窗口上层，中心缩放与径向模糊连接；抠图边缘需处理。

直出判断：画幅遮罩/变焦容易；前景越框需抠图

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →

H21 · 原作约100—128秒

分析单元 07 / 100—128秒

暗红人物／同心弧／透视速度通道

实际观察

暗红面部与浮字，倒置人物前有粉白弧线扇形；后为长透视线和彩色亮点。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

弧线/扇形程序绘制，沿消失点伸展线条，前后层景深与发光。

直出判断：弧线、速度线和亮点容易；人物素材需提供

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →RGB错位、条带与故障 →

H21 · 原作约132—152秒

分析单元 08 / 132—152秒

战斗叠字／色条／菱形网格

实际观察

战斗上叠大字，纵向彩色条，后段倾斜字和亮菱形网格。

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

文字层分组运动，矩形遮罩揭示，重复菱形透视排布与辉光。

直出判断：简化字效、色条和网格容易

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →文字排版与逐字动效 →
