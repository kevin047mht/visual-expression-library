H35 · 原作约3—14.52秒

分析单元 01 / 3—14.52秒

青色发光碎片／粒子隧道／光束辉光

实际观察

开头概览人物前后叠青色方片，6–9秒出现光束与发光矩形；13.320–14.280秒密集帧为深色空间中向外延展的矩形碎片与细线，同一构图持续运动。

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

准备矩形/线段粒子，沿纵深分布，按相机透视投影与时间移动；亮部多层模糊叠加模拟Bloom。人物、背景分层后叠加统一青色调。

直出判断：基础版容易，精确粒子速度、光束和纵深关系需调试

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

发光字、光迹与轮廓光 →粒子、花瓣、雪与碎片 →

H35 · 原作约14.28—15.24秒

分析单元 02 / 14.28—15.24秒

文字带翻转收拢／圆形虹膜开场／失焦到清晰

实际观察

14.360秒横排歌词带转斜，14.520秒呈弯曲闭合外观；14.600秒黑场，14.680秒中央小圆孔显出新背景，14.840秒背景充满画面，随后逐渐变清晰，15.240秒又进入浅色过渡画面。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

文本预合成做2.5D旋转/弯曲变形并缩小，圆形alpha遮罩半径从0到对角线；新背景模糊半径随时间递减。外观不足以确定真实3D或具体AE插件。

直出判断：圆形遮罩和模糊容易，连续文字变形需定制

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →形状遮挡、擦除与揭示 →

H35 · 原作约18—27秒

分析单元 03 / 18—27秒

横幅遮罩／双语细排版／分屏窗口

实际观察

18秒概览是模糊人物背景上叠清晰天空横条与细圆圈；21秒宽画幅海边插画占中间，27秒手掌天空与人物小窗叠在同一画面，配细长文字线。

表达作用（教学解读）

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

具体应用场景

记忆、对话、关系对照、主观视点、多人角色介绍、跨素材呼应。

复现建议（非原作者工程还原）

同一底图复制一层模糊；上方用矩形蒙版呈现另一图像，加入细线、圆圈、日文大字及小号英文排版。

直出判断：容易到中等，图片及文字的版式需要设计

常见误用：窗口太多无主次，眼位错位、边框挤脸，层的出现没有叙事理由。

画中画、分屏与局部拼贴 →形状遮挡、擦除与揭示 →

H35 · 原作约33—42秒

分析单元 04 / 33—42秒

相框照片漂移／发光心电线／散景光点

实际观察

33秒插画叠半透明矩形边框；36秒白边照片倾斜悬在空中；39秒出现带发光红芯的折线；42秒人物前后散布黄白光点。以上为概览观察，未验证所有中间运动曲线。

表达作用（教学解读）

把画面变成可触摸的记忆或记录；纸边、阴影与展示顺序可以表现珍惜、拼凑或碎裂。

具体应用场景

回忆、青春、艺术创作、旅行手记、人物档案、纪念短片。

复现建议（非原作者工程还原）

照片贴图加白色外框，做旋转/缩放/位置动画；折线路径逐段揭示加Glow；光点按大小、模糊和速度分层。

直出判断：机制容易，现成插画和光点参数齐全后可代码导出

常见误用：所有纸张纹理一样重；阴影方向不一致；折页遮挡错误；照片墙只有数量而没有观看顺序。

纸张、照片与漫画分格 →发光字、光迹与轮廓光 →

H35 · 原作约48—69秒

分析单元 05 / 48—69秒

前景虚焦遮挡／倾斜图像框／网格圆环字／半色调纹理

实际观察

48秒神社场景前景黑色叶影虚焦，51秒画幅和上下英文条倾斜；63秒人物横条放在网格上，圆周环排小字；66秒人物附近有点状网纹，69秒画面下半变黑并出现细圆线。

表达作用（教学解读）

用少量形状、方向和重复建立性格，让图形与人物一起表达轻盈、秩序或紧张。

具体应用场景

青春、角色介绍、音乐视觉、活动包装、清楚的图形风格。

复现建议（非原作者工程还原）

把人物/前景叶片/背景分层，近景层加模糊并相对移动；图像矩形做旋转；网格重复绘线，圆弧逐字布局，半色调用点阵蒙版。

直出判断：基础几何和纹理容易，抠图及遮挡关系中等

常见误用：形状种类与颜色都无限增加；图形仅为填空；不顾人物视线与轮廓。

几何拼贴与形状语言 →漫画分层与2.5D视差 →

H35 · 原作约72—81秒

分析单元 06 / 72—81秒

叶片剪影前景／花瓣漂浮／夜景星光统一调色

实际观察

72–75秒同一双人插画前叠黑色叶片，75秒加入浅色花瓣；78–81秒变成蓝色夜景、亮色星点/流光与水面人物。概览显示合成层次，不能据此断言人物本身被逐帧手绘或补帧。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

预先提取人物和背景，叶片用透明PNG/路径，花瓣以旋转精灵运动，统一蓝色调并加发光点与前景虚焦。

直出判断：粒子和调色容易，人物分层和景深关系需素材处理

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →漫画分层与2.5D视差 →

H35 · 原作约84—85.92秒

分析单元 07 / 84—85.92秒

竖条揭示／白色曝光脉冲／人物高反差叠化

实际观察

84.000秒两条竖窗分开显示人物，84.080秒扩成完整插画；84.160–84.560秒同图逐渐过曝再恢复。85.200秒起新人物以半透明/高反差紫白形态叠入，85.600秒清晰，85.760秒背景换成蓝色并保留前景人物；下方字幕条随后出现。

表达作用（教学解读）

把注意力从旧信息带往新信息；遮满时换底图，保持方向或形状上的联系。

具体应用场景

章节转换、空间跨越、角色亮相、画内物体自然遮挡后的换景。

复现建议（非原作者工程还原）

竖向矩形蒙版展开；曝光或白色罩层alpha做短脉冲；新人物透明层由alpha0到1，叠一层阈值/反差调色作过渡，最后撤旧背景换新背景。

直出判断：容易到中等，需要干净人物素材和逐帧调整叠化节奏

常见误用：每镜不同花哨转场；遮罩与运动方向相反；过渡比内容本身更长；遮挡未满就穿帮。

形状遮挡、擦除与揭示 →漫画分层与2.5D视差 →

H35 · 原作约96—105秒

分析单元 08 / 96—105秒

环形路径排字／细圆HUD／粉紫辉光粒子

实际观察

96秒概览深色人物旁有纵排英文字和横向标题；99秒黑底双细圆与环绕小字；102–105秒天使插画前出现粉紫亮点和中央泛光。仅概览，不把亮度变化次数计作切镜。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

SVG/Canvas绘圆并按弧长定位文字，主体文字居中；人物贴图上叠粉色点精灵与多层模糊光斑，亮度按时间包络控制。

直出判断：基础版容易，细致字体与光线氛围需调试

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

分析单元 09 / 108—126秒

胶片条空间拼贴／前后景虚焦／画内素材替换／打字式字幕

实际观察

108秒后多条带齿孔胶片交叉、重复人物图像。113–114秒主要是虚焦的画内人物图向外露出边框，115.160→115.280秒胶片中的图像从人物/灰色背景换成青色碎片，胶片结构持续；116秒更多胶片随视野扩大显露。小白字约114.440秒起逐字增加。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景
