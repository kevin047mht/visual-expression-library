分析单元 01 / 0—12秒

霓虹废墟／紫色巨球／漫画城市／手势

实际观察

人物和紫色巨球、黑白漫画城市、白发人物手势轮换，与系列前两话存在明显相同画面。

表达作用（教学解读）

建立段落、材质和情绪的一致性；颜色变化可以承担信息，而不只是美化。

具体应用场景

多片源混剪、人物立场、回忆/现实区分、冷暖转折、品牌统一。

复现建议（非原作者工程还原）

系列镜头再选取，紫球可圆mask+辉光简化；原人物/城市场景由生成素材提供。

直出判断：简化紫球/漫画阈值容易；精确城市人物需素材

常见误用：所有镜头同一滤镜；肤色被破坏；饱和度代替焦点；色彩含义前后矛盾。

分析单元 07 / 94.4—110秒

召唤碎石／红色俯冲／冲击帧／城市烟尘

实际观察

石块围绕召唤人物飞出，红光人物俯冲，金环与黑白冲击帧后城市被灰烟吞没，再切角色和废墟。

表达作用（教学解读）

短暂中断视觉连续性，强调接触、转折或心理断裂；其价值来自前后的对比。

具体应用场景

打击点、快速连接、记忆跳跃、段落转折；需要根据内容选择强度。

复现建议（非原作者工程还原）

短镜重组、粒子/径向环/阈值冲击帧；整体场景由生成镜头提供。

直出判断：简化冲击环/阈值/烟层容易；大场面和角色动作难

常见误用：把闪烁当节奏本身；没有稳定画面作参照；为掩盖动作不清持续加闪。
