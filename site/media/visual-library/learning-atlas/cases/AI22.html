AI22 · 原作约5—16.1秒

分析单元 01 / 5—16.1秒

发光骰子阵列／标题压暗背景／渐隐转场

实际观察

单颗线框骰子变密集彩色骰子阵列；14.1–15.5秒标题稳定，15.567秒开始渐暗，16秒转空背景。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

实例化立方体与骰点、随机旋转，标题独立层，背景亮度和透明度包络。

直出判断：基础版可做，数量与镜头需性能调试

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →发光字、光迹与轮廓光 →

AI22 · 原作约20—38秒

分析单元 02 / 20—38秒

投掷计数／柱状分布生长／曲线描出

实际观察

骰子按结果落入列，36–38秒柱形和拟合曲线保持同版式，顶部投掷结果替换、总次数增长，随后淡出。

表达作用（教学解读）

把可控规则变成可见变化；通过不变量、比例和相位建立秩序或空间。

具体应用场景

概念解释、音乐可视化、抽象世界、图表、程序艺术。

复现建议（非原作者工程还原）

随机数或预设数据驱动柱高、累计曲线、数字和小图标。

直出判断：容易；增长数字不是独立换镜

常见误用：符号无含义；空间复杂度替代概念清晰；将程序生成误等同于文生视频生成。

AI22 · 原作约85—125秒

分析单元 04 / 85—125秒

粒子随机运动／分枝聚合／格点火势／阈值滑杆

实际观察

粒子围绕中心运动，树枝状结构长出，绿色格点上出现橙色区域并配概率滑杆与覆盖率。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

随机游走、扩散聚合、格点状态更新，参数绑定滑杆和统计图。

直出判断：可以程序输出，模拟规模与稳定性需调试

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。
