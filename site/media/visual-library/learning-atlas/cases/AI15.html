AI15 · 原作约0—24秒

分析单元 01 / 0—24秒

幻想森林／第一人称手部／蓝色魔法雾

实际观察

暗森林中发光花和漂浮亮点，手从第一人称视角伸向蓝雾，再见远处裙装人物。

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

场景与人物镜头先制作；简单雾和粒子可叠加，但手与雾的遮挡交互需蒙版或生成。

直出判断：基础雾与发光容易；可靠的人物交互生成需筛选

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

AI15 · 原作约32—56秒

分析单元 02 / 32—56秒

废墟城市建立镜头／梦境与现实切换

实际观察

森林过渡到毁坏的秋叶原，汽车、建筑废墟、街道远景交替，随后出现黑场。概览只能描述跨段场景。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

不同场景镜头按叙事排序，以硬切或黑场连接；烟雾和调色可后期补充。

直出判断：剪辑连接容易，复杂场景美术需生成或制作

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →巨构、雾层与尺度参照 →

AI15 · 原作约64—96秒

分析单元 03 / 64—96秒

第一人称车厢对话／战术地图界面

实际观察

车厢人物近景持续，前景枪和手参与；96秒地图分区、倒计时、信息栏占满画面。

表达作用（教学解读）

用规则、选择与反馈组织关系，让抽象状态可被看见。

具体应用场景

人物关系、搜索、等待、推理、产品功能解释、系统压力；数值需要真实含义或明确虚构设定。

复现建议（非原作者工程还原）

对话镜头生成或拍摄，地图用矢量分区、文字和状态条程序绘制；再合成进设备或独立画面。

直出判断：清晰战术UI可确定性绘制，人物表演与前景交互需筛选

常见误用：假数据制造伪解释；辅助文字太暗；每个窗口同时运动；手机界面只是装饰外壳。

界面、菜单与信息面板 →密度、停留与段落节奏 →

AI15 · 原作约133—135秒

分析单元 04 / 133—135秒

连续跟随运镜／硬切到瞭望塔

实际观察

士兵从帐篷门口走入，视角跟随，134.434秒切到铁丝网后的瞭望塔。

表达作用（教学解读）

以观看距离和运动方向改变心理距离，让观众发现、逼近、远离或重新理解对象。

具体应用场景

环境揭示、人物情绪、冲刺、回忆、同一张图中的细节发现。

复现建议（非原作者工程还原）

将连续动作素材与建立镜头连接，保持空间方向一致。

直出判断：切镜容易，连续人物动画和空间一致性需素材

常见误用：每镜都推近；速度变化没有事件依据；把同镜转动误算为剪辑；光流扭曲当成流畅。

镜头推拉、跟随与变速 →动作、视线与形状匹配 →

AI15 · 原作约182—184秒

分析单元 05 / 182—184秒

动作反打／射手近景／目标全景

实际观察

目标在同一街面持续晃动；183.083秒切射手近景，183.55秒回到目标全景。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

按动作方向组织正反打；人物动作在镜头内继续，射击细节不能由静帧判断音画同步。

直出判断：剪辑容易，射手姿态与动作连贯需审核

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

动作、视线与形状匹配 →密度、停留与段落节奏 →

AI15 · 原作约232—288秒

分析单元 06 / 232—288秒

手机画中画／暖色回忆／冷暖叙事对照

实际观察

第一人称看手机中的粉发人物，随后转到樱花场景与牵手视角，再回暗色车厢。

表达作用（教学解读）

利用相邻镜头改变理解，使原来无关的画面形成主题、对比或关系。

具体应用场景

纪念、广告、人物关系重组、旅行随笔、社会观点、品牌回顾。

复现建议（非原作者工程还原）

手机屏幕用四角透视贴图或生成；回忆镜头暖调，现实冷调，按叙事位置切换。

直出判断：屏幕替换和冷暖调色容易；牵手与人物一致性需制作

常见误用：素材只因好看而排列；上下文失真；借剪接制造未经支持的事实判断。

语义选材与意象蒙太奇 →色彩组织与选择保色 →

AI15 · 原作约384—408秒

分析单元 07 / 384—408秒

剖面建筑信息图／设备屏幕透视

实际观察

设备屏幕展示多层建筑剖面和绿色高亮楼层。许多细字不宜从概览判断为正确内容。

表达作用（教学解读）

用熟悉尺寸与层次，让宏大空间被感知；留停帮助观众建立尺度。

具体应用场景

世界观、建筑概念、场景设定、神圣、敬畏、孤独和压迫。

复现建议（非原作者工程还原）

程序绘制建筑楼层、标签与高亮，输出平面UI再用四角透视合成到屏幕。

直出判断：规则信息图适合直出；真实可读文字应程序排版

常见误用：没有比例参照；每镜同一宏大构图；雾遮住所有结构；反射与相机运动不一致。

巨构、雾层与尺度参照 →漫画分层与2.5D视差 →
