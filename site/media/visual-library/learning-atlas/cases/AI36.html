AI36 · 原作约0—36秒

分析单元 01 / 0—36秒

黑底提示／红黑环境／书法标题

实际观察

开头黑底白字红色重点，4–28秒红云火光和异象眼睛，32秒暗红大书法，36秒左侧白色竖向书法。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

文字独立渲染为透明层，红/白分色，按版面安排；背景红黑可调色统一，但复杂异象需源图。

直出判断：字层和调色容易；字体需授权，复杂环境不属简单滤镜

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

AI36 · 原作约40—72秒

分析单元 02 / 40—72秒

对白字幕／主客观镜头和正反打

实际观察

少年、老人、手持纸张细节交替，白底字幕居下，景深与灯笼背景维持。

表达作用（教学解读）

让一次画面替换有理由：继续动作、转换观点、给反应，或通过相似形状建立联系。

具体应用场景

动作、对话、运动、情绪混剪、多来源的视觉联系。

复现建议（非原作者工程还原）

剪全景/人物近景/道具插入，字幕描边定时显示；景深主要依赖源素材。

直出判断：有素材时容易，角色一致性需处理

常见误用：只匹配颜色不顾动作阶段；方向突变；每次连接都加过渡掩盖问题。

动作、视线与形状匹配 →漫画分层与2.5D视差 →

AI36 · 原作约76—84秒

分析单元 03 / 76—84秒

透明发光人群／水面反射

实际观察

蓝白半透明人形行走，边缘高亮，水面亦有影像；84秒转蛇尾细节。

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

抠人像降alpha，边缘提取加glow，镜像翻转/透视与波纹置换做简化倒影。

直出判断：平面轮廓和简化倒影中等；一致的人群动作、真实水体需素材/3D/生成

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

实际观察

107秒嘴前青白丝带，107.7转花苞接收丝带，108.7起花瓣逐渐打开露出多眼面部，红烟伸向前方；110秒后白竖书法渐显。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

复现建议（非原作者工程还原）

AI36 · 原作约116—124秒

分析单元 05 / 116—124秒

花内微缩燃烧建筑／火焰烟柱

实际观察

同花朵中可见建筑、火焰与上升烟柱，124秒回到人物侧脸。仅概览不足断言所有花内变化的生成路径。

表达作用（教学解读）

用熟悉尺寸与层次，让宏大空间被感知；留停帮助观众建立尺度。

具体应用场景

世界观、建筑概念、场景设定、神圣、敬畏、孤独和压迫。

复现建议（非原作者工程还原）

将建筑层遮罩进花心、加烟火透明素材与局部辉光，跟踪花朵；复杂透视需3D或生成。

直出判断：已有合适素材时中等，复杂花内空间与火灾非简单预设

常见误用：没有比例参照；每镜同一宏大构图；雾遮住所有结构；反射与相机运动不一致。

巨构、雾层与尺度参照 →复杂动作与镜头素材 →

AI36 · 原作约144—192秒

分析单元 06 / 144—192秒

低机位细节／反应镜头／延迟展示

实际观察

院落、木柴、提灯脚步，到少年近景、女子、手部、反打，再展示房间完整空间。画面冲击主要靠信息揭示顺序。

表达作用（教学解读）

把注意力从旧信息带往新信息；遮满时换底图，保持方向或形状上的联系。

具体应用场景

章节转换、空间跨越、角色亮相、画内物体自然遮挡后的换景。

复现建议（非原作者工程还原）

用道具/局部→人物反应→全景编排，控制单镜停留，字幕适量；阴暗氛围用对比与色温统一。

直出判断：剪接机制容易；生成表演与剧情编排需逐镜工作

常见误用：每镜不同花哨转场；遮罩与运动方向相反；过渡比内容本身更长；遮挡未满就穿帮。

形状遮挡、擦除与揭示 →动作、视线与形状匹配 →
