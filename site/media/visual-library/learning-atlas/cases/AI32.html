分析单元 01 / 0—5.331秒

前景松枝／云上红宫／崖台人物

实际观察

红宫与秋树在云海，深色前景松枝框出远景；2.862转岩壁平台上的小红衣人物。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

前景枝/主体/云海分层，冷暖光与尺度统一，人物作为空间参照。

直出判断：有分层素材后云雾/视差容易；建筑和岩壁美术需生成或3D

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →巨构、雾层与尺度参照 →

AI32 · 原作约5.331—15.706秒

分析单元 02 / 5.331—15.706秒

巨门云浪／崖中宫／室内天光

实际观察

巨大红门两侧云浪，接暖红悬宫与坐姿人物，再接殿内垂直白光束。

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

云浪用噪声位移加分层遮挡；殿内光束用体积感渐变、细尘粒和发光。

直出判断：简化云雾/光束容易；正确建筑空间与动态云浪较难

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

AI32 · 原作约15.706—36.205秒

分析单元 03 / 15.706—36.205秒

长廊柱列／消失点／雾中人物

实际观察

极长红柱廊跨云海，双列宫阙形成中轴，阶梯转弯和人物缓行。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

透视源图或3D长廊，遮罩分层慢推，深度雾和统一阴影；人物动作由源视频提供。

直出判断：慢推/雾层容易；长建筑连续细节和角色动作难

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

AI32 · 原作约51.732—61.7651秒

分析单元 05 / 51.732—61.7651秒

镜面倒影／斜光／圆门月轮

实际观察

长廊前水面映宫阙、斜光扫过，雾缓动；后为圆形红门框住月亮和山体。

表达作用（教学解读）

用熟悉尺寸与层次，让宏大空间被感知；留停帮助观众建立尺度。

具体应用场景

世界观、建筑概念、场景设定、神圣、敬畏、孤独和压迫。

复现建议（非原作者工程还原）

镜像图层+细波纹模拟水面，雾层和斜光遮罩；圆门前景/远山/月亮分层。

直出判断：简化倒影/光束/雾容易；准确反射和原建筑美术需素材

常见误用：没有比例参照；每镜同一宏大构图；雾遮住所有结构；反射与相机运动不一致。
