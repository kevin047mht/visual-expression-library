这一例先看什么

审美判断

白底黑色短文案、窄幅人物窗与少量英文形成克制层级；小字需原尺寸阅读，不能因为留白多或变化少判低质量。

迁移到自己的题材

漫画改编、人物回忆、纪念、故事提案、海报动态化、低动作但高情绪密度的段落。

教学提问：前景、中景、背景分别是什么？如果镜头移动，原图未画出的部分由谁补齐？

H07 · 原作约0—17秒

分析单元 01 / 0—17秒

高留白／纸面颗粒／小字双语文案／窄幅漫画窗

实际观察

4/8秒白底黑小字和细颗粒；12秒画面右侧人物与左文案，16秒简笔标题。

表达作用（教学解读）

把画面变成可触摸的记忆或记录；纸边、阴影与展示顺序可以表现珍惜、拼凑或碎裂。

具体应用场景

回忆、青春、艺术创作、旅行手记、人物档案、纪念短片。

复现建议（非原作者工程还原）

白底纸纹叠低alpha噪声，左右栅格排版，漫画裁切为窗口，字体分中文主行与小英文副行。

直出判断：容易，少量素材和清晰文案即可直出

常见误用：所有纸张纹理一样重；阴影方向不一致；折页遮挡错误；照片墙只有数量而没有观看顺序。

纸张、照片与漫画分格 →景深、柔焦与负空间 →

H07 · 原作约20—48秒

分析单元 02 / 20—48秒

条带裁切／三连重复人物／前景虚化与平移

实际观察

20秒侧背人物构图，24秒细横幅漫画，28秒同人物重复三份，32秒方形人物窗，44秒漫画与礼堂淡叠。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

矩形蒙版与复制排版，图片分层位移，加适量高斯模糊模拟景深，叠化连接空间。

直出判断：机制容易；漫画抠图/补背景需手工或分割

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →漫画分层与2.5D视差 →

H07 · 原作约55—57秒

分析单元 03 / 55—57秒

甩镜模糊／大字与人物分层／黑条收缩与黑闪

实际观察

55秒窄幅眼部，55.067起大范围方向模糊，55.267新人物配橙蓝底与散大字；56.267黑上下边增厚，56.533/56.8短黑帧后回同一画面，文字更换。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

先快速平移/旋转加运动模糊遮接点，人物与字分层；蒙版高度压缩，插黑帧，底部词块独立替换。

直出判断：基础机制容易，字体大小/镜头曲线/可读性需逐镜调试

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →闪白、黑帧与冲击帧 →

H07 · 原作约60—88秒

分析单元 04 / 60—88秒

宽画幅／书本举起／冷暖合成／黑底文案停顿

实际观察

60秒黑上下边夹暖色室内，68秒蓝天举书剪影，72秒蓝色纹理，76秒方幅云与小字，80/84秒黑底文案，88秒夕阳双人。

表达作用（教学解读）

建立段落、材质和情绪的一致性；颜色变化可以承担信息，而不只是美化。

具体应用场景

多片源混剪、人物立场、回忆/现实区分、冷暖转折、品牌统一。

复现建议（非原作者工程还原）

抠漫画人物接合适背景，加投影与统一光色；黑白字卡做停顿，按空间收放调整图像窗口。

直出判断：素材齐时中等，人物抠图、光线匹配和背景选择需处理

常见误用：所有镜头同一滤镜；肤色被破坏；饱和度代替焦点；色彩含义前后矛盾。

色彩组织与选择保色 →

H07 · 原作约90.3—92.3秒

分析单元 05 / 90.3—92.3秒

灰剪影过渡／斜网格／挤压线形转场／人物全身显露

实际观察

90.5人物灰剪影、90.633面部近景配斜网格；91.7压成黑底细线，91.767起白底斜向刷出，91.9完整人物与多个细框；92.167后再次方向模糊。

表达作用（教学解读）

把注意力从旧信息带往新信息；遮满时换底图，保持方向或形状上的联系。

具体应用场景

章节转换、空间跨越、角色亮相、画内物体自然遮挡后的换景。

复现建议（非原作者工程还原）

复制alpha作灰剪影，斜线网格背景；整体组层高度压缩至细线，白色遮罩按方向扫开，人物层与框线分时出现。

直出判断：中等，可程序化；准确边缘和转场速度需调试

常见误用：每镜不同花哨转场；遮罩与运动方向相反；过渡比内容本身更长；遮挡未满就穿帮。

形状遮挡、擦除与揭示 →几何拼贴与形状语言 →

H07 · 原作约98—102秒

分析单元 06 / 98—102秒

斜向甩镜／大字散落景深／中轴白字带／角色卡替换

实际观察

98.4起斜向拉伸，98.7新人物和散大字；99.8白底大字各自字号/角度/模糊不同；100.4黑场、100.8白线、100.9图卡中轴白带，101.4另一人物与手势。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

字做独立图层，按虚拟深度控制大小/模糊；斜向运动模糊连接，白条横贯画面承载中英词；人物卡在相同版式替换。

直出判断：中等，代码可出排版/遮罩；字体、图卡抠图与动势需调

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →漫画分层与2.5D视差 →

H07 · 原作约104—144.2秒

分析单元 07 / 104—144.2秒

半色调点阵／舞台背光／竖幅窗／圆形背景片尾

实际观察

104秒点阵带，108秒人物面向灯光与观众，112/116秒小窗与竖幅，120秒大圆半色调图与人物及署名，136秒横条，140秒天空背影。

表达作用（教学解读）

把短暂破坏作为失控、断裂、冲突或数字材质的提示。

具体应用场景

赛博题材、记忆中断、身份不稳、高潮强调；也可短时掩护连接。

复现建议（非原作者工程还原）

网点图可按灰度采样圆点，矩形/圆形遮罩控制画幅，人物alpha叠后，光线用径向渐变与辉光。

直出判断：简化网点、画幅和片尾容易；舞台空间合成中等

常见误用：全程持续导致麻木；色散让脸和字长期看不清；把所有亮度变化算成切镜。

RGB错位、条带与故障 →画中画、分屏与局部拼贴 →

用连续画面核对

保留原研究的多段局部摘录。片段含音轨不代表已听审；本资料不评价音乐卡点或对白节奏。

短时变化怎样理解

55–57秒眼部窄幅经甩镜到新人物至少1次，黑闪和黑边变化另记；98–102秒至少4次主构图替换，散字景深不是每字一刀。

把镜头连接、版式更新、局部图层变化和镜内运动分开记录。所查窗口是下限，不是全片平均或AI／人工排名。
