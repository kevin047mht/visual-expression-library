H30 · 原作约0—12秒

分析单元 01 / 0—12秒

碎片空间／人物双重曝光／椭圆暗角

实际观察

碎片围绕中心光点；人物与森林叠印；暗色风景被椭圆或模糊边缘围住。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

多边形碎片层、人物蒙版与背景纹理叠加、径向渐变暗角和景深模糊。

直出判断：基础机制容易，人物与森林融合需调节

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →景深、柔焦与负空间 →

H30 · 原作约16—24秒

分析单元 02 / 16—24秒

黑白波纹扭曲／相机取景框／液化拉伸

实际观察

漫画人物局部被涡旋扭曲，树场景叠取景框，随后黑白图形像熔化般拉伸。

表达作用（教学解读）

建立段落、材质和情绪的一致性；颜色变化可以承担信息，而不只是美化。

具体应用场景

多片源混剪、人物立场、回忆/现实区分、冷暖转折、品牌统一。

复现建议（非原作者工程还原）

位移贴图、极坐标或旋涡变换、矢量取景框；叠加噪声驱动局部形变。

直出判断：取景框容易；连续液化需调试

常见误用：所有镜头同一滤镜；肤色被破坏；饱和度代替焦点；色彩含义前后矛盾。

色彩组织与选择保色 →

H30 · 原作约28—52秒

分析单元 03 / 28—52秒

发光屏幕／空间钟表／漫画网点药瓶

实际观察

暗室发光矩形屏幕；钟表作为透视前景，字幕分布两侧；药瓶漫画线稿配网点和斜向空间。

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

矩形发光贴图、透视图层、景深与投影；半色调纹理和文字层分别合成。

直出判断：基础图层合成容易，完整空间需素材与灯光安排

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

发光字、光迹与轮廓光 →漫画分层与2.5D视差 →

H30 · 原作约76—84.583秒

分析单元 04 / 76—84.583秒

花瓣前景／负片闪烁／撕纸遮罩／径向模糊

实际观察

人物前散落花瓣。83–85秒人物在正负片间交替，局部被不规则白面擦过；84.167秒转另一人物构图，84.583秒转中央小漫画卡片。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

反色关键帧、噪声阈值遮罩、缩放模糊、花瓣粒子；画面替换独立控制。

直出判断：规则效果容易；干净边缘与人物资产需处理

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →漫画分层与2.5D视差 →

H30 · 原作约86—88秒

分析单元 05 / 86—88秒

横向切片错位／纸片字幕／黑闪／嵌套线框字卡

实际观察

手部画面被横向块状拉开；86.75秒及87.083秒黑闪；纸片字幕被放大撕裂，87.833秒落到黑底嵌套矩形字卡。

表达作用（教学解读）

把短暂破坏作为失控、断裂、冲突或数字材质的提示。

具体应用场景

赛博题材、记忆中断、身份不稳、高潮强调；也可短时掩护连接。

复现建议（非原作者工程还原）

横条遮罩独立偏移，纸片纹理与字幕绑定，关键帧曝光和显隐，矩形描边旋转。

直出判断：基础版容易，卡片运动可程序化

常见误用：全程持续导致麻木；色散让脸和字长期看不清；把所有亮度变化算成切镜。

RGB错位、条带与故障 →画中画、分屏与局部拼贴 →

斜向冲击拉伸／天鹅线稿／花瓣景深／黑白喷溅

实际观察

人物随斜线拉伸模糊，黑底天鹅线稿前漂浮白瓣，结尾白底黑色水滴喷溅。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

直出判断：基础版容易，精确线稿需现成素材

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。
