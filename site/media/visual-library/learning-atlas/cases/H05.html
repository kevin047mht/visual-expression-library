【静止画MAD/海虎】地心引力

让静止画产生空间动作与冲突的组织动作／武侠／英雄

黑白漫画、红黑冲击、山景云海和白场尾声有疏密反差，人物尺度变化和墨迹/条带组织前后层次。

从画面里找依据

这一例先看什么

黑白漫画、红黑冲击、山景云海和白场尾声有疏密反差，人物尺度变化和墨迹/条带组织前后层次。

审美判断

漫画人物黑白强轮廓与局部红色有明确焦点，竖排文字/宽幅小字辅助叙事；短暂拉伸、网点与冲击帧是动势设计，不能逐张要求静态阅读。

迁移到自己的题材

漫画改编、人物回忆、纪念、故事提案、海报动态化、低动作但高情绪密度的段落。

教学提问：前景、中景、背景分别是什么？如果镜头移动，原图未画出的部分由谁补齐？

带画面的分析单元

图像标出取样时间，对应观察中的关键状态。单帧不能独立证明运动，连续性请结合摘录。表达作用与应用场景是教学解读，复现路线是建议，不是原作者工程还原。

H05 · 原作约8—20秒

分析单元 01 / 8—20秒

黑白漫画分层／山景合成／暖色眩光与网点

实际观察

概览8秒人物立在漫画山崖并叠暖色光斑；12秒城市、16秒雪山配章节小字，20秒剪影云海有网点。概览不足以确定层间真实视差。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

先将漫画人物、山崖、天空分层，关键帧推拉；叠噪声、网点与模糊光斑。真实雪山需素材。

直出判断：基础分层运镜和网点容易；抠图、线稿修补与构图需素材处理

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →色彩组织与选择保色 →

H05 · 原作约24—28秒

分析单元 02 / 24—28秒

红黑双色／竖排白字／横向黑白条带

实际观察

27–27.3秒红黑画面缩放；27.4秒转黑白头像与竖排白字，27.9–28秒两条黑带跨脸滑入，间留细白线。

表达作用（教学解读）

建立段落、材质和情绪的一致性；颜色变化可以承担信息，而不只是美化。

具体应用场景

多片源混剪、人物立场、回忆/现实区分、冷暖转折、品牌统一。

复现建议（非原作者工程还原）

灰度和阈值建立黑白底，选定区域红色着色；文字逐字纵排，矩形图层按时间滑移，细线独立叠加。

直出判断：条带、纵排文字和双色处理容易，准确人物遮罩需准备

常见误用：所有镜头同一滤镜；肤色被破坏；饱和度代替焦点；色彩含义前后矛盾。

色彩组织与选择保色 →文字排版与逐字动效 →

H05 · 原作约28.1—30.9秒

分析单元 03 / 28.1—30.9秒

横向拉伸模糊／平铺插帧／竖条开窗／局部反色

实际观察

28.1–28.2横向模糊连接横构图，28.7–28.9短暂出现漫画重复平铺；29–29.2手臂置于窄白竖条，29.3后为手部近景；30.8眼部同图反色一瞬，30.9换剑柄。反色不计新镜头。

表达作用（教学解读）

把注意力从旧信息带往新信息；遮满时换底图，保持方向或形状上的联系。

具体应用场景

章节转换、空间跨越、角色亮相、画内物体自然遮挡后的换景。

复现建议（非原作者工程还原）

单帧或短序列平铺成网格，遮罩裁出竖条；方向模糊与scaleX快速变化形成拖拽，反色用颜色反转。

直出判断：几何机制容易；选择何时插入及素材轮廓需编排

常见误用：每镜不同花哨转场；遮罩与运动方向相反；过渡比内容本身更长；遮挡未满就穿帮。

形状遮挡、擦除与揭示 →闪白、黑帧与冲击帧 →

H05 · 原作约32—68秒

分析单元 04 / 32—68秒

墨迹笔刷／红色喷点／烟雾与镜头光

实际观察

概览32秒黑白人物配红喷点，36、48秒烟雾遮前景；52秒眼睛局部绿色，56秒圆形红黑区与锁链，64秒手部红线与上方粉光，68秒黑墨块。仅据概览描述形态。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

墨迹作为亮度遮罩或贴图，喷点用粒子/固定纹理，烟雾叠加透明素材；局部眼色用遮罩，光斑用模糊渐变。

直出判断：简化光雾和遮罩容易；复杂墨迹与锁链需贴图或矢量素材

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →色彩组织与选择保色 →

H05 · 原作约96—124秒

分析单元 05 / 96—124秒

宽银幕构图／细字幕／圆轨迹发光与气泡

实际观察

96秒宽幅山水，104秒双人侧脸间有发光点及细弧线；108秒倒置城市与圈泡，112秒白空间左侧字幕，116秒飞鸟与人物，120秒漫画竖向拖影。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

现成场景按宽幅裁切，字幕独立定时；发光圆点沿样条，圆泡以描边圆/贴图布置，整体旋转模拟倒置。

直出判断：字幕、轨迹、圈泡与旋转容易；美术和空间遮挡需调试

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →发光字、光迹与轮廓光 →

H05 · 原作约126—128秒

分析单元 06 / 126—128秒

冲击闪帧串联／黑帧停顿／径向拉近

实际观察

126秒白场后红色电弧、漫画剪影和红底构图密集更换；126.733–126.8黑场，随后人物及碎块向外放大。127.333–127.533又黑场，127.733后进入天空碎块画面。闪帧、黑场和漫画图替换交错，不能把每个明暗变化都当切镜。

表达作用（教学解读）

短暂中断视觉连续性，强调接触、转折或心理断裂；其价值来自前后的对比。

具体应用场景

打击点、快速连接、记忆跳跃、段落转折；需要根据内容选择强度。

复现建议（非原作者工程还原）

按帧表安排漫画图、色卡和短黑帧；用带辉光折线模拟电弧；图层缩放叠径向模糊，碎块沿轨迹外扩。

直出判断：序列控制与基础冲击效果容易；漫画素材、碎块边缘和节奏需人工设计

常见误用：把闪烁当节奏本身；没有稳定画面作参照；为掩盖动作不清持续加闪。

闪白、黑帧与冲击帧 →密度、停留与段落节奏 →

H05 · 原作约138—140秒

分析单元 07 / 138—140秒

紫白大字旋涡／网点与速度线／斜向擦入

实际观察

138–138.467大字同布局快速扭转缩放，紫色边缘和白速度线交替，138.533换黑白吼叫侧脸；139秒手部入场，139.2–139.333黑白斜形遮挡，139.4两人物构图，139.6起推近其中一人。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

将字体或漫画字形栅格化，旋转缩放配位移和径向线；斜多边形遮罩连接人物图，最后推近并加模糊。

直出判断：基础字形变换和斜遮罩容易；准确夸张字形需字形/美术资源

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →镜头推拉、跟随与变速 →

H05 · 原作约140—176秒

分析单元 08 / 140—176秒

漫画人物分层／冷暖色光晕／白场留字

实际观察

140、144、148秒人物和天空叠光雾；152秒黑白人物近景，156、172秒是对峙与打击构图，176秒白底人物配黑色大字和三角碎片。不能从4秒概览断定所有中间动作。

表达作用（教学解读）

建立段落、材质和情绪的一致性；颜色变化可以承担信息，而不只是美化。

具体应用场景

多片源混剪、人物立场、回忆/现实区分、冷暖转折、品牌统一。

复现建议（非原作者工程还原）

人物单独透明层，背景色调与光斑统一；几何碎片旋转淡出，末尾白底排字提供停顿。

直出判断：图层动画与白场文字容易；复杂对打、形变和原漫画修补需逐镜处理

常见误用：所有镜头同一滤镜；肤色被破坏；饱和度代替焦点；色彩含义前后矛盾。

色彩组织与选择保色 →漫画分层与2.5D视差 →

H05 · 原作约180—188秒

分析单元 09 / 180—188秒

白场尾声／小字与团队标识

实际观察

180、184秒白底居中小字，188秒黑色团队图形标识。停留和留白与前段密集变化形成节奏差。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

白色背景加定时文字与已有透明标识，按阅读时长安排停留。

直出判断：容易，标识素材需提供或自行设计

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。

密度、停留与段落节奏 →景深、柔焦与负空间 →

短时变化怎样理解

27–31秒保守7次主要构图替换，反色和同构图扩展另列；138–140秒大字旋转、斜形遮挡到人物至少3次，推近不另计。
