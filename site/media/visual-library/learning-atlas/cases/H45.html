呐，你喜欢跑步嘛？【小栗帽/赛马娘/静止系MAD】

静止画的精细分层、透视胶片与字串变化，是空间与信息的叠加；共享源计划素材的劳动归属也要保留。

从画面里找依据

这一例先看什么

胶片纹理、漫画着色、烟花、刻度泡泡和透视胶片带构成多种空间，原计划共享素材需说明。

审美判断

蓝眼与暗场形成焦点，后段品红标题、白底竖字、红蓝细条保持清晰层级；随机字不是需全读正文。

迁移到自己的题材

漫画改编、人物回忆、纪念、故事提案、海报动态化、低动作但高情绪密度的段落。

教学提问：前景、中景、背景分别是什么？如果镜头移动，原图未画出的部分由谁补齐？

带画面的分析单元

图像标出取样时间，对应观察中的关键状态。单帧不能独立证明运动，连续性请结合摘录。表达作用与应用场景是教学解读，复现路线是建议，不是原作者工程还原。

H45 · 原作约0—10.8秒

分析单元 01 / 0—10.8秒

旧胶片纹理／暗角／薄雾

实际观察

漫画人物以窄窗呈现，有灰白薄雾、竖向划痕、颗粒和虚焦。

表达作用（教学解读）

决定什么值得看、什么退到感受层；清晰与模糊、占满与留空之间的关系塑造语气。

具体应用场景

回忆、亲密、孤独、人物介绍、信息减负、画面间的呼吸。

复现建议（非原作者工程还原）

噪声纹理、划痕细线、暗角和透明雾层，人物分层加轻微平移。

直出判断：纹理、雾、暗角容易；人物细分层需处理

常见误用：模糊所有层；细字落在高亮区域；浅色误认为高级；没有清楚的主焦点。

景深、柔焦与负空间 →纸张、照片与漫画分格 →

H45 · 原作约12—32秒

分析单元 02 / 12—32秒

漫画着色／散景／烟花

实际观察

手与森林光束、桥边人物、蓝眼特写，夜空烟花和彩色散景。

表达作用（教学解读）

决定什么值得看、什么退到感受层；清晰与模糊、占满与留空之间的关系塑造语气。

具体应用场景

回忆、亲密、孤独、人物介绍、信息减负、画面间的呼吸。

复现建议（非原作者工程还原）

漫画抠图/补绘/着色，背景虚化，烟花粒子轨迹和辉光，镜头光斑叠层。

直出判断：简化烟花和散景容易；精细着色与原画美术需素材

常见误用：模糊所有层；细字落在高亮区域；浅色误认为高级；没有清楚的主焦点。

景深、柔焦与负空间 →发光字、光迹与轮廓光 →

H45 · 原作约33—49秒

分析单元 03 / 33—49秒

分层漫画／黑白放射冲击／光束

实际观察

俯视人物、黑色剪影、编号人物后有强黑白放射形与人物特写。

表达作用（教学解读）

将平面关系变成有前后层次的观看空间；小幅运动可以放大情绪。

具体应用场景

静止画MAD、回忆、图像故事、海报动态化、人物介绍。

复现建议（非原作者工程还原）

多层漫画Z轴错位/镜头微移，放射线与阈值色阶，光束遮罩加辉光。

直出判断：简化冲击光束容易；抠图补洞和空间一致性中等

常见误用：所有层同速或反向乱动；人物像纸板；补洞不完整；视角变化超出原画信息。

漫画分层与2.5D视差 →发光字、光迹与轮廓光 →

H45 · 原作约51—62.4秒

分析单元 04 / 51—62.4秒

品红题字／极简竖排对白／彩色细条

实际观察

人物胸前品红圆底和日文横字，继而白底竖排细字、红蓝细长条与线框。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

文字和几何层独立排版，行/字遮罩揭示，色条位移与透视缩放。

直出判断：简化字效和几何版式容易直出

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →几何拼贴与形状语言 →

H45 · 原作约62.4—67秒

分析单元 05 / 62.4—67秒

黑帧连接／窄幅插窗／角色动态

实际观察

小窗口角色发丝、手部、脸接跑步群像，光点、红蓝细横光覆盖。

表达作用（教学解读）

短暂中断视觉连续性，强调接触、转折或心理断裂；其价值来自前后的对比。

具体应用场景

打击点、快速连接、记忆跳跃、段落转折；需要根据内容选择强度。

复现建议（非原作者工程还原）

画幅遮罩缩放、角色源层运动、短黑帧连接，横向光条跟踪。

直出判断：窗口/黑帧/光条容易；发丝和跑步动作用源素材

常见误用：把闪烁当节奏本身；没有稳定画面作参照；为掩盖动作不清持续加闪。

闪白、黑帧与冲击帧 →复杂动作与镜头素材 →

H45 · 原作约69—76秒

分析单元 06 / 69—76秒

红色链条／灼烧字纹／眼部冲击

实际观察

黑场景上红链条和光点，随后棕黑纹理大字及蓝眼漫画近景。

表达作用（教学解读）

让多个时间、视角或人物关系同时出现；通过对位建立联系，而非只提高画面数量。

具体应用场景

记忆、对话、关系对照、主观视点、多人角色介绍、跨素材呼应。

复现建议（非原作者工程还原）

链条可重复矢量沿路径排布，噪声纹理与粗糙遮罩做灼烧感，眼部放大加径向模糊。

直出判断：简化链条和纹理字中等；自然链条空间摆动需3D或精细路径

常见误用：窗口太多无主次，眼位错位、边框挤脸，层的出现没有叙事理由。

画中画、分屏与局部拼贴 →文字排版与逐字动效 →

H45 · 原作约78—88秒

分析单元 07 / 78—88秒

刻度仪表／泡泡／人物分层逆光

实际观察

弧形刻度与小字围绕人物，漂浮泡泡；后为脚手架/河岸逆光人物。

表达作用（教学解读）

用运动方向、尺度和密度建立空气、空间或情绪；装饰层应服务焦点。

具体应用场景

回忆、季节、梦幻、寒冷、散场、能量爆发、文本聚散。

复现建议（非原作者工程还原）

弧线刻度程序绘制，透明圆泡高光、前后景虚化，人物与光源分层。

直出判断：刻度和泡泡容易；光照与抠图边缘需调试

常见误用：平均铺满；近远粒子大小与模糊无差别；粒子挡脸；用程序火星冒充纪实拍摄。

粒子、花瓣、雪与碎片 →漫画分层与2.5D视差 →

斜置胶片条中有小画面，前方大串文字快速替换，90.34前后收束成较小中央语句，泡泡继续漂浮。

表达作用（教学解读）
