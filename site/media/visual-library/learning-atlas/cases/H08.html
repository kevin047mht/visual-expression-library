审美判断

横条画幅、竖排对白与大描边标题分层，黑红题图对比明确；赛事开场包装不算本片新增设计。

迁移到自己的题材

H08 · 原作约0—12秒

分析单元 01 / 0—12秒

比赛包装／大字透视／红黑封面

实际观察

4秒大MAD字和虚线矩形、8秒角色与比赛标，12秒红黑题图。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

文字透视/挤出假厚度，图像窗与线框排版，红黑双色映射。

直出判断：简化字效与版式容易；比赛公共包装归属未确定

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

文字排版与逐字动效 →漫画分层与2.5D视差 →

H08 · 原作约16—44秒

分析单元 02 / 16—44秒

横向画幅遮罩／城市叠层／描边字／线稿反相

实际观察

多段图像以宽条显示，32秒城市上标题、36秒暗背景描边字、40秒城市亮线与说明。

表达作用（教学解读）

把注意力从旧信息带往新信息；遮满时换底图，保持方向或形状上的联系。

具体应用场景

章节转换、空间跨越、角色亮相、画内物体自然遮挡后的换景。

复现建议（非原作者工程还原）

上下遮罩、源片缩放/平移、文字描边，边缘提取/反相与光感纹理。

直出判断：遮罩与字效容易；城市源美术和镜头由素材提供

常见误用：每镜不同花哨转场；遮罩与运动方向相反；过渡比内容本身更长；遮挡未满就穿帮。

形状遮挡、擦除与揭示 →文字排版与逐字动效 →

H08 · 原作约48—124秒

分析单元 03 / 48—124秒

漫画着色／浅景深／漏光／纵向对白

实际观察

漫画人物局部着色、暖光、暗角、背景虚化；60/64秒竖排文字；124秒两人中央、黑白图案环绕。

表达作用（教学解读）

决定什么值得看、什么退到感受层；清晰与模糊、占满与留空之间的关系塑造语气。

具体应用场景

回忆、亲密、孤独、人物介绍、信息减负、画面间的呼吸。

复现建议（非原作者工程还原）

人物/背景分层并补洞，色块与光影遮罩，前景模糊层模拟景深；对白独立排版。

直出判断：对白/漏光容易；精细分层补绘、脸部着色与光影一致性需逐图处理

常见误用：模糊所有层；细字落在高亮区域；浅色误认为高级；没有清楚的主焦点。

景深、柔焦与负空间 →漫画分层与2.5D视差 →

H08 · 原作约130—131.1秒

分析单元 04 / 130—131.1秒

液化扭曲连接／对白揭示

实际观察

130.2秒人物侧脸对白逐字出现；130.9–131秒侧脸和对白融成不规则波纹，131.1秒换破损环境中的人物。

表达作用（教学解读）

把注意力从旧信息带往新信息；遮满时换底图，保持方向或形状上的联系。

具体应用场景

章节转换、空间跨越、角色亮相、画内物体自然遮挡后的换景。

复现建议（非原作者工程还原）

噪声位移贴图强度先升后降，A/B图像在扭曲峰值切换，外轮廓alpha变形，文字可行/字遮罩揭示。

直出判断：简化液化和揭字中等；准确保留面部轮廓需调参

常见误用：每镜不同花哨转场；遮罩与运动方向相反；过渡比内容本身更长；遮挡未满就穿帮。

形状遮挡、擦除与揭示 →文字排版与逐字动效 →

H08 · 原作约131.1—134秒

分析单元 05 / 131.1—134秒

人物与环境分层／竖排双栏／地面故障块

实际观察

131.1–132.6人物近景与废墟微动，132.8秒转低头人物、石墙、两列竖字，脚下红黑矩形故障块横移。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

观点短片、歌词视觉、人物宣言、章节、情绪高潮；先决定哪些词必须读懂，哪些只是纹理。

复现建议（非原作者工程还原）

分层人物/背景相机微移，局部光晕，文字列排版，地面条块用噪声/随机矩形与位移。

直出判断：文字和故障块容易；可信景深与人物抠图需素材整理

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

H08 · 原作约158.2—160.2秒

分析单元 06 / 158.2—160.2秒

电弧／能量环／放射冲击／速度线通道

实际观察

星空人物手部伸展、紫色电弧铺开；159.067黑白冲击，159.333正面人物配环光，159.667转彩色速度线通道、160.067再黑白亮形。

表达作用（教学解读）

让能量、方向或主次可见；清楚的字芯和主体轮廓应保留。

具体应用场景

战斗、魔法、科技、梦境、舞台、标题强调、人物焦点。

复现建议（非原作者工程还原）

抠图/静图缩放配电弧折线路径，辉光环与粒子，短黑白曝光，透视线向消失点延伸。

直出判断：简化电弧/光环/速度线容易；多层精细合成与原角色画面需处理

常见误用：只加大模糊半径；光源不影响周围环境；发光覆盖所有细节；把原片光效当新增。

发光字、光迹与轮廓光 →RGB错位、条带与故障 →

H08 · 原作约180—202.933秒

分析单元 07 / 180—202.933秒

分屏／亮度遮罩／漏光转文字

实际观察

180秒两个人物并排，192秒夕景，200秒高对比白底黑形；201秒两人白底静态，到202.333秒光斑遮过后转黑纹理竖排文字。

表达作用（教学解读）

把阅读顺序变成观看顺序；用字重、位置与停留表达强调、犹豫或压迫。

具体应用场景

复现建议（非原作者工程还原）

分屏遮罩；亮度映射；叠加移动柔光斑，在明亮覆盖时替换底图。

直出判断：分屏和漏光转场容易；不把漏光每次闪动当新镜头

常见误用：每个字都弹跳、整句停留不足、所有文字同时争主位。严肃叙事里无理由的回弹会削弱重量。

H08 · 原作约204—236.48秒

分析单元 08 / 204—236.48秒

暗纹理竖字／立体字森林／极简片尾

实际观察

204–208秒黑纹理和竖字，220秒密集细高字层与城市色片，224–236秒团队标与手绘墓碑。

表达作用（教学解读）

通过变化与稳定的比例让信息有轻重。视觉密度来自切镜、版式与局部动画三个层面，不只靠刀数。

具体应用场景

所有形式；尤其高潮前的蓄力、解释段的阅读、回忆段的停留和快慢对照。

复现建议（非原作者工程还原）

噪声纹理、文字逐字淡入、透视字卡多层排布，手绘线图需素材。

直出判断：简单文字/片尾容易；大量透视字层需排布，原图与团队标不照搬

常见误用：全片等密度；把闪帧当新镜；高切速被当成质量分；没有稳定段供观众理解。
