# 资料馆的阅读设计

主任务是图像与论点对照、跨案例检索和表达练习。采用静态HTML及本地JavaScript，不依赖外部服务。

已查阅ui-ux-pro-max的设计建议。两次检索得到的营销页面结构不适合学习资料，未采用；借鉴其Swiss Modernism网格、清楚层级、键盘焦点、低运动和响应式原则。导航和学习编排由本任务独立设计，属于适配回退，不将检索结果冒充验证过的阅读馆模板。

- 暖纸色背景、深色正文与低饱和绿色链接，图像保留原色。
- 桌面将画面与分析并排；窄屏按“画面—分析”顺序堆叠。
- 页面使用本机中文字体，无外部字体下载。
- 全部100例有静态HTML；筛选和对照使用本地数据，file协议也无需fetch。
- 图片有时间码、alt、固有尺寸和延迟加载；视频不自动播放。
- 高对比闪帧可以作为证据，但首页代表帧优先选已有观察中能辨认内容的稳定状态。
- 交互至少44像素高，焦点可见，尊重减少动态设置，提供打印样式。
