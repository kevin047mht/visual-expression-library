# 视觉表达资料馆

双击 index.html 即可离线阅读，不需要安装或登录。主入口包含学习地图、100例图谱、20种手法、8条阅读路径、10组对照与表达练习。

案例页把真实画面放在对应分析旁；点图可打开保存的单帧，短片保留在上层 evidence 目录。请保留整个 bilibili-editing-study 文件夹的目录结构，勿单独移动 learning-atlas。

筛选和自选对照由本地JavaScript运行；无外部字体、CDN、分析统计或上传。已读和笔记只尝试保存在当前浏览器；本地文件策略可能限制保存，重要笔记请用“导出”按钮备份。

分类、表达解读、应用场景和练习是教学建议，不能当作原作者意图。原研究是间隔概览与局部连续帧，不声称连续看完100部；音画对拍未核验。H30详细制作方式仍待核，16条局部参考不能写成100部全片精品认证。

atlas-index.json保留分类和逐例内容；image-provenance.json列图片原始路径、时间与哈希。网页可打印；全部案例有静态HTML，禁用脚本仍可顺序阅读。
