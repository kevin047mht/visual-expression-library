# B站AI与人工剪辑：100条画面取样、特效描述与直出评估

交付范围：AI相关50条、人工主导剪辑参考50条，用户截图中的7条参考全部纳入。100条均保存第一方页面快照、全片间隔概览、局部连续帧和至少两段摘录；累计284段局部摘录，97条增量审阅记录中有653条效果观察，最初3条另作详细分析。画面质量复筛后，84条作为主要视觉研究样本，16条作为局部机制／局限参考。

## 两组在本次画面中的表现

AI相关作品可分三种路径：AI写代码绘制PV／几何和文字动画；生成角色或景观镜头后由人组织后期；作者设定分镜、参考图及动作时间段再生成镜头。前一种擅长按时间表准确重复文字、面板、几何与参数运动；后两种的复杂美术和运动需要生成素材，不能从“AI制作”标题推断剪辑、脚本和修正也已自动完成。《侠影宠梦》明确列出剪映剪辑；Seedance武侠测试片尾展示参考图和分时段动作输入。

人工组同时有动态AMV、静止漫画合成、影视／游戏选材、人物叙事和纯文字混剪。已审片段中的价值既可能是立体排字、抠图和空间层次，也可能是相同手势、表情反应或情绪意象的选材连接。《电影混剪·相遇》与新海诚AMV的复杂云海、摄影和人物演技主要来自原素材，不能当成剪辑者新增特效；《致作家》的条带持续运动则说明视觉密度不必依赖整屏硬切。

两组题材、年代、片长和制作路径并未匹配，且有同源代码、系列剧集、仿作及共享片头。因此不能用局部切镜数、播放量、token数或分辨率得出“AI／人工整体更快、更好”的排名。能比较的是具体窗口中如何维持视觉焦点，以及哪一层工作能程序化。
